| APP-0001 | 2026-05-17 | Alzer and Kwong conjectured the reciprocal zeta function \(F(x)=1/\zeta(x)\) has the sign pattern \[ F''(x)>0\quad\text{on }(-4n,-4n+2), \] and \[ F''(x)<0\quad\text{on }(-4n-2,-4n), \] for every integer \(n\ge1\). | Alzer-Kwong convexity and concavity pattern for reciprocal zeta | solution candidate at THEORY_v001 | no contact |
