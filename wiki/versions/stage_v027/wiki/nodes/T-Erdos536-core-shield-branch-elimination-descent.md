# Theorem: Erdos536 core shield branch elimination descent

## Statement

Core/shield branch elimination theorem: in any admissible lower-trace spread model from the Erdos536 frontier, zero coordinate coverage cannot be maintained by fixed common cores, moving common cores, or endpoint shields. More precisely, each such branch either forces rank-thinness, produces a support-level fork \(A\cup B=C\), gives positive conditional coverage \(\mathbf E[\Omega_k(C)\mid C\in\mathcal F_k]>0\), or descends to a strictly smaller endpoint/core model with a controlled complexity measure that terminates.
