# Definition: Laguerre-Polya EGF coefficient sequence

## Statement

For an entire function written in exponential generating form \(f(x)=\sum_{n\ge0}\gamma_n x^n/n!\), the coefficient sequence is \(\gamma_n(f)=n![x^n]f(x)\). In Wang--Yang's source problem this sequence is attached to a Laguerre--Polya function and is assumed positive and decreasing.
