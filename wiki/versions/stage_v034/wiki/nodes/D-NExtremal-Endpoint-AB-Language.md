# Definition: Special N-extremal endpoint A/B language

## Statement

For a special \(N\)-extremal indeterminate measure \(\mu\), Berg--Szwarc define \(a(\mu)=\sup\{\alpha:\mu\in A(\alpha)\}=\inf\{\beta:\mu\in B(\beta)\}\), and endpoint classes \(A\), \(B\) according as \((1+x^2)^{-a(\mu)}d\mu\) is indeterminate or determinate.
