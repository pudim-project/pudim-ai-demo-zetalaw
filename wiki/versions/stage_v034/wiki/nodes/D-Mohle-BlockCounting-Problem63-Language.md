# Definition: Mohle block-counting Problem 6.3 language

## Statement

In Mohle's block-counting source, \(\Delta=\{u_1\ge u_2\ge\cdots\ge0: |u|=\sum_i u_i\le1\}\). For \(n\in\mathbb N\), the source quantity \(p_n(u)\) is \(\mathbb E\widetilde Y(n,u)-\mathbb E(\widetilde Y(n,u)^2)\), and Problem 6.3 asks whether \(p_n(u)\ge0\) for all \(u\in\Delta\).
