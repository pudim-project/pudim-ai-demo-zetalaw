# Definition: Caratheodory class normalization

## Statement

The normalized Caratheodory class \(\mathcal P\) consists of analytic functions \(p\) on \(\mathbb D\) with \(p(z)=1+\sum_{n\ge1}c_nz^n\) and \(\operatorname{Re}p(z)>0\) on \(\mathbb D\). In particular, every \(p\in\mathcal P\) satisfies \(p(0)=1\).
