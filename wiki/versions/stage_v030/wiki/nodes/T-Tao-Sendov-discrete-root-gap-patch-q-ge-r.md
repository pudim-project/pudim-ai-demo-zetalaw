# Theorem: T-Tao-Sendov-discrete-root-gap-patch-q-ge-r

## Statement

For every compact range 0<r0<=r<=1-rho<1, there exist c(r0,rho)>0 and d0(r0,rho) such that for all integers m,N>=1, D=m+N, q=m/D, d=D+1, if q>=r then every root of the tangent-cluster quadratic inside the unit disk has gap 1-|y|>=c(r0,rho)/d.

## Scope

- Exact integer tangent-cluster model, compact r range, q>=r only.
