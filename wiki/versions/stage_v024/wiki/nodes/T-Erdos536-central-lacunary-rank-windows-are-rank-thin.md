# Theorem: Erdos 536 central lacunary rank windows are o sqrt S rank thin and mass negligible

## Statement

Let \(S_k=\sum_{i\le k}1/p_i\) and let \(\nu_k(p_i\in S)=1/p_i\). If \(R_k\subseteq\{0,1,\ldots,k\}\) has the property that, for each fixed \(M>1\), the positive ranks in \(R_k\cap[1,MS_k]\) contain no pair \(r<s\le2r\), then \(|R_k\cap[1,MS_k]|=O_M(\log S_k)=o(\sqrt{S_k})\). Consequently the \(\nu_k\)-mass of sets with ranks in \(R_k\cap[1,MS_k]\) tends to \(0\), and the tail \(|S|>MS_k\) is bounded by \(1/M\).
