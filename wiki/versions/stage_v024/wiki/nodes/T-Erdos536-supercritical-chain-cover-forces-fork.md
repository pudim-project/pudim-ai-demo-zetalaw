# Theorem: Erdos 536 supercritical chain cover maximum fibers force lower shadow fork

## Statement

For every fixed \(0<\theta<1\), if a high-support family \(\mathcal F_k\subseteq H_{k,\theta}\) has supercritical weighted maximum-fiber chain-cover number \(C_k(\theta)\not=o(\sqrt{S_k})\) along a positive-mass subsequence, then for infinitely many \(k\) it contains a lower-shadow fork: three distinct \(A,B,C\in\mathcal F_k\) such that \(A,B\subsetneq C\) and \(A\cup B=C\).
