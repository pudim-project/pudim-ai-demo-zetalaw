# Theorem: Bazhlekova no cover seed coefficient pattern break Q4482 y4479

## Statement

At the no-cover seed \((a,b)=(3/2,2/5)\), the signed derivative polynomial \(R_{4482}(y)=(-1)^{4481}Q_{4482}(y)\) has a negative \(y^{4479}\) coefficient. Hence the observed-through-201 pattern that only the \(y^{n-1}\) coefficient can be negative is false as an all-order statement.
