# Theorem: Yin p,k-digamma complete monotonicity implies alpha <= 1

## Statement

For \(p\in\mathbb N\), \(k>0\), if \(x^\alpha\left[\frac1k\log\frac{pkx}{x+k(p+1)}-\psi_{p,k}(x)\right]\) is completely monotone on \((0,\infty)\), then \(\alpha\le1\).
