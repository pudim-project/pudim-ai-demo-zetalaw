# Theorem: H_a=e^a-(1+a/x)^x completely monotonic for 0<a<=1 via Alzer Berg H_1 Stieltjes theorem

## Statement

For every \(0<a\le1\), the function \(H_a(x)=e^a-(1+a/x)^x\) is completely monotonic on \((0,\infty)\).
