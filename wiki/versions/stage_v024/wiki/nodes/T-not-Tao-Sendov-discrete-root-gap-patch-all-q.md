# Negative_Result: T-not-Tao-Sendov-discrete-root-gap-patch-all-q

## Statement

The compact-r discrete tangent-cluster bound 1-s>=c(r0,rho)/d cannot hold uniformly for all q=m/(m+N). In the below-boundary layer q=r-mu/d, the large-root gap has leading term kappa_r(r^2(3-r^2)-mu)/d, so tuning mu near r^2(3-r^2) can produce interior gaps of order d^-2.

## Scope

- Negative result for the all-q tangent-cluster patch; does not affect the q>=r theorem.
