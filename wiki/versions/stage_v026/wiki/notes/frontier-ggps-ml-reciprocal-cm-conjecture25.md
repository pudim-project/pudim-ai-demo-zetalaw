# Frontier Note: GGPS Mittag-Leffler Reciprocal CM Characterization

Source: R. Garrappa, S. Gerhold, A. Popolizio, and T. Simon, *On some inequalities for the two-parameter Mittag-Leffler function in the complex plane*, arXiv:2410.11852.

The first-contact audit records Conjecture 25 as source-open and fresh-checked: for \(1<\alpha<2\), the source asks for the equivalence between the global inequality
\[
|E_{\alpha,\beta}(z)|\ge E_{\alpha,\beta}(\operatorname{Re}z),
\]
the window \(\beta\in[\alpha-1,\alpha]\), and complete monotonicity of \(x\mapsto1/E_{\alpha,\beta}(x)\) on \((0,\infty)\).

The first Student pass did not solve the source problem. It admitted four primitive-level results:

- The positive Laplace representation of \(1/E_{\alpha,\beta}\) cannot be continued across the first negative real zero by asking for a finite exponential moment at that zero.
- If the global inequality holds, every non-real zero \(\zeta\) must satisfy \(E_{\alpha,\beta}(\operatorname{Re}\zeta)\le0\).
- If the global inequality holds and \(E_{\alpha,\beta}(x)>0\), then \((E_{\alpha,\beta}'(x))^2-E_{\alpha,\beta}(x)E_{\alpha,\beta}''(x)\ge0\).
- If \(\log G\) is a complete Bernstein function with the standard representation, then \(|G(x+iy)|\ge G(x)\) for \(x>0\).

Status: bridge and route-hygiene only. No APP is solved. The next non-numeric route is the compact positive-island problem, with the lower endpoint \(\beta=\alpha-1\) separated from the source's open-strip reduction.
