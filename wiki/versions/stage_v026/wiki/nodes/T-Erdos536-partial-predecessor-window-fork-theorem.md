# Theorem: Erdos 536 partial predecessor rank window density forces fork or nondegenerate lower ranks

## Statement

Partial predecessor-window fork theorem: in the prime-biased Erdos 536 setup, every positive-mass fork-free coherent moving-star system with occupied tops in a central linear window and with lower traces concentrated in the predecessor regime either has nondegenerate lower-rank mass, or its actual predecessor closure contains a positive-density partial rank window on two close ranks \(m<n\le2m\). In the latter case there exist distinct \(A,B,C\in\mathcal F_k\) with \(A\cup B=C\). Consequently the dense partial-predecessor branch of `T-Erdos536-fork-free-coherence-links-top-window-to-lower-star-ranks` holds.
