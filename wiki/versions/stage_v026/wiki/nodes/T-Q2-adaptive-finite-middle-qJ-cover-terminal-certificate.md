# Theorem: adaptive finite middle cover below qJ plus compact and near one covers proves terminal endpoint

## Statement

Using the true near-zero cover \((0,1/100]\), the true endpoint-sign certificate on \(J\), and the true enclosure lemmas, there is an adaptive finite rational cover of \([1/100,1409/5000]\cup[293/1000,9/10]\) proving \(Q_2(x)<q_J\) on every interval. Combined with a compact one-crossing certificate for \(G\) outside \(J\) and a near-one cover on \([9/10,1)\), this determines \(L_2=Q_2(\xi)\) and \(\mathcal I_2=(Q_2(\xi),3]\).
