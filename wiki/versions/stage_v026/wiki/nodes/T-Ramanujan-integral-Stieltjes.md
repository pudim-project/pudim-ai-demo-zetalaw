# Theorem: Ramanujan integral I_R is Stieltjes

## Statement

The Ramanujan integral \(I_R(x)=\int_0^\infty e^{-xt}\,dt/[t(\pi^2+\log^2 t)]\) is a Stieltjes function on \((0,\infty)\).
