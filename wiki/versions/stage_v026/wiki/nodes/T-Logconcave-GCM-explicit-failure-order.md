# Theorem: explicit log-concave Gaussian heat-flow entropy complete monotonicity failure order

## Statement

There is an explicit log-concave probability measure \(\mu\) on \(\mathbb R\), an explicit time \(t_0>0\), and an explicit integer \(m\ge6\) such that \((-1)^mH_\mu^{(m)}(t_0)<0\).
