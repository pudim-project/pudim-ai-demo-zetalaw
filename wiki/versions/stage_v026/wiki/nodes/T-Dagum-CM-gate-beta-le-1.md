# Theorem: Dagum auxiliary function is completely monotone for alpha nonnegative and beta between zero and one

## Statement

For \(f_{\alpha,\beta}(x)=x^{-\alpha}(1+x^\beta)^{-1}\), if \(\alpha\ge0\) and \(0\le\beta\le1\), then \(f_{\alpha,\beta}\) is completely monotone on \((0,\infty)\).
