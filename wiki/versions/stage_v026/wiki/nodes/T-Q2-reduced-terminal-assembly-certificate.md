# Theorem: reduced assembly of true endpoint covers finite middle cover and compact certificate proves terminal endpoint

## Statement

The terminal endpoint follows from the reduced certificate package consisting of the true near-zero cover \((0,1/100]\), the true near-one cover \([9/10,1)\), the true endpoint-sign certificate on \(J\), a finite-middle cover of \([1/100,1409/5000]\cup[293/1000,9/10]\) below \(q_J\), and a compact one-crossing/dominance certificate for \(G\) on \([1409/5000,293/1000]\setminus J\). This package determines \(L_2=Q_2(\xi)\) and \(\mathcal I_2=(Q_2(\xi),3]\).
