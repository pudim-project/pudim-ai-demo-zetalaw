# Theorem: YHL alpha zero k-digamma bracket CM iff mu <= kc/2

## Statement

For positive \(k,a,b,c,d\), the function \(B(x)=\psi_k(ax+b)-k\log(cx+d)\) is completely monotonic on \((0,\infty)\) if and only if \(\mu=kc+ad-bc\le kc/2\).
