# Theorem: Simon gamma quotient is Bernstein for alpha in (0,1)

## Statement

For every \(0<\alpha<1\), the function \(F_\alpha(x)=\Gamma(x+\alpha)/(\Gamma(x)x^\alpha)\) is a Bernstein function on \((0,\infty)\).
