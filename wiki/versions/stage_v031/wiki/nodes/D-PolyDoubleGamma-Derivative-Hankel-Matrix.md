# Definition: Poly-double-gamma derivative Hankel matrix

## Statement

For \(y>0\), \(n\ge2\), and positive integers \(j,m\), define the Proposition 4.1 Hankel-type matrix \(H_m^{(n,j)}(y)=[\psi_2^{(n+(a+b)j)}(y)]_{a,b=0}^{m}\). This is the matrix corresponding to the determinant in Mishra--Swaminathan Proposition 4.1.
