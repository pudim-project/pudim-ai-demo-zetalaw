# Proposition: First-cycle entropy bound for threshold-aware Erdos defects

## Statement

Use the notation of [[wiki/nodes/mrw-f1348014e087|Threshold-aware CRT certificate for Erdos first-hit block uniformity]].  Let
\[
I=\{A+1,\ldots,B\},\qquad T=n_B,\qquad L=L_B,\qquad M=|D_I|=L\eta_I.
\]
Assume \(T\ge2\), and define
\[
\Phi(T,M)=
\begin{cases}
0,&M=0,\\[4pt]
\displaystyle\max_{1\le k\le M}
\frac{H_{T+k-1}-H_{T-1}}{\log(T+k-1)},&M\ge1,
\end{cases}
\]
where \(H_n=\sum_{1\le j\le n}1/j\).  Then the threshold-aware defect satisfies
\[
Q_I\le \Phi(T,M).
\]
In particular,
\[
Q_I\le
\min\left\{
\frac{M}{T\log T},
\frac{T^{-1}+\log(1+M/T)}{\log T}
\right\}.
\]

Consequently, if \(0=N_0<N_1<\cdots\), \(I_r=\{N_{r-1}+1,\ldots,N_r\}\), and
\[
P_{I_r}+\Phi(n_{N_r},L_{N_r}\eta_{I_r})
\le C\eta_{I_r}+\varepsilon_r,\qquad
\sum_r\varepsilon_r<\infty,
\]
then \(B\) has logarithmic density \(\delta=\lim_N\delta_N\).

The profile \(\Phi(T,M)\) is sharp for abstract first-active support data: among \(M\) distinct first active representatives all at least \(T\), the largest possible value of the normalized prefix sum is obtained by the packed representatives
\[
T,T+1,\ldots,T+M-1.
\]

## Proof

List the first active representatives \(\tau_I(d)\) in increasing order:
\[
\tau_1<\tau_2<\cdots<\tau_M.
\]
They are distinct integers and each is at least \(T\), so
\[
\tau_j\ge T+j-1
\]
for every \(1\le j\le M\).

Fix \(x\ge2\), and let
\[
k=\#\{j:\tau_j<x\}.
\]
If \(k=0\), the \(Q_I\) prefix at \(x\) is empty.  If \(k\ge1\), then
\[
\sum_{\tau_j<x}\frac1{\tau_j}
\le
\sum_{j=1}^k\frac1{T+j-1}
=H_{T+k-1}-H_{T-1}.
\]
Also \(x>\tau_k\ge T+k-1\), hence \(\log x\ge\log(T+k-1)\).  Therefore
\[
\frac1{\log x}\sum_{\tau_j<x}\frac1{\tau_j}
\le
\frac{H_{T+k-1}-H_{T-1}}{\log(T+k-1)}
\le \Phi(T,M).
\]
Taking the supremum over \(x\ge2\) proves \(Q_I\le\Phi(T,M)\).

The first displayed corollary follows from
\[
H_{T+k-1}-H_{T-1}
\le \frac{k}{T}\le \frac{M}{T}
\]
and from
\[
H_{T+k-1}-H_{T-1}
\le \frac1T+\int_T^{T+k}\frac{dt}{t}
\le \frac1T+\log(1+M/T),
\]
while \(\log(T+k-1)\ge\log T\).

For the density consequence, the stated hypothesis gives
\[
P_{I_r}+Q_{I_r}\le C\eta_{I_r}+\varepsilon_r.
\]
The threshold-aware CRT certificate [[wiki/nodes/mrw-f1348014e087|Threshold-aware CRT certificate for Erdos first-hit block uniformity]] then gives the block-uniform first-hit hypothesis, and [[wiki/nodes/mrw-e0778085804e|Block-uniform first-hit criterion for Erdos residue-class logarithmic density]] gives the logarithmic-density conclusion.

Finally, the sharpness assertion is the elementary rearrangement principle for \(M\) distinct integers bounded below by \(T\): for each fixed \(k\), the largest possible reciprocal prefix sum is obtained by the \(k\) smallest admissible integers \(T,\ldots,T+k-1\).  Thus no estimate depending only on \(T\) and \(M\) can improve \(\Phi(T,M)\); further improvement must use the residue structure of \(D_I\), not just the number of first active representatives.

## Notes

- This is a first-cycle entropy improvement over the crude activation-scale bound because the cost grows with the packed harmonic profile of \(M=L\eta_I\) first representatives rather than linearly as \(M/(T\log T)\).
- This proposition is still a sufficient certificate, not a complete solution of Erdos Problem #25.
- The sharpness clause is only for abstract first-active support data.  A full Erdos #25 proof still needs residue-overlap structure that prevents such packing, or a genuine residue-specific actual-mass obstruction.
