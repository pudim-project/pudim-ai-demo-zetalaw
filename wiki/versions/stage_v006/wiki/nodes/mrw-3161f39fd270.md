# Proposition: Odd-cycle endpoint pair shields give non-bipartite diffuse residuals

## Statement

Let \(h\ge2\) be an integer and set \(k=2h+1\).  Let
\[
B=V_0\sqcup V_1\sqcup\cdots\sqcup V_{k-1}
\]
be a finite disjoint endpoint decomposition with every \(V_i\ne\varnothing\),
indices taken modulo \(k\), and independent product weights \(0<q_b<1\).
Let \(G\) be the complete blow-up of the odd cycle \(C_k\): vertices in
\(V_i\) are adjacent exactly to vertices in \(V_{i-1}\cup V_{i+1}\), and
there are no edges inside any \(V_i\).

Then \(G\) is triangle-free.  Hence its two-point endpoint-pattern family
\[
\mathcal E(G)=\{\{u,v\}:uv\in E(G)\}
\]
is interval-shielded, and for every terminal core \(T\) disjoint from \(B\)
the supported endpoint-pair residual is exactly
\[
\mathcal R_G(L)=\Pi_G(B)\mathfrak M_T(L-2).
\]

Writing
\[
P_0(B)=\prod_{b\in B}(1-q_b),
\qquad
R_i=\sum_{v\in V_i}\frac{q_v}{1-q_v},
\]
the endpoint mass is
\[
\Pi_G(B)=P_0(B)\sum_{i=0}^{k-1}R_iR_{i+1}.
\]

In the balanced diffuse specialization, take \(m\to\infty\) through integers
with
\[
|V_i|=m,\qquad q_b=q=\frac{\alpha}{km}<1
\]
for a fixed \(\alpha>0\).  Then
\[
\Pi_G(B)=km^2q^2(1-q)^{km-2}
\longrightarrow
e^{-\alpha}\frac{\alpha^2}{k}.
\]
In particular, a balanced \(C_5\)-blow-up has limiting endpoint mass
\[
e^{-\alpha}\frac{\alpha^2}{5}.
\]

Since all \(V_i\) are nonempty, \(G\) contains an odd cycle.  Therefore
\(\mathcal E(G)\) is not representable as a single two-class one-from-each
subtower on the same endpoint coordinate set \(B\), without duplicating or
splitting endpoint vertices.  Its edge set does decompose as the disjoint union
of adjacent complete-bipartite blocks
\[
E(G)=\bigsqcup_{i=0}^{k-1}E(K_{V_i,V_{i+1}}),
\]
but this is only a block decomposition of the endpoint graph, not a single
global two-class tower reduction.  Any blockwise subtower interpretation must
keep the common exact-absence factor for all endpoint coordinates outside the
chosen adjacent pair.

## Proof

If a triangle existed in \(G\), its three vertices would have to lie in three
parts \(V_i,V_j,V_\ell\), because no part has internal edges.  Projecting those
parts to the quotient graph would give a triangle in \(C_k\).  But
\(k=2h+1\ge5\), so the cycle \(C_k\) has no triangle.  Thus \(G\) is
triangle-free.  By `mrw-1b04240e9886`, \(\mathcal E(G)\) is
interval-shielded and its supported terminal lift has exact residual
\[
\mathcal R_G(L)=\Pi_G(B)\mathfrak M_T(L-2).
\]

Let \(r_b=q_b/(1-q_b)\).  The mass formula in `mrw-1b04240e9886` gives
\[
\Pi_G(B)=P_0(B)\sum_{uv\in E(G)}r_ur_v.
\]
Every edge of \(G\) belongs to a unique adjacent block
\(K_{V_i,V_{i+1}}\).  Hence
\[
\sum_{uv\in E(G)}r_ur_v
=
\sum_{i=0}^{k-1}
\left(\sum_{u\in V_i}r_u\right)
\left(\sum_{v\in V_{i+1}}r_v\right)
=
\sum_{i=0}^{k-1}R_iR_{i+1},
\]
which proves the exact endpoint mass formula.

For the balanced specialization, \(P_0(B)=(1-q)^{km}\) and
\[
R_i=\frac{mq}{1-q}.
\]
Therefore
\[
\Pi_G(B)
=(1-q)^{km}k\left(\frac{mq}{1-q}\right)^2
=km^2q^2(1-q)^{km-2}.
\]
Since \(q=\alpha/(km)\),
\[
km^2q^2=\frac{\alpha^2}{k}
\qquad\text{and}\qquad
(1-q)^{km-2}\to e^{-\alpha}.
\]
Thus
\[
\Pi_G(B)\to e^{-\alpha}\frac{\alpha^2}{k},
\]
and the case \(k=5\) gives \(e^{-\alpha}\alpha^2/5\).

Finally choose \(v_i\in V_i\) for every \(i\).  The vertices
\[
v_0,v_1,\ldots,v_{k-1}
\]
span a copy of \(C_k\).  Since \(k\) is odd, \(G\) is non-bipartite.  A single
two-class one-from-each subtower on the same endpoint coordinate set has
endpoint support contained in \(X\times Y\) for some bipartition
\(B=X\sqcup Y\), so its endpoint graph is bipartite.  Hence this odd-cycle
shield is not a single subtower of the kind quarantined by
`mrw-50bca8113dbf`.

The displayed block decomposition is immediate from the definition of the
complete odd-cycle blow-up: the only edges are the complete adjacent blocks
between \(V_i\) and \(V_{i+1}\), and these blocks are edge-disjoint for
\(k\ge5\).  This decomposition does not supply a global two-class tower,
because the odd cycle prevents a consistent global bipartition of the endpoint
coordinates.

## Notes

- The balanced \(C_5\)-blow-up is a positive diffuse endpoint-pair shield with
  limiting endpoint mass \(e^{-\alpha}\alpha^2/5\), but it remains a shifted
  terminal residual \(\mathfrak M_T(L-2)\), not terminal evidence for Erdos 536.
- This proposition separates odd-cycle triangle-free shields from the complete
  bipartite obstruction quarantined in `mrw-50bca8113dbf`.  The obstruction is
  not a single one-from-each tower on the same endpoint coordinates.
- The edge set is still a finite adjacent-block mixture.  The next question is
  whether general non-bipartite triangle-free endpoint shields reduce to a
  controlled finite odd-cycle/block mixture, or whether they require a new
  endpoint-profile residual theorem.
- No \(M_{P_k}(\theta)\), \(U_k(\theta)\), or \(R_P(\theta)\) lift follows
  without a terminal-core residual estimate.
