# Corollary: Product lower shadows charge common high-window terminal mass

## Statement

Let \(T\) be finite and let \(\nu_T\) be a product probability law on \(2^T\)
with coordinate probabilities \(0<q_t<1\).  For real \(h\), define
\[
H_h(T)=\{R\subseteq T:|R|>h\},
\qquad
\tau_h=\nu_T(H_h(T)).
\]
For every \(\mathcal G\subseteq2^T\),
\[
\nu_T(\mathcal G\cap H_h(T))
\le
\nu_T(\downarrow\mathcal G)\,\tau_h,
\]
where
\[
\downarrow\mathcal G
=
\{C\subseteq T:C\subseteq R\text{ for some }R\in\mathcal G\}.
\]
Consequently, if \(\tau_h>0\), then
\[
\nu_T(\downarrow\mathcal G)
\ge
\frac{\nu_T(\mathcal G\cap H_h(T))}{\tau_h}.
\]

Now let
\[
\mathcal F
=
\bigcup_{e\in\mathcal E}\{e\cup R:R\in\mathcal R_e\}
\subseteq2^{B\sqcup T}
\]
be pair-link-free.  If \(e_1,e_2,e_3\in\mathcal E\) are pairwise distinct and
\[
e_3\in I_B(e_1,e_2),
\]
then, for every real \(h\) with \(\tau_h>0\),
\[
\nu_T(\mathcal R_{e_3})
\le
1-
\frac{
\nu_T((\mathcal R_{e_1}\cap\mathcal R_{e_2})\cap H_h(T))
}
{\tau_h}.
\]
In particular, if
\[
\nu_T((\mathcal R_{e_1}\cap\mathcal R_{e_2})\cap H_h(T))
\ge \alpha\,\tau_h
\]
for some \(0\le\alpha\le1\), then
\[
\nu_T(\mathcal R_{e_3})\le1-\alpha.
\]

## Proof

We first prove the product-measure correlation fact used in the charging
inequality.  If \(D\subseteq2^T\) is decreasing and
\(A\subseteq2^T\) is increasing, then
\[
\nu_T(D\cap A)\le\nu_T(D)\nu_T(A).
\]
We prove this by induction on \(|T|\).  The case \(|T|=0\) is immediate.
Write \(T=T'\sqcup\{t\}\), let \(q=q_t\), and for \(i=0,1\) define sections
\[
D_i=\{S\subseteq T':S\cup i\{t\}\in D\},
\qquad
A_i=\{S\subseteq T':S\cup i\{t\}\in A\}.
\]
Because \(D\) is decreasing, \(D_1\subseteq D_0\).  Because \(A\) is
increasing, \(A_0\subseteq A_1\).  Put
\[
d_i=\nu_{T'}(D_i),
\qquad
a_i=\nu_{T'}(A_i).
\]
By induction,
\[
\nu_{T'}(D_i\cap A_i)\le d_i a_i
\qquad(i=0,1).
\]
Therefore
\[
\nu_T(D\cap A)
\le
(1-q)d_0a_0+q d_1a_1.
\]
Also
\[
\nu_T(D)\nu_T(A)
=
((1-q)d_0+q d_1)((1-q)a_0+q a_1).
\]
The difference between the right side and
\((1-q)d_0a_0+q d_1a_1\) is
\[
q(1-q)(d_0-d_1)(a_1-a_0)\ge0,
\]
because \(d_0\ge d_1\) and \(a_1\ge a_0\).  This proves the correlation
inequality.

Now let
\[
D=\downarrow\mathcal G,
\qquad
A=H_h(T).
\]
The set \(D\) is decreasing and \(H_h(T)\) is increasing.  Also
\[
\mathcal G\cap H_h(T)\subseteq D\cap H_h(T).
\]
Thus
\[
\nu_T(\mathcal G\cap H_h(T))
\le
\nu_T(D\cap H_h(T))
\le
\nu_T(D)\nu_T(H_h(T))
=
\nu_T(\downarrow\mathcal G)\tau_h.
\]
If \(\tau_h>0\), division gives the displayed lower bound.  If
\(\tau_h=0\), the undivided inequality still holds and no divided assertion is
made.

For the endpoint-fiber consequence, set
\[
\mathcal G=\mathcal R_{e_1}\cap\mathcal R_{e_2}.
\]
By `mrw-82f19bf75c98`,
\[
\mathcal R_{e_3}\cap\downarrow\mathcal G=\varnothing.
\]
Hence
\[
\nu_T(\mathcal R_{e_3})
\le
1-\nu_T(\downarrow\mathcal G).
\]
Substituting the lower-shadow charging bound gives
\[
\nu_T(\mathcal R_{e_3})
\le
1-
\frac{
\nu_T((\mathcal R_{e_1}\cap\mathcal R_{e_2})\cap H_h(T))
}
{\tau_h},
\]
as claimed.  The \(\alpha\)-fraction form is the same inequality after the
displayed lower bound on the common high-window mass.

## Notes

- This is a local quantitative charging lemma, not terminal Erdos 536
  evidence.  Its force depends on proving nontrivial common high-window
  overlap for the first two endpoint fibers.
- No condition \(q_t\le1/2\) is used; the product-measure correlation proof
  works for all \(0<q_t<1\).
- If \(h<0\), then \(H_h(T)=2^T\) and \(\tau_h=1\).  If \(h\ge |T|\), then
  \(H_h(T)=\varnothing\) and \(\tau_h=0\), so only the undivided inequality is
  asserted.
