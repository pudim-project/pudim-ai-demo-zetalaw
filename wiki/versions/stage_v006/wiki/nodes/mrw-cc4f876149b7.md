# Proposition: Intersecting deletion-trace obstruction for lower-shadow union covers

## Statement

Let \(P\) be a finite set and let \(\mathcal F\subseteq2^P\).  Call \(\mathcal F\) lower-shadow union-cover-free if there are no \(A,B,C\in\mathcal F\) such that
\[
A,B\subsetneq C,\qquad A\ne B,\qquad A\cup B=C.
\]

For \(C\in\mathcal F\), define the deletion trace below \(C\) by
\[
\mathcal D_{\mathcal F}(C)
=
\{D\subseteq C:\ D\ne\varnothing,\ C\setminus D\in\mathcal F\}.
\]
Then \(\mathcal F\) is lower-shadow union-cover-free if and only if, for every \(C\in\mathcal F\), the family \(\mathcal D_{\mathcal F}(C)\) is pairwise intersecting:
\[
D\cap E\ne\varnothing
\qquad(D,E\in\mathcal D_{\mathcal F}(C)).
\]

Consequently, every fixed-rank deletion trace
\[
\mathcal D_{\mathcal F,d}(C)
=
\mathcal D_{\mathcal F}(C)\cap\binom Cd
\]
is intersecting.  In particular,
\[
\left|\{p\in C:\ C\setminus\{p\}\in\mathcal F\}\right|\le1
\]
for every \(C\in\mathcal F\).

## Proof

First assume that \(\mathcal F\) is lower-shadow union-cover-free.  Fix \(C\in\mathcal F\).  Suppose for contradiction that there are \(D,E\in\mathcal D_{\mathcal F}(C)\) with
\[
D\cap E=\varnothing.
\]
Put
\[
A=C\setminus D,\qquad B=C\setminus E.
\]
Since \(D\) and \(E\) are nonempty by definition of the deletion trace, both \(A\) and \(B\) are proper subsets of \(C\).  Also \(D\ne E\): if \(D=E\), then the nonempty set \(D\) would be disjoint from itself, impossible.  Hence \(A\ne B\).  Finally,
\[
A\cup B
=(C\setminus D)\cup(C\setminus E)
=C\setminus(D\cap E)
=C.
\]
Thus \(A,B,C\in\mathcal F\) form a forbidden lower-shadow union-cover triple, a contradiction.  Therefore every deletion trace is pairwise intersecting.

Conversely, assume that every deletion trace \(\mathcal D_{\mathcal F}(C)\) is pairwise intersecting.  If \(\mathcal F\) had a lower-shadow union-cover triple \(A,B,C\), define
\[
D=C\setminus A,\qquad E=C\setminus B.
\]
Because \(A,B\subsetneq C\), both \(D\) and \(E\) are nonempty.  Since \(A,B\in\mathcal F\), both \(D\) and \(E\) lie in \(\mathcal D_{\mathcal F}(C)\).  But
\[
D\cap E
=(C\setminus A)\cap(C\setminus B)
=C\setminus(A\cup B)
=\varnothing,
\]
contradicting the assumed pairwise intersection of the trace.  This proves the equivalence.

The fixed-rank assertion follows because any subfamily of a pairwise-intersecting family is pairwise intersecting.  For \(d=1\), two distinct singleton deletion sets are disjoint, so at most one singleton \(\{p\}\) can occur in \(\mathcal D_{\mathcal F}(C)\).  This is exactly the displayed one-deletion bound.

## Notes

- This proposition is purely local and set-theoretic; it does not use the biased measure \(\nu_P\).
- It strengthens the one-deletion consequence already recorded in [[wiki/nodes/mrw-3c39ca3d1973|Pair-link shadow criterion for biased squarefree residuals]] by controlling all deletion sizes at once.
- For a fixed rank \(d\le |C|/2\), classical Erdos-Ko-Rado theory suggests a sharp uniform bound on \(\mathcal D_{\mathcal F,d}(C)\), but no such external theorem is imported here as a local proof.
- The proposition does not prove [[wiki/nodes/mrw-d0402aea6f58|Biased lower-shadow union-cover problem for Erdos 536]].  The missing step is a weighted lower-shadow theorem showing that positive biased high-support mass forces a deletion trace with two disjoint members.
