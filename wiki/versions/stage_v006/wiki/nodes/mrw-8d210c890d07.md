# Lemma: CRT projection amplification identity for finite residue shadows

## Statement

Let \(M,n\ge1\), let \(S\subseteq \mathbb Z/M\mathbb Z\), and let \(\nu_S\) be the uniform probability measure on \(S\).  Fix a residue class \(a\pmod n\), and put \(g=(M,n)\).  In the asymptotic finite-shadow sense, the conditional mass of the future congruence \(m\equiv a\pmod n\) inside the shadow \(S\) is
\[
\nu_S(m\equiv a\pmod n)
=
\frac{g}{n}\,
\nu_S(s\equiv a\pmod g).
\]
Consequently any one-step CRT dispersion estimate must control the projection concentration of the current shadow modulo the relevant gcd \(g\), not only the ambient reciprocal mass \(1/n\).

## Proof

For a fixed class \(s\pmod M\), the simultaneous congruences
\[
m\equiv s\pmod M,
\qquad
m\equiv a\pmod n
\]
are solvable if and only if \(s\equiv a\pmod g\).  If they are solvable, the Chinese remainder theorem gives one residue class modulo
\[
\operatorname{lcm}(M,n)=\frac{Mn}{g}.
\]
Relative to the single class \(s\pmod M\), this occupies the fraction
\[
\frac{M}{\operatorname{lcm}(M,n)}=\frac{g}{n}.
\]
Averaging this conditional fraction over the uniformly chosen surviving class \(s\in S\) gives
\[
\nu_S(m\equiv a\pmod n)
=
\frac{g}{n}
\nu_S(\{s\in S:s\equiv a\pmod g\}),
\]
which is the claimed identity.
