# Note: Small-residue obstruction to unshifted CRT prefix-defect summability

## Statement

The unshifted CRT prefix-dispersion defect \(R_I\) from [[wiki/nodes/mrw-2945dff32e3e|CRT prefix-dispersion certificate for Erdos first-hit block uniformity]] is not automatically summable, even in sparse residue systems for which the older union-tail criterion already proves logarithmic density.

More precisely, there are strictly increasing moduli \(n_i\), residues \(a_i\pmod {n_i}\), and singleton blocks \(I_i=\{i\}\) such that
\[
\sum_i\frac1{n_i}<\infty,\qquad P_{I_i}=0,\qquad \sum_i\eta_{I_i}<\infty,
\]
but
\[
\sum_i R_{I_i}=\infty.
\]
In fact the construction can be made with
\[
R_{I_i}\ge \frac{1}{4i\log(4i+1)}
\]
while \(\eta_{I_i}\le 1/n_i\), so \(R_{I_i}/\eta_{I_i}\) can be forced arbitrarily large by taking \(n_i\) sufficiently large.

This is not a counterexample to Erdos Problem #25.  It is a route obstruction: the unshifted \(R_I\) may count a small residue representative that lies before the activation threshold \(m\ge n_i\), so \(R_I\)-summability is too strong as an automatic target.

## Proof

Construct the residue system recursively.  Keep
\[
\sum_i\frac1{n_i}<\frac18
\]
by choosing each new \(n_i\) sufficiently large.  Suppose \(a_j,n_j\) have been chosen for \(j<i\), and put \(M_i=4i\).  The previous exclusions forbid, inside \(\{1,\ldots,M_i\}\), the union of the residue classes
\[
m\equiv a_j\pmod {n_j}\qquad (j<i).
\]
The number of forbidden integers is at most
\[
\sum_{j<i}\left(\frac{M_i}{n_j}+1\right)
\le
M_i\sum_{j<i}\frac1{n_j}+i-1
<
\frac{M_i}{8}+i
<M_i.
\]
Thus there exists an integer \(a_i\le M_i=4i\) that is not congruent to any earlier \(a_j\pmod {n_j}\).  Choose \(n_i>a_i\), with \(n_i>n_{i-1}\), so large that the reciprocal sum remains \(<1/8\).

For the singleton block \(I_i=\{i\}\), the first-hit set \(H_i=B_{i-1}\setminus B_i\) is contained in \(\{m\ge n_i\}\), hence the threshold-prefix term satisfies
\[
P_{I_i}=0.
\]
Its finite-shadow decrement is at most the raw density of one residue class:
\[
\eta_{I_i}=h_i\le \frac1{n_i}.
\]
On the other hand, the residue \(a_i\) survives every previous exclusion by construction and satisfies the current congruence \(m\equiv a_i\pmod {n_i}\).  Therefore \(a_i\) belongs to the eventual CRT support \(D_{I_i}\) modulo \(L_i=\operatorname{lcm}(n_1,\ldots,n_i)\).

Taking \(y=a_i+1\) in the definition of \(R_{I_i}\) gives
\[
R_{I_i}
\ge
\frac{1}{\log(a_i+1)}\frac1{a_i}
\ge
\frac{1}{4i\log(4i+1)}.
\]
The series \(\sum_i1/(i\log i)\) diverges, so \(\sum_iR_{I_i}=\infty\).  Meanwhile
\[
\sum_i\eta_{I_i}\le \sum_i\frac1{n_i}<\infty.
\]
This proves the obstruction.

The construction does not refute the logarithmic-density problem, because \(\sum_i1/n_i<\infty\) places it inside the locally proved summable-reciprocal subcase of [[wiki/nodes/mrw-f92c897044c4|Union-tail criterion for Erdos residue-class logarithmic density]].
