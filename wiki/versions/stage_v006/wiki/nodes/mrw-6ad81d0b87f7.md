# Definition: Tail zeta partition function

## Statement

For \(s>1\) and \(n\in\mathbb N\), define
\[
Z_{s,n}:=\zeta_n(s):=\sum_{k=n}^{\infty}k^{-s}.
\]
The corresponding tail zeta law is
\[
\rho_{s,n}(k)=\frac{k^{-s}}{\zeta_n(s)},\qquad k\ge n.
\]
This is a conservative definition-level patch connecting the candidate to the existing zeta-law partition viewpoint.
