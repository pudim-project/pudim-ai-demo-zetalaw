# Proposition: Outside variance controls moving-junta comparable-pair visibility

## Statement

Let
\[
P_k=\{p_1,\ldots,p_k\},\qquad q_i=\frac1{p_i},
\]
and let \(\nu_k\) be the product law on \(2^{P_k}\) with
\[
\nu_k(p_i\in S)=q_i.
\]
Let \(J_k\subseteq P_k\) be arbitrary.  Put
\[
R_k=P_k\setminus J_k,\qquad
W_k(J_k)=\sum_{p_i\in R_k}q_i(1-q_i).
\]
Assume the product-measure antichain estimate
\[
\mu(\mathcal A)
\le
C\left(1+\sum_i r_i(1-r_i)\right)^{-1/2}
\tag{1}
\]
for every antichain \(\mathcal A\) under every Bernoulli product law whose
coordinate probabilities satisfy \(0<r_i\le1/2\), with an absolute constant
\(C\).  Let \(C_0=\max(C,1)\).

Suppose \(\mathcal F_k\subseteq2^{P_k}\) satisfies the moving-junta
comparable-pair visibility condition
\[
A,C\in\mathcal F_k,\qquad A\subsetneq C
\quad\Longrightarrow\quad
(C\setminus A)\cap J_k\ne\varnothing.
\tag{2}
\]
Then
\[
\nu_k(\mathcal F_k)
\le
C_0(1+W_k(J_k))^{-1/2}.
\tag{3}
\]
Consequently, if \(W_k(J_k)\to\infty\), then
\[
\nu_k(\mathcal F_k)\to0.
\]
If \(\nu_k(\mathcal F_k)\ge\eta>0\) along a subsequence, then along that
subsequence
\[
W_k(J_k)\le C_0^2\eta^{-2}-1.
\tag{4}
\]
The same conclusions hold after intersecting \(\mathcal F_k\) with any
high-support event \(H_{k,\theta}=\{S:|S|>\theta\sum_{i\le k}q_i\}\).

## Proof

Condition on the root trace \(S\cap J_k\).  For each \(U\subseteq J_k\), define
the outside fiber
\[
\mathcal A_{k,U}
=
\{T\subseteq R_k: U\cup T\in\mathcal F_k\}.
\]
This is an antichain in \(2^{R_k}\).  Indeed, if \(T_1,T_2\in\mathcal A_{k,U}\)
and \(T_1\subsetneq T_2\), then
\[
U\cup T_1\subsetneq U\cup T_2
\]
is a strict comparable pair in \(\mathcal F_k\).  Its difference is
\[
(U\cup T_2)\setminus(U\cup T_1)=T_2\setminus T_1\subseteq R_k,
\]
so the difference misses \(J_k\), contradicting (2).

Let \(\nu_{J_k}\) and \(\nu_{R_k}\) denote the corresponding marginal product
laws.  If \(R_k=\varnothing\), then
\[
\nu_{R_k}(\mathcal A_{k,U})
\le
1
\le
C_0(1+W_k(J_k))^{-1/2}.
\]
Otherwise, the coordinate probabilities on \(R_k\) still satisfy
\(0<q_i\le1/2\), and applying (1) to the outside antichain gives
\[
\nu_{R_k}(\mathcal A_{k,U})
\le
C(1+W_k(J_k))^{-1/2}
\le
C_0(1+W_k(J_k))^{-1/2}.
\]
Averaging over \(U\) with the actual root-trace distribution gives
\[
\begin{aligned}
\nu_k(\mathcal F_k)
&=
\sum_{U\subseteq J_k}
\nu_{J_k}(U)\nu_{R_k}(\mathcal A_{k,U})\\
&\le
C_0(1+W_k(J_k))^{-1/2}
\sum_{U\subseteq J_k}\nu_{J_k}(U)\\
&=
C_0(1+W_k(J_k))^{-1/2},
\end{aligned}
\]
which proves (3).  The decay statement follows immediately when
\(W_k(J_k)\to\infty\).  If \(\nu_k(\mathcal F_k)\ge\eta\), then (3) gives
\[
\eta\le C_0(1+W_k(J_k))^{-1/2},
\]
which rearranges to (4).  Intersecting with \(H_{k,\theta}\) only decreases the
measure and preserves the visibility implication.

## Used by

- Next #536 route: any positive-mass high-support family satisfying a rooted or
  junta comparable-pair visibility rule must have root sets \(J_k\) with bounded
  outside variance.  Thus moving roots do not survive merely by escaping every
  fixed finite \(J\); they must absorb all but \(O(1)\) of the reciprocal-prime
  Bernoulli variance, or the family must evade comparable-pair visibility
  altogether.

## Notes

- This proposition removes the \(2^{|J_k|}\) trace-count loss from
  [[mrw-9e0b4f1a5c33]] by conditioning on the root trace and applying the
  antichain estimate only in the outside coordinates.
- For fixed finite \(J\), the outside variance satisfies
  \[
  W_k(J)=V_k-O_J(1)\to\infty,
  \]
  so this proposition subsumes the fixed-junta vanishing conclusion.
- For \(J_k=P_k\), one has \(W_k(J_k)=0\), and the visibility condition is
  vacuous.  The bound becomes only \(\nu_k(\mathcal F_k)\le C_0\), so the result
  does not overclaim in the full-root case.
- This proposition does not prove \(U_k(\theta)\to0\).  Union-freeness gives
  pairwise-intersecting deletion traces below each top set, but it does not by
  itself produce a root set \(J_k\) for which all comparable-pair deletions hit
  \(J_k\) while \(W_k(J_k)\to\infty\).
- The same conditioning proof works verbatim for an arbitrary Bernoulli product
  law on a finite decomposition \(P=J\sqcup R\) whenever the outside coordinate
  probabilities satisfy \(0<r_i\le1/2\): every fixed \(J\)-trace fiber is an
  antichain in \(R\), so the mass is bounded by the antichain constant times
  \((1+\sum_{i\in R}r_i(1-r_i))^{-1/2}\).
