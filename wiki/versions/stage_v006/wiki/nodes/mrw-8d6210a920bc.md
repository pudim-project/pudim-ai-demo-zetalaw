# Proposition: Endpoint interval shadows obey interval-pileup alternatives

## Statement
Let \(B\) be finite and let \(\pi_B\) be a product probability law on \(2^B\)
with \(0<q_b<1\) for every \(b\in B\).  For \(a,c\subseteq B\), write
\[
I_B(a,c)=\{g\subseteq B:a\triangle c\subseteq g\subseteq a\cup c\}.
\]

Let \(\mathcal A,\mathcal C\subseteq2^B\) have positive endpoint masses
\[
\lambda=\pi_B(\mathcal A)>0,\qquad \mu=\pi_B(\mathcal C)>0.
\]
Define
\[
\mathsf I_B(\mathcal A,\mathcal C)
=
\bigcup_{a\in\mathcal A,\ c\in\mathcal C}I_B(a,c)
\]
and the normalized endpoint interval-pair density
\[
D_{\mathcal A,\mathcal C}(g)
=
\frac{1}{\lambda\mu}
\sum_{\substack{a\in\mathcal A,\ c\in\mathcal C\\ g\in I_B(a,c)}}
\frac{\pi_B(a)\pi_B(c)}{\pi_B(I_B(a,c))}.
\]
Then \(D_{\mathcal A,\mathcal C}\ge0\), its \(\pi_B\)-support is exactly
\(\mathsf I_B(\mathcal A,\mathcal C)\), and
\[
\sum_{g\subseteq B}\pi_B(g)D_{\mathcal A,\mathcal C}(g)=1.
\]
Consequently, if \(K\ge1\) and
\[
D_{\mathcal A,\mathcal C}(g)\le K
\quad\text{for every }g\subseteq B,
\]
then
\[
\pi_B(\mathsf I_B(\mathcal A,\mathcal C))\ge K^{-1}.
\]
Contrapositively, if \(\sigma>0\) and
\[
\pi_B(\mathsf I_B(\mathcal A,\mathcal C))<\sigma,
\]
then there is \(g\in\mathsf I_B(\mathcal A,\mathcal C)\) such that
\[
D_{\mathcal A,\mathcal C}(g)>\sigma^{-1}.
\]

For one endpoint family \(\mathcal A\), define the ordered distinct-pair mass
\[
Z_{\mathcal A}
=
\sum_{\substack{a,c\in\mathcal A\\a\ne c}}\pi_B(a)\pi_B(c)
=
\pi_B(\mathcal A)^2-\sum_{a\in\mathcal A}\pi_B(a)^2.
\]
If \(Z_{\mathcal A}>0\), define
\[
\mathsf J_B(\mathcal A)
=
\bigcup_{\substack{a,c\in\mathcal A\\a\ne c}}I_B(a,c)
\]
and
\[
D_{\mathcal A}^{\ne}(g)
=
\frac{1}{Z_{\mathcal A}}
\sum_{\substack{a,c\in\mathcal A,\ a\ne c\\ g\in I_B(a,c)}}
\frac{\pi_B(a)\pi_B(c)}{\pi_B(I_B(a,c))}.
\]
Then \(D_{\mathcal A}^{\ne}\) has exact \(\pi_B\)-support
\(\mathsf J_B(\mathcal A)\), integrates to one, and satisfies the same
bounded-pileup and pileup-witness alternatives:
if \(K\ge1\) and \(D_{\mathcal A}^{\ne}\le K\), then
\[
\pi_B(\mathsf J_B(\mathcal A))\ge K^{-1},
\]
while if \(\sigma>0\) and \(\pi_B(\mathsf J_B(\mathcal A))<\sigma\), then
some \(g\in\mathsf J_B(\mathcal A)\) has
\[
D_{\mathcal A}^{\ne}(g)>\sigma^{-1}.
\]
If \(Z_{\mathcal A}=0\), then no distinct endpoint-parent pair is present and
no repeated-parent shadow conclusion is asserted.

In the pair-link-free endpoint-fiber setting of `mrw-e64516fca3bd`, write
\[
\mathcal E_R=\{e:R\in\mathcal U_e\}.
\]
If \(R_1\ne R_2\), if
\[
\mathcal C_T\subseteq I_T(R_1,R_2)\setminus\{R_1,R_2\},
\]
if \(\pi_B(\mathcal E_{R_1}),\pi_B(\mathcal E_{R_2})>0\), and if
\[
D_{\mathcal E_{R_1},\mathcal E_{R_2}}(g)\le K
\quad\text{for all }g\subseteq B
\]
with \(K\ge1\), then
\[
\sum_{R_3\in\mathcal C_T}\nu_T(R_3)\pi_B(\mathcal E_{R_3})
\le
\left(1-K^{-1}\right)\nu_T(\mathcal C_T).
\]
If \(R\subseteq T\), if
\[
\mathcal D_T\subseteq\{R_0\subseteq T:R_0\subsetneq R\},
\]
if \(Z_{\mathcal E_R}>0\), and if
\[
D_{\mathcal E_R}^{\ne}(g)\le K
\quad\text{for all }g\subseteq B
\]
with \(K\ge1\), then
\[
\sum_{R_0\in\mathcal D_T}\nu_T(R_0)\pi_B(\mathcal E_{R_0})
\le
\left(1-K^{-1}\right)\nu_T(\mathcal D_T).
\]

## Proof
Because \(0<q_b<1\), every endpoint atom and every endpoint interval has
positive \(\pi_B\)-measure.  For the cross density,
\[
\sum_{g\subseteq B}\pi_B(g)D_{\mathcal A,\mathcal C}(g)
=
\frac1{\lambda\mu}
\sum_{a,c}
\frac{\pi_B(a)\pi_B(c)}{\pi_B(I_B(a,c))}
\sum_{g\in I_B(a,c)}\pi_B(g)
=1.
\]
The exact support statement follows because \(g\) lies in the union
\(\mathsf I_B(\mathcal A,\mathcal C)\) if and only if it receives at least one
strictly positive summand.  If \(D_{\mathcal A,\mathcal C}\le K\), then
\[
1
=
\sum_{g\in\mathsf I_B(\mathcal A,\mathcal C)}
\pi_B(g)D_{\mathcal A,\mathcal C}(g)
\le
K\pi_B(\mathsf I_B(\mathcal A,\mathcal C)),
\]
so \(\pi_B(\mathsf I_B(\mathcal A,\mathcal C))\ge K^{-1}\).  The small-shadow
pileup witness is the contrapositive.

The repeated-parent proof is the same argument after replacing the normalizing
mass \(\lambda\mu\) by the ordered distinct-pair mass \(Z_{\mathcal A}\).  The
ordered convention matches the ordered parent roles in the pair-link interval
condition; using unordered pairs would divide both numerator and denominator by
two and would give the same density.

For the child-loss corollaries, apply `mrw-e64516fca3bd` with
\[
\sigma=K^{-1}.
\]
In the cross-terminal case, bounded pileup gives
\[
\pi_B(\mathsf I_B(\mathcal E_{R_1},\mathcal E_{R_2}))\ge K^{-1},
\]
and `mrw-e64516fca3bd` gives the displayed mass loss over
\(\mathcal C_T\).  In the repeated-parent case, bounded distinct-pair pileup
gives
\[
\pi_B(\mathsf J_B(\mathcal E_R))\ge K^{-1},
\]
and the repeated-parent lower-shadow part of `mrw-e64516fca3bd` gives the
displayed mass loss over \(\mathcal D_T\).

## Notes
- This is a local routing proposition, not terminal Erdos 536 evidence.
- The density statement itself is standalone.  Its child-loss corollaries
  depend on `mrw-e64516fca3bd`, whose route lineage uses `mrw-e3fec03bf987`,
  `mrw-d83f21b84e5c`, `mrw-20ca89f696f2`, and `mrw-baa182012831`.
- `mrw-6f8a9d8c0ea7` is a sibling heavy-atom corollary: a single large pair of
  endpoint atoms gives one direct shadow lower bound, while this proposition
  gives a diffuse bounded-pileup alternative.
- Empty terminal child sets make the child-loss inequalities vacuous.
- If \(\pi_B(\mathcal E_{R_1})=0\), \(\pi_B(\mathcal E_{R_2})=0\), or
  \(Z_{\mathcal E_R}=0\), the corresponding normalized density is undefined
  and no conclusion is asserted.
- Oracle accepted the result after requiring \(K\ge1\), \(\sigma>0\), exact
  support wording, and explicit zero-multiplicity boundary notes.  Scout
  remained a scaffold response and was ingested raw-only.
