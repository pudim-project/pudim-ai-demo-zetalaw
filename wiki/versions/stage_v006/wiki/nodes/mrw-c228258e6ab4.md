# Proposition: Fair-thinning bound for lower-shadow deletion traces

## Statement

Let \(P\) be a finite set and let \(\mathcal F\subseteq 2^P\) be lower-shadow union-cover-free.  For \(C\in\mathcal F\), let \(A\) be a uniformly random subset of \(C\).  Then
\[
\Pr(A\in\mathcal F\mid C)\le \frac12+2^{-|C|}.
\]

Equivalently, if
\[
\mathcal D_{\mathcal F}(C)
=
\{D\subseteq C:\ D\ne\varnothing,\ C\setminus D\in\mathcal F\}
\]
is the deletion trace from [[wiki/nodes/mrw-cc4f876149b7|Intersecting deletion-trace obstruction for lower-shadow union covers]], then
\[
2^{-|C|}\,|\mathcal D_{\mathcal F}(C)|\le \frac12.
\]

Now let \(P\) be a finite set of primes and write \(\nu_P\) for the product law with \(\nu_P(p\in S)=1/p\).  Let \(\widetilde\nu_P\) be the product law with
\[
\widetilde\nu_P(p\in C)=\min(2/p,1).
\]
Sample \(C\sim\widetilde\nu_P\), then sample \(A\) from \(C\) by keeping every element of \(C\) independently with probability \(1/2\).  Then \(A\sim\nu_P\).  If \(\mathcal F\subseteq2^P\) is lower-shadow union-cover-free, then
\[
\Pr(A\in\mathcal F,\ C\in\mathcal F)
\le
\frac12\,\widetilde\nu_P(\mathcal F)
+
\mathbb E_{\widetilde\nu_P}\!\left[
1_{\mathcal F}(C)2^{-|C|}
\right].
\]
In particular, if \(\mathcal F\subseteq H_{P,\theta}=\{C:|C|>\theta S_P\}\) and \(\theta>0\), where \(S_P=\sum_{p\in P}1/p\), then
\[
\Pr(A\in\mathcal F,\ C\in\mathcal F)
\le
\left(\frac12+2^{-\theta S_P}\right)\widetilde\nu_P(\mathcal F).
\]

## Proof

Fix \(C\in\mathcal F\).  By [[wiki/nodes/mrw-cc4f876149b7|Intersecting deletion-trace obstruction for lower-shadow union covers]], the deletion trace \(\mathcal D_{\mathcal F}(C)\) is pairwise intersecting.  Pair the subsets of \(C\) into complementary pairs
\[
\{D,\ C\setminus D\}.
\]
No pair can contribute two members to \(\mathcal D_{\mathcal F}(C)\), because two complementary nonempty deletion sets would be disjoint and hence would contradict pairwise intersection.  Also \(\varnothing\notin\mathcal D_{\mathcal F}(C)\) by definition.  Therefore
\[
|\mathcal D_{\mathcal F}(C)|\le 2^{|C|-1}.
\]

For uniformly random \(A\subseteq C\), put \(D=C\setminus A\).  If \(D\ne\varnothing\), then \(A\in\mathcal F\) is exactly the event \(D\in\mathcal D_{\mathcal F}(C)\).  The remaining event \(D=\varnothing\) is \(A=C\), which has probability \(2^{-|C|}\) and is always in \(\mathcal F\) because \(C\in\mathcal F\).  Hence
\[
\Pr(A\in\mathcal F\mid C)
\le
2^{-|C|}|\mathcal D_{\mathcal F}(C)|+2^{-|C|}
\le
\frac12+2^{-|C|}.
\]

For the product-measure statement, first note that if \(p=2\), then \(\widetilde\nu_P(p\in C)=1\) and the fair thinning puts \(p\in A\) with probability \(1/2=1/p\).  If \(p>2\), then \(\widetilde\nu_P(p\in C)=2/p\), so after fair thinning \(p\in A\) with probability \((2/p)(1/2)=1/p\).  The coordinates are independent, so \(A\sim\nu_P\).

Conditioning on \(C\) and multiplying the first bound by \(1_{\mathcal F}(C)\) gives
\[
\Pr(A\in\mathcal F,\ C\in\mathcal F)
=
\mathbb E_{\widetilde\nu_P}
\left[
1_{\mathcal F}(C)\Pr(A\in\mathcal F\mid C)
\right]
\le
\frac12\,\widetilde\nu_P(\mathcal F)
+
\mathbb E_{\widetilde\nu_P}
\left[
1_{\mathcal F}(C)2^{-|C|}
\right].
\]
If \(\mathcal F\subseteq H_{P,\theta}\) and \(\theta>0\), then every \(C\in\mathcal F\) has \(|C|>\theta S_P\), so \(2^{-|C|}\le 2^{-\theta S_P}\).  This proves the final displayed estimate.

## Notes

- This proposition is a gate, not a solution of the biased lower-shadow union-cover problem.  It only says that any lower-shadow-free candidate has small downward fair-thinning overlap from each selected top set.
- The missing reverse inequality is now explicit: a proof of the full trace theorem would need to show that every positive-mass high-support family has enough fair-thinning self-overlap to exceed the right side above, after excluding the already-quarantined rank-only and finite-core-cylinder templates.
- The statement imports no external theorem.  The source note records biased intersecting-family context for future strengthening, especially product-measure EKR and junta/stability tools.
