# Corollary: Separator branches are lower-light or upper-costly

## Statement
Let \(T\) be finite with product law \(\nu_T\) and coordinate probabilities
\[
0<q_t<1.
\]
For \(Z\subseteq T\), set
\[
c(Z)=\nu_T(R\cap Z=\emptyset)=\prod_{z\in Z}(1-q_z),
\qquad
Q(Z)=\sum_{z\in Z}q_z.
\]
Let \(\mathcal A,\mathcal V\subseteq2^T\) satisfy the terminal separator
hypotheses from `mrw-58fd4a90babe`:
\[
A\cap Z\ne\emptyset\quad(A\in\mathcal A),
\qquad
V\cap Z=\emptyset\quad(V\in\mathcal V).
\]

Then for every real \(h\),
\[
\nu_T(\mathcal A\cap\{|R|>h\})
\le
\nu_T(R\cap Z\ne\emptyset)
=
1-c(Z)
\le
Q(Z),
\]
and
\[
\nu_T(\mathcal V\cap\{|R|>h\})
=
c(Z)\,
\nu_{T\setminus Z}(\mathcal V^{\setminus Z}\cap\{|W|>h\})
\le
c(Z)
\le
e^{-Q(Z)}.
\]

Consequently, for every \(\lambda>0\), every separator branch satisfies the
following dichotomy:

- if \(Q(Z)<\lambda\), then the lower fiber has absolute terminal mass
  \[
  \nu_T(\mathcal A\cap\{|R|>h\})<\lambda
  \]
  in every support window;
- if \(Q(Z)\ge\lambda\), then the upper smaller-core residual has coefficient
  \[
  c(Z)\le e^{-\lambda}.
  \]

Mass-forced form: if for some \(m>0\),
\[
\nu_T(\mathcal A\cap\{|R|>h\})\ge m,
\]
then
\[
Q(Z)\ge m,
\qquad
c(Z)\le e^{-m}.
\]
More generally, in a two-fiber endpoint assembly with endpoint weight
\(\pi_B(f)>0\), if
\[
\pi_B(f)\nu_T(\mathcal A\cap\{|R|>L-|f|\})\ge m,
\]
then
\[
Q(Z)\ge \frac{m}{\pi_B(f)}
\qquad\text{and}\qquad
c(Z)\le \exp\!\left(-\frac{m}{\pi_B(f)}\right).
\]

Thus a terminal separator branch is either lower-light or upper-costly.  If the
branch is lower-light, its mass must pass to the upper smaller-core residual
from `mrw-58fd4a90babe`; if it is not lower-light, the upper residual pays an
explicit absent-\(Z\) coefficient.

## Proof
The lower family is contained in the event that the random terminal set hits
\(Z\):
\[
\mathcal A\cap\{|R|>h\}
\subseteq
\{R:R\cap Z\ne\emptyset\}.
\]
Therefore
\[
\nu_T(\mathcal A\cap\{|R|>h\})
\le
\nu_T(R\cap Z\ne\emptyset)
=
1-\prod_{z\in Z}(1-q_z)
=
1-c(Z).
\]
By the union bound,
\[
1-c(Z)
=
\nu_T\!\left(\bigcup_{z\in Z}\{z\in R\}\right)
\le
\sum_{z\in Z}q_z
=
Q(Z).
\]

The upper factorization is exactly the product-law part of
`mrw-58fd4a90babe`: because every member of \(\mathcal V\) avoids \(Z\),
\[
\nu_T(\mathcal V\cap\{|R|>h\})
=
c(Z)\,
\nu_{T\setminus Z}(\mathcal V^{\setminus Z}\cap\{|W|>h\}).
\]
The induced-core probability is at most \(1\), giving the bound by \(c(Z)\).
Finally,
\[
c(Z)=\prod_{z\in Z}(1-q_z)\le\prod_{z\in Z}e^{-q_z}=e^{-Q(Z)}.
\]

The dichotomy follows immediately.  If \(Q(Z)<\lambda\), the lower estimate
gives
\[
\nu_T(\mathcal A\cap\{|R|>h\})<\lambda.
\]
If \(Q(Z)\ge\lambda\), the upper coefficient estimate gives
\[
c(Z)\le e^{-Q(Z)}\le e^{-\lambda}.
\]

For the mass-forced form, the lower estimate gives
\[
m\le\nu_T(\mathcal A\cap\{|R|>h\})\le Q(Z),
\]
so \(Q(Z)\ge m\), and therefore \(c(Z)\le e^{-m}\).  The endpoint-weighted
form is the same argument after dividing the antecedent by \(\pi_B(f)>0\):
\[
\nu_T(\mathcal A\cap\{|R|>L-|f|\})\ge \frac{m}{\pi_B(f)}.
\]
If \(m>\pi_B(f)\), the antecedent is impossible, so the implication is still
valid but vacuous.

## Depends on
- `mrw-58fd4a90babe`: terminal separators factor the upper fiber as a
  smaller-core residual with coefficient \(c(Z)\).
- `mrw-0cbd2c0086d7`: active branches require positive high-window mass before
  chargeable overlap or shield alternatives become useful.
- `mrw-108414b9dce7`: chargeable alternatives later turn common high-window
  overlap into third-fiber loss.

## Used by
- Future no-small-separator alternatives: separator branches with non-negligible
  lower mass force an explicit upper coefficient loss.
- Future residual classification: low-\(Q(Z)\) separators are lower-light and
  must pass mass to the upper smaller-core residual.

## Notes
- This is branch-quarantine bookkeeping, not terminal Erdos 536 evidence.
- No \(q_t\le1/2\) hypothesis is needed; \(0<q_t<1\) suffices.
- The estimates hold for every real \(h\).  If \(h<0\), the support cutoff is
  automatic; if \(h\ge |T|\), the high-window event is empty.
- If \(Z=\emptyset\), then \(Q(Z)=0\), \(c(Z)=1\), and the separator hypothesis
  forces \(\mathcal A=\emptyset\).  The lower bound reads \(0\le0\) and the
  upper factorization is the identity on \(T\).
- If \(\mathcal A=\emptyset\) or \(\mathcal V=\emptyset\), the corresponding
  estimates are vacuous and valid.
- Oracle accepted the corollary after replacing "equivalently" by the
  mass-forced wording and noting that endpoint-weighted applications are
  nonvacuous only when \(0<m\le\pi_B(f)\).  Scout returned only a scaffold
  response and was ingested raw-only.
