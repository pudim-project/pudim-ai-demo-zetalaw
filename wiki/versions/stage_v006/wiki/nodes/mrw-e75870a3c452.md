# Corollary: Zero shield gaps are empty-bottom comparable pairs

## Statement
Let \(B\) be finite with endpoint product law
\[
\pi_B(a)=\prod_{b\in a}q_b\prod_{b\notin a}(1-q_b),
\qquad 0<q_b<1.
\]
For distinct endpoint patterns \(e,f\subseteq B\), define
\[
I_B(e,f)=\{g\subseteq B:e\triangle f\subseteq g\subseteq e\cup f\},
\qquad
S(e,f)=I_B(e,f)\setminus\{e,f\}.
\]
Use the empty-product convention \(\prod_{b\in\emptyset}q_b=1\).

Then the following trichotomy holds.

1. If \(e\) and \(f\) are incomparable, then neither endpoint belongs to
   \(I_B(e,f)\), so
   \[
   S(e,f)=I_B(e,f),
   \qquad
   \pi_B(S(e,f))=\pi_B(I_B(e,f))>0.
   \]

2. If \(f\subsetneq e\), then
   \[
   I_B(e,f)=\{(e\setminus f)\cup u:u\subseteq f\},
   \]
   only the larger endpoint \(e\) lies in \(I_B(e,f)\), and
   \[
   \pi_B(S(e,f))
   =
   \pi_B(I_B(e,f))
   \left(1-\prod_{b\in f}q_b\right).
   \]
   Hence \(\pi_B(S(e,f))=0\) if and only if \(f=\emptyset\).  If additionally
   \(0<q_b\le1/2\) for every \(b\) and \(m=|f|\ge1\), then
   \[
   \pi_B(S(e,f))
   \ge
   (1-2^{-m})\pi_B(I_B(e,f)).
   \]

3. If \(e\subsetneq f\), symmetrically only \(f\) lies in \(I_B(e,f)\), and
   \[
   \pi_B(S(e,f))
   =
   \pi_B(I_B(e,f))
   \left(1-\prod_{b\in e}q_b\right).
   \]
   Thus \(\pi_B(S(e,f))=0\) if and only if \(e=\emptyset\), with the same
   \((1-2^{-m})\)-relative lower bound for \(m=|e|\ge1\) under \(q_b\le1/2\).

Consequently, the only distinct endpoint pairs with zero shield gap are the
empty-bottom comparable pairs
\[
(\emptyset,u)\quad\text{or}\quad(u,\emptyset),
\qquad u\ne\emptyset.
\]
Every incomparable pair and every comparable pair with nonempty smaller endpoint
has positive shield gap.  In the active branch after `mrw-4a33f7d04fc3`, a
distinct nonchargeable high-overlap locally shielded pair is therefore either an
empty-bottom comparable obstruction, or it has a positive shield gap governed by
the interval mass and the displayed bottom-product factor.

## Proof
First note the endpoint-membership criterion.  Since
\[
I_B(e,f)=\{g:e\triangle f\subseteq g\subseteq e\cup f\},
\]
one has
\[
e\in I_B(e,f)
\quad\Longleftrightarrow\quad
e\triangle f\subseteq e
\quad\Longleftrightarrow\quad
f\subseteq e.
\]
Similarly,
\[
f\in I_B(e,f)\quad\Longleftrightarrow\quad e\subseteq f.
\]
Thus if \(e\) and \(f\) are incomparable, neither endpoint lies in the interval.
The product formula from `mrw-4a33f7d04fc3` gives \(\pi_B(I_B(e,f))>0\), since
\(B\) is finite and all \(q_b\in(0,1)\).  Therefore \(S(e,f)=I_B(e,f)\) and
\(\pi_B(S(e,f))>0\).

Assume now that \(f\subsetneq e\).  Then
\[
e\triangle f=e\setminus f,
\qquad
e\cup f=e,
\]
so
\[
I_B(e,f)=\{g:e\setminus f\subseteq g\subseteq e\}
=\{(e\setminus f)\cup u:u\subseteq f\}.
\]
The coordinates in \(e\setminus f\) are forced present, the coordinates outside
\(e\) are forced absent, and the coordinates of \(f\) are free.  Hence
\[
\pi_B(I_B(e,f))
=
\prod_{b\in e\setminus f}q_b
\prod_{b\notin e}(1-q_b).
\]
Only the larger endpoint \(e\) lies in \(I_B(e,f)\).  Moreover
\[
\pi_B(e)
=
\prod_{b\in e}q_b
\prod_{b\notin e}(1-q_b)
=
\pi_B(I_B(e,f))\prod_{b\in f}q_b.
\]
Thus
\[
\pi_B(S(e,f))
=
\pi_B(I_B(e,f))-\pi_B(e)
=
\pi_B(I_B(e,f))
\left(1-\prod_{b\in f}q_b\right).
\]
Since \(\pi_B(I_B(e,f))>0\) and \(0<q_b<1\), the final factor vanishes exactly
when \(f=\emptyset\).  If \(q_b\le1/2\) and \(m=|f|\ge1\), then
\[
\prod_{b\in f}q_b\le2^{-m},
\]
which gives
\[
\pi_B(S(e,f))
\ge
(1-2^{-m})\pi_B(I_B(e,f)).
\]
The case \(e\subsetneq f\) is identical after interchanging \(e\) and \(f\).
