# Proposition: Fixed overfull endpoint patterns are terminal residuals

## Statement

Use the finite endpoint-tower notation
\[
P=P_0\supseteq P_1\supseteq\cdots\supseteq P_r,
\qquad
P_{j-1}=P_j\sqcup X_j\sqcup Y_j
\quad(1\le j\le r).
\]
Let
\[
\omega=((A_1,B_1),\ldots,(A_r,B_r)),
\qquad
A_j\subseteq X_j,\quad B_j\subseteq Y_j,
\]
be an endpoint occupancy pattern, and write
\[
E(\omega)=\bigcup_{j=1}^r(A_j\cup B_j).
\]
The phrase "pattern" is exact: in the endpoint coordinates, exactly the set
\(E(\omega)\) is selected and all endpoint coordinates outside \(E(\omega)\)
are absent.
For \(\mathcal R\subseteq2^{P_r}\), define the fixed-pattern assembly
\[
\mathcal A_\omega(\mathcal R)
=
\{R\cup E(\omega):R\in\mathcal R\}\subseteq2^P.
\]

Then \(\mathcal A_\omega(\mathcal R)\) is pair-link-free in \(2^P\) if and
only if \(\mathcal R\) is pair-link-free in \(2^{P_r}\).

Under the product law on \(2^P\), let \(\pi(\omega)\) be the endpoint-pattern
probability from [[mrw-05f82d03b190]].  For every real threshold \(L\),
\[
\nu_P(\mathcal A_\omega(\mathcal R)\cap\{S:|S|>L\})
=
\pi(\omega)\,
\nu_{P_r}(\mathcal R\cap\{R:|R|>L-|E(\omega)|\}).
\]
Consequently, the optimal high-support mass among fixed-pattern assemblies is
exactly
\[
\pi(\omega)\,\mathfrak M_{P_r}(L-|E(\omega)|).
\]

If \(\omega\) is overfull, meaning that some \(A_j\) or \(B_j\) has size at
least \(2\), then every member of \(\mathcal A_\omega(\mathcal R)\) lies in
the realized overfull endpoint event \(O_{\mathrm{ov}}\) of
[[mrw-c82229c73d8d]].  Thus positive realized overfull high-support mass can
be carried entirely by a fixed endpoint pattern and is, by itself, only a
shifted terminal-core residual.  It does not force the pointwise mixed
incidence hypothesis needed by [[mrw-7f0eb8d1648c]] unless additional
cross-pattern interaction, residual decay, or an independent mixed-support
witness is proved.

## Proof

The endpoint set \(E(\omega)\) is common to all members of
\(\mathcal A_\omega(\mathcal R)\) and is disjoint from \(P_r\).  If
\(\mathcal R\) is not pair-link-free, choose pairwise distinct
\(R_1,R_2,R_3\in\mathcal R\) with
\[
R_3\in I_{P_r}(R_1,R_2).
\]
Then \(S_i=R_i\cup E(\omega)\) are pairwise distinct members of
\(\mathcal A_\omega(\mathcal R)\).  Since the same endpoint set is adjoined to
all three,
\[
S_1\triangle S_2=R_1\triangle R_2,
\qquad
S_1\cup S_2=E(\omega)\cup R_1\cup R_2,
\]
so \(S_3\in I_P(S_1,S_2)\).  Hence
\(\mathcal A_\omega(\mathcal R)\) is not pair-link-free.

Conversely, suppose \(\mathcal R\) is pair-link-free and that
\[
S_i=R_i\cup E(\omega)\in\mathcal A_\omega(\mathcal R)
\qquad(i=1,2,3)
\]
are pairwise distinct with \(S_3\in I_P(S_1,S_2)\).  Pairwise distinctness of
the \(S_i\) is exactly pairwise distinctness of the \(R_i\), because the
endpoint part is fixed.  Again
\[
S_1\triangle S_2=R_1\triangle R_2,
\qquad
S_1\cup S_2=E(\omega)\cup R_1\cup R_2.
\]
Since \(R_3\subseteq P_r\) and \(E(\omega)\cap P_r=\varnothing\), the interval
condition for \(S_3\) reduces exactly to
\[
R_1\triangle R_2\subseteq R_3\subseteq R_1\cup R_2,
\]
that is, \(R_3\in I_{P_r}(R_1,R_2)\).  This contradicts pair-link-freeness of
\(\mathcal R\).  Therefore \(\mathcal A_\omega(\mathcal R)\) is
pair-link-free.

The product-measure identity is the fixed-pattern summand of
[[mrw-05f82d03b190]].  The endpoint event
\[
\{S\subseteq P:S\cap(P\setminus P_r)=E(\omega)\}
\]
has probability \(\pi(\omega)\), independently of the terminal \(P_r\)-section.
For \(S=R\cup E(\omega)\),
\[
|S|>L
\quad\Longleftrightarrow\quad
|R|>L-|E(\omega)|.
\]
This gives the displayed mass identity.  Taking the supremum over all
pair-link-free terminal fibers \(\mathcal R\subseteq2^{P_r}\) gives
\[
\pi(\omega)\,\mathfrak M_{P_r}(L-|E(\omega)|),
\]
and the supremum is attained up to the definition of \(\mathfrak M_{P_r}\) by
using an extremal terminal fiber.

Finally, if some \(A_j\) or \(B_j\) has size at least \(2\), then every
\(S=R\cup E(\omega)\) contains a same-class endpoint pair
\[
e\in \binom{A_j}{2}\quad\text{or}\quad e\in\binom{B_j}{2}.
\]
Thus \(S\in O_{\mathrm{ov}}\) for every member of the assembly.  The previous
paragraphs show that this fully realized overfull mass still decouples into a
fixed endpoint probability times a shifted terminal residual.  Therefore
realized overfull occupancy, without a cross-pattern or terminal-residual
argument, is not a pointwise mixed-incidence certificate.

## Notes

- This proposition is the realized-mass analogue of the ambient slack
  obstruction [[mrw-d65c4d544e56]].  Even actual overfull mass is not enough
  for the mixed-incidence route when it is confined to one fixed endpoint
  pattern.
- The proposition does not weaken [[mrw-c82229c73d8d]].  It explains why the
  strict-deletion residual branch is the correct accounting object for fixed
  overfull patterns.
- The next viable theorem must use interactions between different endpoint
  patterns, prove decay of the terminal residuals
  \(\mathfrak M_{P_r}(L-|E(\omega)|)\), or exhibit an independent
  same-component point-support overlap \(\Xi(K)>0\).  A single overfull pattern
  cannot supply that conclusion by itself.
- Focused Oracle passed the proposition and requested only the exact-pattern
  convention to be stated explicitly; this is now included in the statement.
