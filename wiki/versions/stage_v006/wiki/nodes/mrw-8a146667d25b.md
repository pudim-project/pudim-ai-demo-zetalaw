# Corollary: Endpoint exclusion for the n=2 polygamma beta window

## Statement

Let
\[
C_2(x)=\psi''(x)+x\psi^{(3)}(x),
\qquad
P_2(x)=\psi''(x)\psi''(1/x).
\]
If
\[
x^\beta C_2(x)-P_2(x)<0\qquad(x>0),
\]
then
\[
2<\beta\le3.
\]
Equivalently, the left endpoint \(\beta=2\) is not admissible in the \(n=2\) even-order polygamma beta-window problem.

## Proof

By [[wiki/nodes/mrw-0241ab931d33|Even-order envelope reduction for polygamma beta windows]], every admissible \(\beta\) for the \(n=2\) window satisfies
\[
2\le\beta\le3.
\]
It remains to rule out \(\beta=2\).

The endpoint asymptotics used in the even-order envelope reduction give, as \(x\to0^+\),
\[
C_2(x)=4x^{-3}(1+o(1)),
\qquad
P_2(x)=2x^{-1}(1+o(1)).
\]
Therefore
\[
\frac{x^2C_2(x)}{P_2(x)}\to2.
\]
For all sufficiently small positive \(x\), this ratio is greater than \(1\).  Hence
\[
x^2C_2(x)-P_2(x)>0
\]
for all sufficiently small positive \(x\), so \(\beta=2\) cannot be admissible.  Combining this exclusion with \(2\le\beta\le3\) proves the claim.
