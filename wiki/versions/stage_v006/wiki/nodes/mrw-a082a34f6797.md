# Proposition: Parity-consistent robust overlap components have coherent signature potentials

## Statement

Use the notation of [[mrw-750fb7a7e30c]].  Thus all lower corridors share one
ancestor-signature system \(V=\bigsqcup_\tau V_\tau\), each corridor \(i\)
has selected signature \(\tau_i\), oriented sides
\[
S_i^0=U_i,\qquad S_i^1=W_i,
\]
and a robust side-overlap edge \(e\) with endpoints \(i,j\) has endpoint side
labels
\[
s_e(i),s_e(j)\in\{0,1\}
\]
and tests
\[
S_i^{s_e(i)}\cap S_j^{s_e(j)}.
\]
Set
\[
p_e=s_e(i)+s_e(j)\pmod 2.
\]
Robustness forces
\[
\tau_j=\operatorname{comp}^{p_e}(\tau_i),
\]
where \(\operatorname{comp}\) is coordinatewise complement.

Let \(H\) be a finite loopless multigraph of robust side-overlap edges.  For
each connected component \(K\) of \(H\), choose a root \(r\in K\).  Then there
is a well-defined parity potential
\[
\epsilon_i\in\{0,1\}\qquad(i\in K)
\]
such that \(\epsilon_r=0\) and, for every edge \(e\) with endpoints \(i,j\)
in \(K\),
\[
\epsilon_i+\epsilon_j=p_e\pmod 2.
\tag{1}
\]
Consequently, if \(\rho=\tau_r\), then every selected corridor signature in
the component is forced by
\[
\tau_i=\operatorname{comp}^{\epsilon_i}(\rho).
\tag{2}
\]
The selected pure signature of the oriented side \(S_i^b\) is therefore
\[
\tau_i^b=\operatorname{comp}^{\epsilon_i+b}(\rho).
\tag{3}
\]
In particular, every robust edge \(e\) with endpoints \(i,j\) tests sides with
the same induced pure signature:
\[
\epsilon_i+s_e(i)=\epsilon_j+s_e(j)\pmod 2.
\tag{4}
\]
Thus each parity-consistent robust component is a two-class coherent
signature-potential assembly over the complementary pair
\(\rho,\bar\rho\).

In the complete case \(\lambda_i=1\) for all corridors in \(K\), every
positive-weight point of \(S_i^b\) lies in the class
\[
V_{\operatorname{comp}^{\epsilon_i+b}(\rho)}.
\tag{5}
\]
Hence a complete parity-consistent robust component is an actual two-class
coherent signature-potential assembly, not merely a near-pure one.

## Proof

By [[mrw-750fb7a7e30c]], every cycle in a fully robust side-overlap graph has
even total side parity.  Equivalently,
\[
\sum_{e\in C}p_e=0\pmod 2
\tag{6}
\]
for every cycle \(C\) of \(H\).

Fix a connected component \(K\) and a root \(r\).  For any vertex \(i\in K\),
choose a path \(P:r\leadsto i\) and define
\[
\epsilon_i=\sum_{e\in P}p_e\pmod 2.
\tag{7}
\]
This does not depend on the chosen path.  Indeed, two paths from \(r\) to
\(i\) form a closed walk, and after cancelling repeated backtracking edges the
remaining closed walk is a disjoint mod-2 sum of cycles.  Each cycle has parity
zero by (6), so the two path sums agree.  This proves that the parity potential
is well-defined.  Applying the definition to a path ending with an edge
\(e=ij\) gives (1).

Now propagate signatures from the root.  Along each robust edge \(e=ij\),
[[mrw-750fb7a7e30c]] gives
\[
\tau_j=\operatorname{comp}^{p_e}(\tau_i).
\tag{8}
\]
Induction along any path from \(r\) to \(i\), together with the path
independence of \(\epsilon_i\), gives (2).  Since by definition the selected
pure signature of \(S_i^0\) is \(\tau_i\) and the selected pure signature of
\(S_i^1\) is \(\bar\tau_i\), (2) immediately gives (3).

For an edge \(e\) with endpoints \(i,j\), equation (1) says
\[
\epsilon_j+s_e(j)=\epsilon_i+p_e+s_e(j)
=\epsilon_i+s_e(i)\pmod 2,
\]
because \(p_e=s_e(i)+s_e(j)\).  This proves (4), and therefore all robust
tested overlaps occur within one of the two induced signature classes
determined by \(\rho\) and \(\bar\rho\).

Finally assume \(\lambda_i=1\) for every corridor in \(K\).  The near-purity
conclusion used in [[mrw-750fb7a7e30c]] then has zero defect:
\[
w(S_i^b\cap V_{\tau_i^b})=w(S_i^b).
\]
Since weights are nonnegative, all positive-weight points of \(S_i^b\) lie in
\(V_{\tau_i^b}\).  Substituting (3) gives (5).

## Notes

- This is the explicit normal form for the parity-consistent alternative left
  by [[mrw-750fb7a7e30c]].  It does not create the needed global robust
  odd-parity cycle and does not prove \(M_{P_k}(\theta)\to0\),
  \(U_k(\theta)\to0\), or any \(R_P(\theta)\) lift.
- The next global step must either force an odd-parity robust component from
  positive high-support mass, or audit this two-class coherent signature-potential
  assembly against every full pair-link interval.
- Parallel edges are included: a pair of robust parallel edges with opposite
  parities would be an odd two-edge cycle, so parity consistency forbids it.
