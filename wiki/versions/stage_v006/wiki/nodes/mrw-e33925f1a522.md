# Proposition: Fixed-child obstruction splits into heavy outside cores or tiny top differences

## Statement
Let the hypotheses and notation of `mrw-7708298f0eb8` hold.  Thus
\(P=B\sqcup T\), \(\pi_B\) is a full-support product law on \(2^B\),
\(\nu_T\) is a probability law on \(2^T\), and
\[
\mathcal F
=
\bigcup_{e\in\mathcal E}\{e\cup R:R\in\mathcal U_e\}
\subseteq2^P
\]
is pair-link-free.  For each \(R\subseteq T\), set
\[
\mathcal E_R=\{e\in\mathcal E:R\in\mathcal U_e\}.
\]

Fix distinct \(R_1,R_2\subseteq T\), set
\[
\mathcal A=\mathcal E_{R_1},
\qquad
\mathcal C=\mathcal E_{R_2},
\qquad
\lambda=\pi_B(\mathcal A)>0,
\qquad
\mu=\pi_B(\mathcal C)>0,
\]
and let
\[
\mathcal T\subseteq I_T(R_1,R_2)\setminus\{R_1,R_2\}.
\]
Define
\[
M_{\mathcal T}
=
\sum_{R_3\in\mathcal T}\nu_T(R_3)\pi_B(\mathcal E_{R_3}).
\]

For every \(0<\alpha\le1\), either
\[
M_{\mathcal T}\le(1-\alpha)\nu_T(\mathcal T),
\]
or there is a fixed child \(g\in\mathsf I_B(\mathcal A,\mathcal C)\) such
that
\[
D_{\mathcal A,\mathcal C}(g)>\alpha^{-1},
\qquad
\mathfrak D_g:=\lambda\mu D_{\mathcal A,\mathcal C}(g)
>
\frac{\lambda\mu}{\alpha}.
\]

If the fixed-child alternative occurs, then the following split holds.  Put
\(U=B\setminus g\).  For \(h\subseteq U\), write
\[
\pi_U(h)=\prod_{u\in h}q_u\prod_{u\in U\setminus h}(1-q_u),
\qquad
Q_U(h)=\prod_{u\in h}q_u,
\]
and
\[
\mathcal A_h=\{x\subseteq g:h\cup x\in\mathcal A\},
\qquad
\mathcal C_h=\{y\subseteq g:h\cup y\in\mathcal C\},
\]
\[
a_h=\pi_g(\mathcal A_h),
\qquad
c_h=\pi_g(\mathcal C_h).
\]
Let
\[
W_g
=
\sum_{h\subseteq U}\pi_U(h)Q_U(h)a_hc_h.
\]
For \(0<\rho<\tau\le1\), define
\[
E_\rho(g)
=
\{h\subseteq U:a_hc_h>0,\ Q_U(h)\ge\rho\}.
\]
Then one of the following alternatives holds.

1. Heavy outside-core branch:
\[
\pi_U(E_\rho(g))\ge\tau-\rho.
\]

2. Tiny top-difference branch: there are \(h\subseteq U\),
\(x\in\mathcal A_h\), and \(y\in\mathcal C_h\) with
\[
x\cup y=g,
\qquad
\prod_{b\in x\triangle y}q_b
<
\frac{\tau}{\mathfrak D_g}
<
\frac{\alpha\tau}{\lambda\mu}.
\]
If, in addition, the ordinary common-core cover probability of
`mrw-4210f8220daf` satisfies \(C_g\le c\), with \(c>0\), the covering pair can
be chosen so that
\[
\prod_{b\in x\triangle y}q_b
<
\frac{c\tau}{\mathfrak D_g}
<
\frac{c\alpha\tau}{\lambda\mu}.
\]

In the prime-biased case \(q_u=1/u\), if the heavy outside-core branch holds
with \(\tau>\rho\), then there is an active common core \(h\in E_\rho(g)\)
with
\[
\prod_{u\in h}u\le\rho^{-1}.
\]

## Proof
Apply `mrw-7708298f0eb8` with the chosen \(0<\alpha\le1\).  If its large
endpoint-shadow loss alternative holds, then
\[
M_{\mathcal T}\le(1-\alpha)\nu_T(\mathcal T),
\]
and there is nothing more to prove.

Otherwise `mrw-7708298f0eb8` gives a fixed child
\(g\in\mathsf I_B(\mathcal A,\mathcal C)\) such that
\[
D_{\mathcal A,\mathcal C}(g)>\alpha^{-1},
\qquad
\mathfrak D_g>\lambda\mu/\alpha>0.
\]
The positivity rules out the \(W_g=0\) boundary in `mrw-4210f8220daf`.

By the fixed-child normal form from `mrw-ce7f13a668ed` and the notation of
`mrw-4210f8220daf`,
\[
W_g
=
\sum_{h\subseteq U}\omega_U(h)a_hc_h,
\qquad
\omega_U(h)=\prod_{u\in h}q_u^2\prod_{u\in U\setminus h}(1-q_u).
\]
Since
\[
\omega_U(h)=\pi_U(h)Q_U(h),
\]
we also have the displayed statement-formula
\[
W_g
=
\sum_{h\subseteq U}\pi_U(h)Q_U(h)a_hc_h.
\]

Fix \(0<\rho<\tau\le1\).  If \(W_g<\tau\), then
`mrw-4210f8220daf` gives an active common core \(h\) and traces
\(x\in\mathcal A_h\), \(y\in\mathcal C_h\) with
\[
x\cup y=g,
\qquad
\prod_{b\in x\triangle y}q_b<\frac{\tau}{\mathfrak D_g}.
\]
The strict comparison
\[
\frac{\tau}{\mathfrak D_g}<\frac{\alpha\tau}{\lambda\mu}
\]
follows from \(\mathfrak D_g>\lambda\mu/\alpha\).  The optional
\(C_g\le c\) conclusion is exactly the cover-probability refinement in
`mrw-4210f8220daf`.

It remains to treat \(W_g\ge\tau\).  On \(E_\rho(g)\), use
\[
Q_U(h)a_hc_h\le1.
\]
Off \(E_\rho(g)\), either \(a_hc_h=0\) or \(Q_U(h)<\rho\), so
\[
Q_U(h)a_hc_h\le\rho.
\]
Therefore
\[
W_g
\le
\sum_{h\in E_\rho(g)}\pi_U(h)
+
\rho\sum_{h\notin E_\rho(g)}\pi_U(h)
\le
\pi_U(E_\rho(g))+\rho.
\]
Since \(W_g\ge\tau\), this gives
\[
\pi_U(E_\rho(g))\ge\tau-\rho.
\]

If \(q_u=1/u\) and \(\tau>\rho\), then \(\pi_U(E_\rho(g))>0\), so
\(E_\rho(g)\) is nonempty.  Any \(h\in E_\rho(g)\) has
\[
Q_U(h)=\prod_{u\in h}\frac1u\ge\rho,
\]
equivalently
\[
\prod_{u\in h}u\le\rho^{-1}.
\]

## Notes
- This proposition is conditional on the non-child-loss fixed-child output of
  `mrw-7708298f0eb8`; Oracle required this phrasing, and the statement above
  includes it.
- If \(\mathcal T=\emptyset\) or \(\nu_T(\mathcal T)=0\), the child-loss
  inequality is vacuous but valid.
- If \(U=\emptyset\), then \(Q_U(\emptyset)=1\).  For \(0<\rho<1\), the heavy
  branch says the sole outside core is active with mass \(1\), unless the
  tiny-difference branch occurs.
- The cases \(g=B\) and \(g=\emptyset\) are algebraically covered in the
  distinct-terminal-parent branch.
- The repeated-parent \(\mathsf J_B\) branch and ordered-distinct denominators
  are not promoted here.
- This is not terminal Erdos 536 evidence.  It isolates the fixed-child
  obstruction as either denominator-bounded outside-core mass or a
  tiny top-difference certificate.
- Oracle returned `PASS_WITH_EDITS`; the requested edit was the conditional
  fixed-child phrasing incorporated above.
