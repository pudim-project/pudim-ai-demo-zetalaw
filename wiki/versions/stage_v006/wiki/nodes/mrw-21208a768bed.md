# Proposition: Empty-singleton-top endpoint families are pair-link-free boundary obstructions

## Statement

Let \(B\) be a finite endpoint set with \(|B|=n\ge3\).  For
\(A,C\subseteq B\), use the ordinary endpoint pair-link interval
\[
I_B(A,C)=\{D:A\triangle C\subseteq D\subseteq A\cup C\}.
\]
Define
\[
\mathcal S_B=\{\varnothing,B\}\cup\{\{b\}:b\in B\}.
\]
Then \(\mathcal S_B\) is ordinary endpoint pair-link-free: there are no
pairwise distinct \(A,C,D\in\mathcal S_B\) with
\[
D\in I_B(A,C).
\]

For product endpoint weights \(0<q_b<1\), set
\[
P_0(B)=\prod_{b\in B}(1-q_b).
\]
Then
\[
\nu_B(\mathcal S_B)
=
P_0(B)\left(1+\sum_{b\in B}\frac{q_b}{1-q_b}\right)
+\prod_{b\in B}q_b.
\]
In the homogeneous case \(q_b=q\), this becomes
\[
\nu_B(\mathcal S_B)
=(1-q)^n+nq(1-q)^{n-1}+q^n.
\]

Consequently, if
\[
\mathfrak P_B(a)
=
\sup\{\nu_B(\mathcal A):\mathcal A\subseteq2^B,\ 
\mathcal A\text{ ordinary endpoint pair-link-free},
\mathcal A\subseteq\{e:|e|>a\}\},
\]
then
\[
\mathfrak P_B(a)
\ge
P_0(B)\left(1+\sum_{b\in B}\frac{q_b}{1-q_b}\right)
+\prod_{b\in B}q_b
\qquad(a<0),
\]
and
\[
\mathfrak P_B(a)
\ge
P_0(B)\sum_{b\in B}\frac{q_b}{1-q_b}
+\prod_{b\in B}q_b
\qquad(0\le a<1).
\]

## Proof

It suffices to check unordered pairs of distinct members of
\(\mathcal S_B\), because \(I_B(A,C)=I_B(C,A)\).

If one endpoint is \(\varnothing\), then
\[
I_B(\varnothing,X)=\{X\}.
\]
Thus the only interval point is already one of the two endpoints, so it cannot
be a third pairwise distinct member.

If the endpoints are two distinct singletons \(\{b\}\) and \(\{c\}\), then
\[
I_B(\{b\},\{c\})=\{\{b,c\}\}.
\]
Since \(n\ge3\), the set \(\{b,c\}\) is neither \(\varnothing\), nor a
singleton, nor all of \(B\).  Hence \(\{b,c\}\notin\mathcal S_B\).

If the endpoints are \(\{b\}\) and \(B\), then
\[
I_B(\{b\},B)=\{D:B\setminus\{b\}\subseteq D\subseteq B\}
=\{B\setminus\{b\},B\}.
\]
The point \(B\) is one of the endpoints.  The point \(B\setminus\{b\}\) has
size \(n-1\ge2\) and is not \(B\), so it is not in \(\mathcal S_B\).  These
cases exhaust all unordered pairs of distinct members of \(\mathcal S_B\).
Therefore no forbidden pair-link triple exists.

For the measure formula, the members are distinct when \(n\ge3\), and
\[
\nu_B(\varnothing)=P_0(B),\qquad
\nu_B(\{b\})=P_0(B)\frac{q_b}{1-q_b},\qquad
\nu_B(B)=\prod_{b\in B}q_b.
\]
Summing \(\varnothing\), the singletons, and \(B\) gives the displayed
arbitrary-weight formula, and the homogeneous formula follows by setting
\(q_b=q\) for all \(b\).

The threshold lower bounds use the strict cutoff \(|e|>a\).  If \(a<0\), all
members of \(\mathcal S_B\) are eligible.  If \(0\le a<1\), the empty set is
excluded, while all singletons and the top set \(B\) remain eligible.

## Notes

- This generalizes `mrw-cdf34678a1e1` from \(n=3\) to every \(|B|\ge3\) and
  arbitrary endpoint product weights.
- The range \(n\ge3\) is the clean nondegenerate range.  For \(n=2\),
  \(I_B(\{b\},\{c\})=\{B\}\), so the two singletons and \(B\) already form a
  forbidden triple; also \(I_B(\{b\},B)=\{\{c\},B\}\).  For \(n=1\), \(B\) is
  itself the singleton, so the displayed family degenerates and the formula
  would double-count unless one treats it as a set.
- This is a boundary obstruction, not terminal evidence for positive
  \(\theta\) Erdos 536 decay.  Its threshold consequences are for \(a<0\) and
  \(0\le a<1\).  At positive proportional thresholds the empty and singleton
  levels disappear.
