# Lemma: Bernstein integer increments are finite Hausdorff moments

## Statement

If \(\Phi\) is a Bernstein function and \(\Delta_n=\Phi(n+1)-\Phi(n)\), then there are \(B\ge0\) and a finite positive measure \(M\) on \([0,1]\) such that \(\Delta_n=B+\int_{[0,1]}u^n\,dM(u)\) for every \(n\ge1\).
