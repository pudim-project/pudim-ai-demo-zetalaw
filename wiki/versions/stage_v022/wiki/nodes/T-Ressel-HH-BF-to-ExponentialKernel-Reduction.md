# Theorem: Ressel Hornich-Hlawka Bernstein problem reduces to exponential kernels

## Statement

Let Delta_f(x,y,z)=f(|x|)+f(|y|)+f(|z|)+f(|x+y+z|)-f(|x+y|)-f(|y+z|)-f(|z+x|) on a Hilbert space. If Delta_{1-exp(-s dot)}(x,y,z)>=0 for every s>0 and every triple x,y,z, then Delta_f(x,y,z)>=0 for every Bernstein function f:[0,infty)->[0,infty). Conversely, one counterexample for f_s(t)=1-exp(-s t) refutes the all-Bernstein source problem.
