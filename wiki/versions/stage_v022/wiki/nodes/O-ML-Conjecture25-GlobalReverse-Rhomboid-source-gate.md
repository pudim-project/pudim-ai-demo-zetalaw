# Open_Problem: Mittag-Leffler Conjecture 25 global reverse inequality source gate

## Statement

For the two-parameter Mittag-Leffler function \(E_{\alpha,\beta}\), verify and attack the remaining source-open Conjecture 25 gap: for every \(\alpha\in(1,2)\) and \(\beta\in[\alpha-1,\alpha]\), does the global reverse inequality \(|E_{\alpha,\beta}(z)|\ge E_{\alpha,\beta}(\Re z)\) hold for all \(z\in\mathbb C\)?
