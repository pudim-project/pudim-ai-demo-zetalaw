# Lemma: Finite Chebyshev-Leja prefixes are weak Leja on the interval

## Statement

The finite Chebyshev-Leja pivot controls the interval sup norm of the prefix polynomial up to a logarithmic factor.
\[
|omega_{l-1}(x_l)| >= ||omega_{l-1}||_infty/(C log n).
\]

## Dependencies

- Chebyshev root grid O(log n)-norming property
- finite Leja pivot maximality on X_n
