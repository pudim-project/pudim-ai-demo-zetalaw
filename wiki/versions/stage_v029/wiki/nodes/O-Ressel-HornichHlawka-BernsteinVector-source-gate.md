# Open_Problem: Ressel vector Hornich-Hlawka Bernstein-function source gate

## Statement

Verify the exact source wording and later-literature novelty for Ressel's question in The Hornich-Hlawka inequality and Bernstein functions: whether, for every Hilbert-space triple x,y,z and every Bernstein function f:[0,infty)->[0,infty), the vector Hornich-Hlawka inequality f(|x+y|)+f(|y+z|)+f(|z+x|) <= f(|x|)+f(|y|)+f(|z|)+f(|x+y+z|) holds. Determine whether proving the exponential-kernel reduction for f(t)=1-exp(-s t), or finding an exact Hilbert-space counterexample to that kernel inequality, answers the exact source problem.
