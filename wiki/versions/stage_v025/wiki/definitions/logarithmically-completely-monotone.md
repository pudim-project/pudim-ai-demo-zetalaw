# Logarithmically Completely Monotone Functions

A positive function \(f\) on \((0,\infty)\) is logarithmically completely monotone, abbreviated LCM, if
\[
(-1)^n(\log f)^{(n)}(x)\ge0
\]
for every \(n\ge1\) and every \(x>0\).

The bridge admitted in `FI-20260530T-elegance-028` uses the standard closure theorem that LCM functions are completely monotone. This is a class-level vocabulary patch for future Bernstein/Stieltjes separation arguments.
