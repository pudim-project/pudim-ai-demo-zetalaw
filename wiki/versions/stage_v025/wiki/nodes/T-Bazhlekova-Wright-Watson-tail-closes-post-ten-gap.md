# Theorem: Bazhlekova Wright Watson tail closes post ten positivity gap

## Statement

For the two seed functions \(\mathcal W_{3/4,11/10}\) and \(\mathcal W_{11/20,21/20}\), the already true compact block \(0\le x\le10\), together with an explicit Watson/Wright expansion and a rigorous remainder estimate on \(x\ge10\), proves \(\mathcal W_{\alpha,p}(x)>0\) for every \(x>0\).
