# Theorem: Erdos 536 diagnostic positive mass top code obstruction with locally unique moving star centers

## Statement

Explicit positive-mass code obstruction attempt with locally unique centers: construct, or rule out within explicit templates, a positive-mass occupied top code \(\mathcal T_k\subseteq H_{k,\theta}\) with nonsparse close central ranks and a locally unique center map \(q(C,r)\) such that each occupied top supports threshold-sharp lower stars, but the union push-forward from lower-star pairs has negligible intersection with \(\mathcal T_k\). If no such template works, record whether the failure is caused by top-code hitting, weighted center-map regularity, rank-thin collapse, or loss of positive \(\nu_k\)-mass.
