# Theorem: Chen Choi Gurland log F strictly completely monotone

## Statement

For \(F(x)=\Gamma(1/x)\Gamma(3/x)/\Gamma(2/x)^2\), the function \(x\mapsto\log F(x)\) is strictly completely monotone on \((0,\infty)\).
