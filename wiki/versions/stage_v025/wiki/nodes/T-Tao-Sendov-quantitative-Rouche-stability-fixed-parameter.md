# Theorem: Tao-Sendov quantitative Rouche stability fixed parameter

## Statement

For fixed tangent-cluster parameters and an admissible rho, an explicit epsilon_rho preserves the critical-point count in D(r,rho) under cluster perturbations.
\[
\varepsilon_\rho=\min\{(1-\rho)/2,\Lambda_\rho/[2d(d-1)(2+r+\rho)^{d-2}]\}.
\]
