# Theorem: Baskakov alpha one r eight rational function is not completely monotone

## Statement

The Baskakov \(\alpha=1\), \(r=8\) function \(f^{[8]}_1(x)=1/((1+x)^8-x^8)\) is not completely monotone on \((0,\infty)\).
