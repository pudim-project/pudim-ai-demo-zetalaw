# Obstruction_Lemma: Principal-only single-primepower von Mangoldt row normalization forces class number one

## Statement

The naive principal-only single-primepower von Mangoldt row sum equals log N a for every nonunit principal integral ideal if and only if the number field has class number one.
\[
R(a)=sum_{q|a, q=p^j, a/q principal} Lambda_K(q)=log Na for all nonunit principal a iff h_K=1.
\]

## Scope

- K is a number field
- state space is nonzero principal integral ideals
- moves divide by exactly one ideal prime-power
- weights are Lambda_K(p^j)=log Np
- normalization is Tao's unmodified log Na row sum

- Do not claim all principal-only chains are impossible.
- Do not claim the full non-UFD Tao analogue is solved.
- Do not claim this rules out class-group-augmented or principal-block chains.
