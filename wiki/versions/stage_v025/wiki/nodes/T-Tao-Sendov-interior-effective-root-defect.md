# Theorem: Tao-Sendov interior effective root defect

## Statement

In the interior regime q in (r,1), the root-gap defect 1-s is bounded below by Delta/(1+|C|) minus an explicit O(1/d) term; if Delta is larger than the error, then 1-s >= Delta/4.
\[
1-s\ge\Delta(r,q)/(1+|C|)-10/(dc_0)\ge\Delta(r,q)/2-10/(dc_0).
\]
