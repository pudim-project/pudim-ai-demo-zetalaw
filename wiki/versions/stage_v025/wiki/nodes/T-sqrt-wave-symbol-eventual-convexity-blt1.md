# Theorem: sqrt(c s^2+d s^b) eventually convex for c,d>0 and 0<b<1

## Statement

For every \(c,d>0\) and \(0<b<1\), the function \(h(s)=\sqrt{c s^2+d s^b}\) satisfies \(h''(s)>0\) for all sufficiently large \(s\).
