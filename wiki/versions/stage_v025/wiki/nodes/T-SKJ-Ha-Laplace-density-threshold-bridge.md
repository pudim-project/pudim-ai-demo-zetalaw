# Theorem: explicit positive measure Laplace representation for H_a exactly on CM parameter set

## Statement

There is an explicit positive-measure Laplace representation \(H_a(x)=\int_0^\infty e^{-xt}\,d\mu_a(t)\) exactly for the complete-monotonicity parameter set of the SKJ/Alzer--Berg problem, with loss of positivity at the conjectured threshold.
