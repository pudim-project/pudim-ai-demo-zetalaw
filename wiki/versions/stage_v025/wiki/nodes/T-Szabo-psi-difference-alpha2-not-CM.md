# Theorem: Szabo psi difference endpoint alpha=2 is not completely monotone for all 0<d<1

## Statement

For every \(0<d<1\), the function \(y\mapsto y^2\left[\psi(y+d)-\psi(y)-d/y\right]\) is not completely monotone on \((0,\infty)\).
