# Theorem: Erdos 536 disjoint defects in occupied top support shadow are equivalent to lower shadow fork

## Statement

For any finite family \(\mathcal F\) and any \(C\in\mathcal F\), the support defect shadow \(\mathsf D_{\mathcal F}(C)=\{C\setminus A:A\in\mathcal F,\ A\subsetneq C\}\) contains two disjoint nonempty defects if and only if there are distinct \(A,B,C\in\mathcal F\) with \(A\subsetneq C\), \(B\subsetneq C\), and \(A\cup B=C\).
