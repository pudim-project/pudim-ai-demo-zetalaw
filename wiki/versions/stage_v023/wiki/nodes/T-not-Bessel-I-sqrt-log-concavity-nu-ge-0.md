# Theorem: exists nu >= 0 and u > 0 such that second derivative of log(sqrt(u) I_nu(u)) is nonnegative

## Statement

not(For every \(\nu\ge0\), the function \(u\mapsto \sqrt{u}\,I_\nu(u)\) is strictly log-concave on \((0,\infty)\).)
