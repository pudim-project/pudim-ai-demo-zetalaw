# Theorem: Yang Tian Bessel W conjecture boundary slice nu=-1/2 is Bernstein for tau <= 1/2

## Statement

For every \(\tau\in(0,1/2]\), the function \(x\mapsto W_{-1/2}(x^\tau)=x^\tau\coth(x^\tau)\) is a Bernstein function on \((0,\infty)\).
