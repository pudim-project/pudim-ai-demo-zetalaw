# Lemma: Tao-Sendov global C separation

## Statement

In the literal tangent-cluster parameter range, the limiting coefficient C(r,q)=qb+(1-q)a is uniformly separated from zero: |C(r,q)|>=2^{-1/2}.
\[
|C(r,q)|\ge2^{-1/2}.
\]
