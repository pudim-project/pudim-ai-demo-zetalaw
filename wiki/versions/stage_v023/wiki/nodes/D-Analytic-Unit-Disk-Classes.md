# Definition: Analytic unit-disk normalization classes

## Statement

Let \(\mathbb D=\{z\in\mathbb C:|z|<1\}\). The normalized analytic class \(\mathcal A\) consists of analytic functions \(f\) on \(\mathbb D\) with \(f(z)=z+\sum_{n\ge2}a_nz^n\), hence \(f(0)=0\) and \(f'(0)=1\).
