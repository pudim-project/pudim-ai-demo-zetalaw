# Theorem: Erdos 536 same endpoint terminal fork lifts to global lower shadow fork

## Statement

In an endpoint-tower branch, any same-endpoint terminal fork lifts to a global lower-shadow fork: if a fixed endpoint pattern \(e\) and terminal sets \(R_1,R_2,R_3\) satisfy \(R_1\ne R_2\), \(R_1,R_2\subsetneq R_3\), and \(R_1\cup R_2=R_3\), then \(e\cup R_1\), \(e\cup R_2\), and \(e\cup R_3\) are three distinct global family members with \((e\cup R_1)\cup(e\cup R_2)=e\cup R_3\).
