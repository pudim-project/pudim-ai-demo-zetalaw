# Theorem: Simon gamma quotient alpha half diagnostic slice is Bernstein

## Statement

The diagnostic slice \(F_{1/2}(x)=\Gamma(x+1/2)/(\Gamma(x)\sqrt{x})\) is a Bernstein function on \((0,\infty)\).
