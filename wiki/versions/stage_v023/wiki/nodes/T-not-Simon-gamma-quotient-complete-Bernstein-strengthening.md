# Theorem: Simon gamma quotient is not CBF for alpha in (0,1)

## Statement

not(For every \(0<\alpha<1\), \(F_\alpha(x)=\Gamma(x+\alpha)/(\Gamma(x)x^\alpha)\) is a complete Bernstein function on \((0,\infty)\)).
