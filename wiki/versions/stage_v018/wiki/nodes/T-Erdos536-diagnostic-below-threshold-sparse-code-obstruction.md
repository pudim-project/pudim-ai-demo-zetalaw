# Theorem: Erdos 536 diagnostic below threshold sparse code obstruction to EKR globalization

## Statement

Diagnostic construction problem: attempt to construct a positive-mass fork-free moving-center sequence \(\mathcal F_k\subseteq H_{k,\theta}\) with nonsparse close-rank support such that every occupied top has all close-rank lower traces below the local EKR threshold \(\binom{s-1}{r}\), the resulting defect-complement EKR-star centers do not synchronize into \(o(\sqrt{S_k})\) center/rank blocks, and candidate unions of lower traces almost never land in occupied tops. If no such construction works, record whether below-threshold sparsity forces vanishing mass, trace-density amplification, or EKR-star center synchronization.
