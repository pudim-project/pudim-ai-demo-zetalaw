# Theorem: Erdos 536 diagnostic below EKR sparse top code predecessor star construction

## Statement

Diagnostic below-EKR sparse top-code construction route: attempt to construct a positive-mass coherent fork-free predecessor-star family with occupied tops in a central linear window, nonlacunary central rank support, local predecessor traces at or below the EKR threshold, and diffuse unsynchronized centers, such that no local trace exceeds \(\binom{s-1}{r}\), no \(o(\sqrt{S_k})\) rank/center capture holds, and lower-trace unions avoid occupied tops. If no construction works, record whether failure is caused by super-EKR amplification, EKR-star center synchronization, rank-block anti-concentration, or occupied-union coverage.
