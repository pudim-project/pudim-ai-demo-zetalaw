# Theorem: Erdos536 bounded defect mean core concentration descent

## Statement

Bounded-defect/mean core-concentration descent theorem: in a lower-trace-rich admissible model whose intersecting defect laws have either a defect of size at most \(m\) or expected defect size at most \(M\) on a positive-mass set of tops, use the true small-defect and bounded-mean lemmas to extract coordinate marginals bounded below. Then either these coordinates form a fixed core, moving core, or endpoint shield with explicit persistence thresholds and strict lexicographic decrease of \(\mathcal C=(\ell_{\mathrm{end}},w_{\mathrm{core}},m_{\mathrm{avail}},r_{\mathrm{width}})\), or the branch produces an explicit obstruction to persistence.
