# Theorem: Erdos536 coordinate energy core shield persistence descent

## Statement

Coordinate-energy to core/shield persistence descent: after atom-heavy cases are separated, if the coordinate energy \(\sum_i q_{C,i}^2\) remains large on a positive-mass set of tops, extract persistent coordinates or endpoint blocks with explicit thresholds. The extraction must either produce a fixed common core, a moving core, or an endpoint shield, and then prove a strict lexicographic decrease of the well-founded complexity \(\mathcal C=(\ell_{\mathrm{end}},w_{\mathrm{core}},m_{\mathrm{avail}},r_{\mathrm{width}})\), or else construct an actual sparse-matching lower-trace obstruction.
