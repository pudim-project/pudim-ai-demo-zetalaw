# Definition: Finite-order total nonnegativity for kernels

## Statement

A kernel \(K\) on an ordered set is \(TN_p\) if, for every \(r\le p\) and every increasing row tuple \(x_1<\cdots<x_r\) and increasing column tuple \(y_1<\cdots<y_r\), the determinant \(\det(K(x_i,y_j))_{i,j=1}^r\) is nonnegative.
