# Theorem: Erdos536 L2 large core shield descent or sparse matching

## Statement

L2-large core/shield descent or sparse-matching theorem: after atom/spread control, if coordinate square-sum remains large on a positive-mass set of occupied tops, extract either fixed common-core concentration, moving-core or endpoint-shield concentration with a strictly decreasing lexicographic complexity, or an actual sparse-matching lower-trace construction. The output must include explicit coordinates/blocks or explicit family members \(A=C\setminus D\); it may not invoke approximate deletion to an intersecting support.
