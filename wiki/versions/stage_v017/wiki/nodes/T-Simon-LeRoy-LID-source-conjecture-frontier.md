# Theorem: Simon Le Roy Mittag-Leffler LID source conjecture frontier

## Statement

In Simon's Le Roy-type Mittag-Leffler problem, the remaining complete-monotonicity frontier is equivalent to whether the positive random variable associated by \({\bf E}[e^{zX}]=(\Gamma(\beta))^\gamma F^{(\gamma)}_{\alpha,\beta}(z)\) must be logarithmically infinitely divisible.
