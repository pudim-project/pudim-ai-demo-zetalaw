# Theorem: forall nu >= 0, u > 0, 1+(nu^2-1/2)/u^2-r/u-r^2 < 0 for r=I_nu'/I_nu

## Statement

Let \(r_\nu(u)=I_\nu'(u)/I_\nu(u)\). For every \(\nu\ge0\) and \(u>0\), \(1+(\nu^2-1/2)/u^2-r_\nu(u)/u-r_\nu(u)^2<0\).
