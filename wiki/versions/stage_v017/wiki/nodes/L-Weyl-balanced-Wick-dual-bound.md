# Lemma: Wick dual bound for balanced Weyl words

## Statement

For the normal-order functional Phi_{-1/2}, every balanced Weyl word with n X's and n D's has absolute value at most n!/2^n.
\[
|Phi_{-1/2}(w)| <= n!/2^n for w in W_n.
\]
