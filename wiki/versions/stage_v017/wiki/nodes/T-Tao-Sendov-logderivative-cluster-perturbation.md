# Theorem: Tao-Sendov logarithmic-derivative cluster perturbation bound

## Statement

For cluster perturbations of size e, the normalized logarithmic derivative differs from the exact model by an explicit reciprocal-sum bound linear in m and N.
\[
|F-F_0|\le \rho e[m/((1+r-\rho)(1+r-\rho-e))+N/((1-\rho)(1-\rho-e))].
\]
