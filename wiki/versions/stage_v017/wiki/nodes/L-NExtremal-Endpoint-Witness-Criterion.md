# Lemma: Endpoint witness criterion for special N-extremal A/B nonemptiness

## Statement

Let \(w(x)=1+x^2\). Then \(A\ne\varnothing\) if and only if there exists \(\nu\in\mathcal M_{i,0}^*\) such that \(w^{-\delta}\nu\in\mathcal M_d^*\) for every \(\delta>0\). Also, \(B\ne\varnothing\) if and only if there exists \(\nu\in\mathcal M_d^*\) such that \(w^\delta\nu\in\mathcal M_i^*\) for every \(\delta>0\).
