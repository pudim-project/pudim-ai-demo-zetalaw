# Theorem: GGPS Mittag-Leffler boundary h strict global convexity

## Statement

For the boundary function \(h:(0,\infty)\to(0,\infty)\) defined by \(2\Gamma(x+h(x))^2=\Gamma(h(x))\Gamma(2x+h(x))\), prove that \(h\) is strictly convex on all of \((0,\infty)\).
