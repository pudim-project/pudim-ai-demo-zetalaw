# Theorem: Erdos 536 global close rank trace density amplifies above local EKR threshold at an occupied top

## Statement

Trace-density amplification theorem: for a coherent intersecting-shadow moving-center system \(\mathcal F_k\subseteq H_{k,\theta}\) with positive \(\nu_k\)-mass and nonsparse close-rank lower-trace density, the density must amplify above the EKR threshold under some occupied top. More explicitly, there is a central close-rank pair \(r<s\le2r\) and an occupied top \(C\in\mathcal F_k\), \(|C|=s\), whose lower \(r\)-trace \(\mathcal A_r(C)=\{A\in\mathcal F_k:A\subsetneq C, |A|=r\}\) satisfies \(|\mathcal A_r(C)|>\binom{s-1}{r}\). Consequently `T-Erdos536-top-local-EKR-trace-threshold-forces-fork` gives distinct \(A,B,C\in\mathcal F_k\) with \(A\cup B=C\).
