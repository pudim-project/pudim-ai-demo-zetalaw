# Theorem: Gomilko Tomilov BF fractional power closure open problem

## Statement

Gomilko--Tomilov ask whether, for every \(0<\alpha<1\), every Bernstein function \(\psi\) has the fractional-power transform \(\psi_\alpha(x)=[\psi(x^\alpha)]^{1/\alpha}\) again Bernstein.
