# Theorem: Erdos 536 fork free coherent intersecting defect shadows collapse to o sqrt S rank profile

## Statement

For every fixed \(0<\theta<1\), every fork-free family \(\mathcal F_k\subseteq H_{k,\theta}\) whose occupied-top defect shadows \(\mathsf D_{\mathcal F_k}(C)\) are all intersecting has a collapsed rank profile: there are rank sets \(R_k\subseteq\{0,1,\ldots,k\}\) with \(|R_k|=o(\sqrt{S_k})\) such that \(\nu_k(\{A\in\mathcal F_k: |A|\notin R_k\})\to0\). Consequently \(\nu_k(\mathcal F_k)\to0\).
