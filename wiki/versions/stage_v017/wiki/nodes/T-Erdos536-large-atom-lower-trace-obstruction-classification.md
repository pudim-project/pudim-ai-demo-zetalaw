# Theorem: Erdos536 large atom lower trace obstruction classification

## Statement

Large-atom lower-trace obstruction classification: in a lower-trace-rich admissible model with large defect atom mass \(\alpha_C=\sum_D\lambda_C(D)^2\) on a positive-mass set of occupied tops, classify the obstruction into exactly one of three templates: a dominant atom lower trace, a finite atom cluster of bounded support, or a moving atom template. Each output must be expressed in actual lower traces \(A=C\setminus D\), and must either produce a rank/comparable-pair obstruction, enter the true \(L^2\)-small branch after removing no mass, or be recorded as a new explicit obstruction. No deletion to intersecting support is allowed.
