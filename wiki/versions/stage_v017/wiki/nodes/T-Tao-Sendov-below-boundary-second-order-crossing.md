# Theorem: T-Tao-Sendov-below-boundary-second-order-crossing

## Statement

For fixed compact 0<r0<=r<=1-rho<1 and bounded mu, in the tangent-cluster below-boundary chart q=r-mu/d the large root satisfies 1-|y_L| = kappa_r Delta/d + Theta(r,mu)/d^2 + O(d^-3), where Delta=r^2(3-r^2)-mu and Theta is explicit. On Delta=0, Theta<0, so the large root is outside the unit disk at second order.

## Scope

- Local tangent-cluster second-order asymptotic; not a global Sendov theorem.
