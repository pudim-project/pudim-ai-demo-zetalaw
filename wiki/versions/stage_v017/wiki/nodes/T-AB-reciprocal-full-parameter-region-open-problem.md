# Theorem: Alzer Berg reciprocal Gini Gamma quotient complete monotonicity parameter region open problem

## Statement

Determine all real parameters \(a,b\) such that \(x\mapsto1/P_{a,b}(u,v;x)\) is completely monotone on \((0,\infty)\) for every \(v>u>0\), where \(P_{a,b}\) is the Alzer--Berg Gini Gamma quotient.
