# Theorem: Erdos 536 diagnostic sparse top code second moment for moving star obstruction

## Statement

Sparse top-code second-moment diagnostic route: attempt to construct, or rule out within natural models, a positive-mass occupied top code \(\mathcal T_k\subseteq H_{k,\theta}\) supporting threshold-sharp moving-star lower fibers such that the second moment of the number of pairs \((A,B)\) with \(A\cup B\in\mathcal T_k\) is negligible. If such a top code cannot retain positive \(\nu_k\)-mass, record whether the obstruction collapses by top-code sparsity, center-entropy compression, or occupied-top density.
