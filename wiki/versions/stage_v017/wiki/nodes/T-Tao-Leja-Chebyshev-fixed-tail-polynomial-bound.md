# Lemma: Fixed residual tail polynomial bound for Chebyshev-Leja next-pivot Lebesgue values

## Statement

If only r Chebyshev roots remain in the residual set, the next-pivot Lebesgue value is at most C^r n^{2r}.
\[
If r=|X_n\A|, then lambda_A(y)+1 <= C^r n^{2r}.
\]
