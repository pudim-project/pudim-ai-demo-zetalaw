# Definition: Jain-Karlin-Schoenberg kernel

## Statement

The Jain--Karlin--Schoenberg kernel is \(K_{JKS}(x,y)=\max(1+xy,0)\) on \(\mathbb R\times\mathbb R\). Its \(\alpha\)-power is the entrywise kernel \(K_{JKS}(x,y)^\alpha\).
