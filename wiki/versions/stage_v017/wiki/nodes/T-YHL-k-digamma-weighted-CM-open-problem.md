# Theorem: Yin-Huang-Lin Open Problem 4.1 k-digamma weighted complete monotonicity parameter classification

## Statement

Determine all parameters \(\alpha,k,a,b,c,d\), with \(k,a,b,c,d>0\), for which \(x^\alpha[\psi_k(ax+b)-k\log(cx+d)]\) is completely monotonic on \((0,\infty)\).
