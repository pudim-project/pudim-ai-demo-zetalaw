# Definition: Alzer-Berg Euler-limit p alpha beta language

## Statement

For \(\alpha>0\) and \(\beta\in\mathbb R\), Alzer and Berg consider \(p_{\alpha,\beta}(x)=e^\alpha-(1+\alpha/x)^{x+\beta}\) on \((0,\infty)\). The exact source problem is to determine all \((\alpha,\beta)\) for which \(p_{\alpha,\beta}\) is completely monotone.
