# Theorem: Erdos536 terminating core shield descent complexity

## Statement

Terminating core/shield descent theorem: in an admissible lower-trace model with zero conditional coverage, every fixed common-core, moving-core, or endpoint-shield obstruction either yields rank-thinness, a support-level fork, positive \(\Omega_k\), or descends to a strictly smaller obstruction under an explicit lexicographic complexity \(\mathcal C=(\ell_{\mathrm{end}},w_{\mathrm{core}},m_{\mathrm{avail}},r_{\mathrm{width}})\). The complexity must be well-founded and strictly decrease at each descent step, so the obstruction cannot persist indefinitely.
