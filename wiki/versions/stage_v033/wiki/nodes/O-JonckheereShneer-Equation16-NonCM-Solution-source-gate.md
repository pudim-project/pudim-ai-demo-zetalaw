# Open_Problem: Jonckheere-Shneer equation (16) non-CM solution question

## Statement

Jonckheere and Shneer derive the transformed nonlinear tail equation \(F(x)=\int_0^\infty F(xb)^2\,\mathbb P(\widetilde B\in db)\). They observe that, unlike the analogous Laplace-transform equation, one now seeks only a non-increasing function \(F\), and ask whether solutions that are not completely monotone exist.
