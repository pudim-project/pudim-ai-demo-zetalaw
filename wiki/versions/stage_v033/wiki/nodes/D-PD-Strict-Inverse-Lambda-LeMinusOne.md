# Definition: Strict inverse in the Pearse-Bondell lambda <= -1 range

## Statement

For \(\lambda=-\gamma\le -1\), the Pearse--Bondell generator \(\phi_{-\gamma}\) is strictly decreasing from \((0,1]\) onto \([0,\infty)\). Hence \(u_\gamma(t)=\phi_{-\gamma}^{-1}(t)\) is a strict inverse mapping \((0,\infty)\) to \((0,1)\), with continuous extension \(u_\gamma(0)=1\).
