# Definition: Nantomah generalized Nielsen beta function

## Statement

For \(p\in\mathbb N\) and \(x>0\), Nantomah's generalized Nielsen beta function is \(\beta_p(x)=\sum_{r=0}^{p}((x+2r)^{-1}-(x+2r+1)^{-1})\).
