# Theorem: T-Tao-Sendov-q-ge-r-patch-role-classification

## Statement

The q>=r root-gap patch is a restricted-branch large-root or all-interior-root control theorem. It is not inherited from the tangent-cluster reduction and is unnecessary for the exact tangent-cluster Sendov conclusion, which follows for all m,N>=1 from the product/root-min estimate. It may still be useful in perturbative arguments that require largest-interior-root control.

## Scope

- Role classification for existing tangent-cluster local results.
