# Source Status: Mainardi Mittag-Leffler Padé Bounds

Oracle forage `FI-20260530T-elegance-033` selected Mainardi's bounds for
\[
e_\alpha(t)=E_\alpha(-t^\alpha),\qquad 0<\alpha<1.
\]
The bounds are
\[
\frac{1}{1+\Gamma(1-\alpha)t^\alpha}
\le
E_\alpha(-t^\alpha)
\le
\frac{1}{1+t^\alpha/\Gamma(1+\alpha)}.
\]

The checked arXiv source does state these bounds as a conjecture/open problem in the body and conclusion. However, the final remark of the same source says a proof was later supplied by Thomas Simon, with reference:

Thomas Simon, "Comparing Fréchet and positive stable laws", Electron. J. Probab. 19 (2014), arXiv:1310.1888.

Therefore this is not a fresh source problem for Pudim. It should not receive a local application label.

The reduction
\[
Q_\alpha(x)=\frac{1/E_\alpha(-x)-1}{x}
\]
may still be useful as a proof handle in other Mittag-Leffler comparison problems, but the Mainardi Padé bounds themselves are source-status demoted.
