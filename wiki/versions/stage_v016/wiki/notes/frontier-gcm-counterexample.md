# Frontier: Gaussian Heat-Flow Entropy Counterexample

Scout forage `FI-20260528T-next-loop-005` selected Gu--Sellke arXiv:2605.11656 as the next diverse heat-flow entropy source.

The source considers
\[
H_\mu(t)=\int_{\mathbb R}(p_t*\mu)(x)\log(p_t*\mu)(x)\,dx
\]
and the Gaussian complete-monotonicity sign pattern
\[
(-1)^mH_\mu^{(m)}(t)\ge0,\qquad m\ge1,\ t>0.
\]

The source states an explicit finite symmetric atomic counterexample at order \(m=5\), with \(t=1/3\), and reports
\[
0.36 < H_\mu^{(5)}(1/3) < 0.37.
\]
This is a refutation target for the local Theory only after Student reproduces a local certificate.

The same source also proves that a log-concave probability measure fails the sign pattern at some order, but explicitly does not give the order. Since the sign pattern is known up to order \(5\) in the log-concave setting, the residual explicit-order problem begins at \(m\ge6\).

Mainardi's Mittag-Leffler Padé-bound conjecture was considered during the same forage, but demoted because the source itself says Thomas Simon supplied a proof in 2013.
