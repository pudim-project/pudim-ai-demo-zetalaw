# Definition: Forward-difference complete monotone sequence

## Statement

With the source convention \(\Delta a_n=a_{n+1}-a_n\), a sequence is completely monotone in the Wang--Yang finite-difference sense when \((-1)^r\Delta^r a_n\ge0\) for all admissible \(n,r\), with strict positivity when the source asks for positive signs.
