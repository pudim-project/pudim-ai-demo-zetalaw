# Theorem: Erdos536 separated defect windows force disjoint pairs

## Statement

For every fixed \(0<\theta<1\), \(\eta>0\), and every admissible non-rank-thin positive-mass family \(\mathcal F_k\subseteq H_{k,\theta}\), a positive-mass set of occupied tops \(C\) has two separated defect-size windows on which the conditional defect law is not concentrated in a common core; on those tops, two independent lower traces have defects \(D,E\) with \(D\cap E=\varnothing\) with probability bounded away from zero along a subsequence. Consequently \(\mathbf E[\Omega_k(C)\mid C\in\mathcal F_k]>0\).
