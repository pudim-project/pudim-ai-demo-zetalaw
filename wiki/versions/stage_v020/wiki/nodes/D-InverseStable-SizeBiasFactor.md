# Definition: Inverse stable power size-biased factor

## Statement

For \(a>b>0\), set \(\alpha=b/a\). If \(S_\alpha\) is positive \(\alpha\)-stable, \(W_0=S_\alpha^{-b}\), and \(W\) is the ordinary \(W_0\)-size-biased random variable, then \(\mathbb E W^s=\Gamma(a(s+1))\Gamma(b)/[\Gamma(b(s+1))\Gamma(a)]\) for \(\Re s>-1\).
