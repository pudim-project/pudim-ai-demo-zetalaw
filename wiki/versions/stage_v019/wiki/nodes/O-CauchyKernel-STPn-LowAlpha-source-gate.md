# Open_Problem: Cauchy kernel strict total positivity below alpha equals one over n source gate

## Statement

Verify exact source wording and later-literature novelty for the Cauchy-kernel strict-total-positivity problem: for every integer n>=2 and alpha<1/n, determine whether K_alpha(x,y)=1/(x^2+2 cos(pi alpha) x y+y^2) is strictly totally positive of order n on (0,infty)^2. Distinguish this strict STP_n statement from the later non-strict TP_n classification.
