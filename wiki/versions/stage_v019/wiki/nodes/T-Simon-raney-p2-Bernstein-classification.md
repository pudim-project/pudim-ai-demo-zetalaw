# Theorem: Simon Raney p=2 Bernstein slice classification

## Statement

For \(\mu_n(r)=\frac{r}{2n+r}\binom{2n+r}{n}\), \(0<r\le2\), the sequence has Simon's Bernstein moment-sequence property exactly at \(r=2\). The endpoint \(r=0\) is a separate degenerate zero-sequence case if that convention is admitted.
