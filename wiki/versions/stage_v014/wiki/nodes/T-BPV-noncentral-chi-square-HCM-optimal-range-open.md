# Theorem: BPV noncentral chi-square HCM optimal parameter range open problem

## Statement

Determine the optimal parameter range \((\mu,\lambda)\), with \(\mu>0\) and \(\lambda>0\), for which the noncentral chi-square density \(\chi_{\mu,\lambda}\) is hyperbolically completely monotone.
