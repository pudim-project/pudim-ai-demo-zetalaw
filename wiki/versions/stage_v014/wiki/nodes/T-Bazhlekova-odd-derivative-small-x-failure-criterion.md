# Theorem: Bazhlekova odd derivative negative polynomial criterion gives small x complete monotonicity failure

## Statement

For a two-term Bazhlekova symbol \(g(s)=c s^a+d s^b\), if the derivative polynomial normal form has \(Q_{2q+1}(y_0)<0\) for some \(q\ge1\) and \(y_0>0\), then \(e^{-x\sqrt{g(s)}}\) is not completely monotone for all sufficiently small \(x>0\); hence the source property \(w_t\ge0\) fails for that exponent pair, uniformly in \(c,d>0\), using the source Laplace-transform identity.
