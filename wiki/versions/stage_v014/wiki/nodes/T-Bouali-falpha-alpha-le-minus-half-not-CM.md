# Theorem: Bouali f alpha alpha less equal minus one half not completely monotone

## Statement

For \(f_\alpha(x)=x^{x(\psi(x)-\log x)-\alpha}\), if \(\alpha\le -1/2\), then \(f_\alpha\) is not completely monotone on \((0,\infty)\).
