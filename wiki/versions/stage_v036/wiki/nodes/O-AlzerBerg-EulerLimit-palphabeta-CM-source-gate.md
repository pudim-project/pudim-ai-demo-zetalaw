# Open_Problem: Alzer-Berg Euler-limit p alpha beta complete monotonicity source gate

## Statement

Verify the exact source status and later-literature novelty for the Alzer-Berg open problem asking to determine all \(\alpha>0\), \(\beta\in\mathbb R\) for which \(p_{\alpha,\beta}(x)=e^\alpha-(1+\alpha/x)^{x+\beta}\) is completely monotone on \((0,\infty)\). Distinguish the full two-parameter problem from later \(\beta=0\) or boundary-slice results.
