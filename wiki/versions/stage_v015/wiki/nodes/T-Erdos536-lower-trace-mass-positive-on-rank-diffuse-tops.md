# Theorem: Erdos 536 non rank thin positive mass families have cover ready lower trace mass below typical tops

## Statement

For every fixed \(0<\theta<1\) and \(\eta>0\), let \(S_k=\sum_{i\le k}1/p_i\). If \(\mathcal F_k\subseteq H_{k,\theta}\) has \(\nu_k(\mathcal F_k)\ge\eta\), then either \(\mathcal F_k\) is rank-thin in the sense of `T-Erdos536-rank-block-anti-concentration`, or a positive \(\nu_k\)-mass set of tops \(C\in\mathcal F_k\) has two separated defect windows \(D_1(C),D_2(C)\) for which the lower-trace masses \(\mu_C\{A\in\mathcal L_{\mathcal F_k}(C): |C\setminus A|\in D_j(C)\}\) are both bounded below and are not contained in a coordinate-deficient core. This cover-ready lower-trace mass forces \(\mathbf E[\psi_k(C)\mid C\in\mathcal F_k]>0\).
