# Theorem: Bazhlekova two-term gap outside unit disk no propagation positivity package

## Statement

For \(g(s)=c s^a+d s^b\), \(c,d>0\), \(1<a\le2\), \(0<b<a-1\), and \((a-1)^2+(b-1)^2>1\), Bazhlekova's propagation positivity package cannot hold for all \(x,t>0\).
