# Theorem: second derivative complete monotonicity gate gives a <= T2 inf formula for SKJ H_a

## Statement

If \(H_a(x)=e^a-(1+a/x)^x\) is completely monotonic on \((0,\infty)\), then \(a\le T_2\), where \(T_2=\inf_{y>0} y^3/((1+y)^2(\log(1+y)-y/(1+y))^2)\).
