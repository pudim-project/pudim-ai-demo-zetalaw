# Theorem: Simon gamma quotient complement is CM for alpha in (0,1)

## Statement

For every \(0<\alpha<1\), the function \(1-\Gamma(x+\alpha)/(\Gamma(x)x^\alpha)\) is completely monotone on \((0,\infty)\).
