# Theorem: Du Wang h31 driver is nondecreasing from a nonnegative endpoint on the middle window

## Statement

For \(1/2\le a\le1\), set \(H_a(u)=h_{31}(a+u)\). Then \(H_a'(u)\ge0\) for all \(u>0\), and \(H_a(0+)=2\log\Gamma(a)\ge0\).
