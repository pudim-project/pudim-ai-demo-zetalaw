# Theorem: Erdos 536 positive mass non rank thin families have occupied top support defect shadow with disjoint defects forcing fork

## Statement

For every fixed \(0<\theta<1\) and \(\eta>0\), let \(S_k=\sum_{i\le k}1/p_i\). If \(\mathcal F_k\subseteq H_{k,\theta}\) has \(\nu_k(\mathcal F_k)\ge\eta\) and is not rank-thin, then there is an occupied top \(C\in\mathcal F_k\) whose support defect shadow \(\mathsf D_{\mathcal F_k}(C)=\{C\setminus A:A\in\mathcal F_k,\ A\subsetneq C\}\) contains two disjoint nonempty defects. Equivalently, there are distinct \(A,B,C\in\mathcal F_k\) with \(A\cup B=C\).
