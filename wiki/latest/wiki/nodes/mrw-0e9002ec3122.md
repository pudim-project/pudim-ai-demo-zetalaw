# Proposition: Pointwise reduction for reciprocal-digamma beta windows

## Statement

Let
\[
A(x)=\psi(x)+x\psi'(x),\qquad
B(x)=\psi(x)\psi(1/x),
\qquad
F_\beta(x)=x^\beta A(x)-B(x)
\]
for \(x>0\).  Let
\[
\mathcal I=\{\beta\in\mathbb R: F_\beta(x)>0\text{ for every }x>0\}.
\]
For \(x\ne1\) with \(A(x)B(x)>0\), put
\[
Q(x)=\frac{\log(B(x)/A(x))}{\log x}.
\]
Define the lower-constraint set
\[
\mathcal L=
\{Q(x):x>1,\ A(x)>0,\ B(x)>0\}
\cup
\{Q(x):0<x<1,\ A(x)<0,\ B(x)<0\},
\]
and the upper-constraint set
\[
\mathcal U=
\{Q(x):0<x<1,\ A(x)>0,\ B(x)>0\}
\cup
\{Q(x):x>1,\ A(x)<0,\ B(x)<0\}.
\]
If there exists \(x>0\) with \(A(x)\le0\le B(x)\), then \(\mathcal I=\varnothing\).  Otherwise
\[
\mathcal I=
\{\beta\in\mathbb R:
\beta>q\text{ for every }q\in\mathcal L
\text{ and }
\beta<q\text{ for every }q\in\mathcal U\}.
\]
In all cases,
\[
\mathcal I\subseteq[-1,\infty).
\]
Consequently the Qi--Lim--Nantomah \(\beta_0\)-window problem is reduced to a sign partition for \(A,B\) plus the scalar envelope \(Q\).  In particular, every point \(0<x<1\) with \(A(x)>0\) and \(B(x)>0\) gives the rigorous upper constraint
\[
\beta<Q(x),
\]
while the endpoint \(x\to0^+\) rules out every \(\beta<-1\).

## Proof

Fix \(x>0\).  If \(A(x)>0\), then
\[
F_\beta(x)>0
\quad\Longleftrightarrow\quad
x^\beta>\frac{B(x)}{A(x)}.
\]
When \(B(x)\le0\), this imposes no restriction on \(\beta\).  When \(B(x)>0\), taking logarithms gives
\[
\beta\log x>\log(B(x)/A(x)).
\]
Thus the condition is \(\beta>Q(x)\) if \(x>1\), and \(\beta<Q(x)\) if \(0<x<1\).

If \(A(x)=0\), then \(F_\beta(x)=-B(x)\).  Hence the point is automatically harmless when \(B(x)<0\), and impossible for every \(\beta\) when \(B(x)\ge0\).

If \(A(x)<0\), then
\[
F_\beta(x)>0
\quad\Longleftrightarrow\quad
x^\beta<\frac{B(x)}{A(x)}.
\]
This is impossible when \(B(x)\ge0\), since then \(B(x)/A(x)\le0\).  When \(B(x)<0\), the ratio \(B(x)/A(x)\) is positive, and logarithms give
\[
\beta\log x<\log(B(x)/A(x)).
\]
Thus the condition is \(\beta<Q(x)\) if \(x>1\), and \(\beta>Q(x)\) if \(0<x<1\).

The preceding pointwise cases are exactly the asserted half-line intersection.  The remaining point \(x=1\) imposes no beta-dependent restriction here, because
\[
F_\beta(1)=A(1)-B(1)=\frac{\pi^2}{6}-\gamma-\gamma^2>0
\]
by the standard elementary bounds \(\gamma<3/5\) and \(\pi^2/6>8/5\).

It remains to record the endpoint obstruction.  As \(x\to0^+\),
\[
\psi(x)=-\frac1x-\gamma+O(x),\qquad
\psi'(x)=\frac1{x^2}+\frac{\pi^2}{6}+O(x),
\]
and
\[
\psi(1/x)=\log(1/x)+O(x).
\]
Therefore
\[
A(x)=-\gamma+O(x)
\]
and
\[
B(x)=-\frac{\log(1/x)}{x}+O(\log(1/x)+1).
\]
Consequently
\[
F_\beta(x)
=-\gamma x^\beta+\frac{\log(1/x)}{x}
+O(\log(1/x)+1)+O(x^{\beta+1})
\]
in the sense needed for dominance of the two leading terms.  If \(\beta<-1\), then \(x^\beta\) grows faster than \(x^{-1}\log(1/x)\), so \(F_\beta(x)\to-\infty\).  Thus no \(\beta<-1\) can belong to \(\mathcal I\).
