# Proposition: One-from-each two-class assemblies decouple by endpoint pair

## Statement

Let \(P=Z\sqcup X\sqcup Y\) be a finite disjoint decomposition with
\(X,Y\ne\varnothing\).  For each ordered endpoint pair
\((x,y)\in X\times Y\), let
\[
\mathcal R_{xy}\subseteq 2^Z.
\]
Define the one-from-each two-class assembly
\[
\mathcal A
=
\{R\cup\{x,y\}:x\in X,\ y\in Y,\ R\in\mathcal R_{xy}\}
\subseteq2^P.
\tag{1}
\]
Thus every member of \(\mathcal A\) contains exactly one point of \(X\),
exactly one point of \(Y\), and an arbitrary allowed core set in \(Z\).

Then \(\mathcal A\) is pair-link-free in \(2^P\) if and only if every endpoint
fiber \(\mathcal R_{xy}\) is pair-link-free in \(2^Z\).

Equivalently, any pair-link triple
\[
A,B,C\in\mathcal A,\qquad A,B,C\ \text{pairwise distinct},\qquad
C\in I(A,B)
\]
must use one common endpoint pair \((x,y)\); after deleting \(\{x,y\}\), it is
exactly a pair-link triple inside the core fiber \(\mathcal R_{xy}\).

Moreover, for any product law \(\nu_P\) on \(2^P\) with coordinate
probabilities \(q_p\in(0,1)\), let \(\nu_Z\) be the restricted product law on
\(2^Z\) and put
\[
\alpha_x=q_x\prod_{u\in X\setminus\{x\}}(1-q_u),
\qquad
\beta_y=q_y\prod_{v\in Y\setminus\{y\}}(1-q_v).
\tag{2}
\]
Then
\[
\nu_P(\mathcal A)=
\sum_{x\in X}\sum_{y\in Y}\alpha_x\beta_y\,\nu_Z(\mathcal R_{xy}).
\tag{3}
\]
For every real \(L\),
\[
\nu_P(\mathcal A\cap\{S:|S|>L\})
=
\sum_{x\in X}\sum_{y\in Y}
\alpha_x\beta_y\,
\nu_Z(\{R\in\mathcal R_{xy}:|R|+2>L\}).
\tag{4}
\]

## Proof

First suppose some fiber \(\mathcal R_{xy}\) is not pair-link-free in \(2^Z\).
Then there are pairwise distinct \(R_1,R_2,R_3\in\mathcal R_{xy}\) such that
\[
R_3\in I_Z(R_1,R_2).
\]
Set
\[
A_i=R_i\cup\{x,y\}\qquad(i=1,2,3).
\]
The three \(A_i\) are pairwise distinct members of \(\mathcal A\).  Since the
same endpoint pair \(\{x,y\}\) is present in all three sets,
\[
A_1\triangle A_2=R_1\triangle R_2,
\qquad
A_1\cup A_2=(R_1\cup R_2)\cup\{x,y\}.
\]
Thus \(A_3\in I_P(A_1,A_2)\), so \(\mathcal A\) is not pair-link-free.

Conversely, assume every \(\mathcal R_{xy}\) is pair-link-free and suppose
\[
A=R_A\cup\{x_A,y_A\},\quad
B=R_B\cup\{x_B,y_B\},\quad
C=R_C\cup\{x_C,y_C\}
\]
are pairwise distinct members of \(\mathcal A\) with \(C\in I_P(A,B)\).
If \(x_A\ne x_B\), then both \(x_A\) and \(x_B\) lie in
\(A\triangle B\).  Every member of \(I_P(A,B)\) must contain
\(A\triangle B\), so \(C\) would contain two points of \(X\).  This is
impossible because every member of \(\mathcal A\) contains exactly one point
of \(X\).  Hence \(x_A=x_B\).  The same argument in \(Y\) gives
\[
y_A=y_B.
\]
Write the common endpoint pair as \((x,y)\).

Because \(C\in I_P(A,B)\), it must contain every element of
\(A\triangle B=R_A\triangle R_B\) and be contained in
\((R_A\cup R_B)\cup\{x,y\}\).  Since \(C\) contains exactly one point of
\(X\) and one point of \(Y\), and the only available endpoint points in the
upper bound are \(x\) and \(y\), we have \(x_C=x\) and \(y_C=y\).  Therefore
\[
R_A\triangle R_B\subseteq R_C\subseteq R_A\cup R_B.
\]
The pairwise distinctness of \(A,B,C\) is now exactly the pairwise
distinctness of \(R_A,R_B,R_C\), so this is a pair-link triple in
\(\mathcal R_{xy}\), contradicting the fiber hypothesis.  Hence
\(\mathcal A\) is pair-link-free.

The measure identities are disjoint decompositions by endpoint pair.  The
event that the \(X\)-section is exactly \(\{x\}\) has probability
\(\alpha_x\), and the event that the \(Y\)-section is exactly \(\{y\}\) has
probability \(\beta_y\).  These events are independent of the \(Z\)-section,
which is governed by \(\nu_Z\).  Summing over the disjoint endpoint pairs
gives (3).  Since every member \(R\cup\{x,y\}\) has cardinality \(|R|+2\), the
same decomposition with the additional condition \(|R|+2>L\) gives (4).

## Notes

- This is a full pair-link interval audit for the exact two-class assembly
  suggested by the complete case of [[mrw-bc27191b14d4]].  Once every set has
  exactly one point from each normalized class, pair-link triples cannot mix
  distinct endpoint pairs.
- The proposition contains the fixed complete-bipartite blow-up
  [[mrw-c7c76faed872]] as the equal-fiber special case: taking all
  \(\mathcal R_{xy}\) equal to one common \(\mathcal R\subseteq2^Z\) recovers
  that construction.
- The formal proof only needs the pair-link interval vocabulary from
  [[mrw-3c39ca3d1973]].  The coherent-component proposition
  [[mrw-bc27191b14d4]] and the fixed blow-up proposition
  [[mrw-c7c76faed872]] are contextual ancestry and special-case comparison,
  not minimal direct proof dependencies.
- This is not terminal evidence for \(M_{P_k}(\theta)\to0\),
  \(U_k(\theta)\to0\), or \(R_P(\theta)\).  It shows that a coherent exact
  two-class assembly may survive the full pair-link interval test by
  decoupling into endpoint-pair core fibers.  The remaining obstruction must
  either force mass outside this exact one-from-each form, prove that the
  endpoint-fiber mixture has vanishing high-support prime-biased mass, or lift
  a stronger core-fiber theorem.
