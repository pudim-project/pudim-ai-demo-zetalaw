# Proposition: Strict endpoint-pair deletions admit compatible re-towering

## Statement

Use the finite endpoint-tower notation of [[mrw-05f82d03b190]]:
\[
P=P_0\supseteq P_1\supseteq\cdots\supseteq P_r,
\qquad
P_{i-1}=P_i\sqcup X_i\sqcup Y_i
\quad(1\le i\le r).
\]
Let
\[
\mathcal E_{\mathrm{ov}}
=
\bigcup_{i=1}^r
\left(\binom{X_i}{2}\cup\binom{Y_i}{2}\right)
\]
be the same-class endpoint-pair set of [[mrw-c82229c73d8d]].  Fix
\(e=\{p,q\}\in\mathcal E_{\mathrm{ov}}\), and suppose \(e\subseteq C_j\),
where \(C_j\in\{X_j,Y_j\}\).  Let \(D_j\) denote the opposite endpoint class
at level \(j\), so \(\{C_j,D_j\}=\{X_j,Y_j\}\).  Put \(P^e=P\setminus e\).

If \(C_j\setminus e\ne\varnothing\), then \(P^e\) has an endpoint tower of
length \(r\) with terminal core \(P_r\).  Its cores are
\[
Q_i=
\begin{cases}
P_i\setminus e, & i<j,\\
P_i, & i\ge j,
\end{cases}
\]
with all endpoint classes unchanged except that \(C_j\) is replaced by
\(C_j\setminus e\).

If \(C_j=e\), then \(P^e\) has an endpoint tower of length \(r-1\) with
terminal core \(P_r\cup D_j\).  Writing its cores as
\(Q_0,\ldots,Q_{r-1}\), they are
\[
Q_i=P_i\setminus e\quad(0\le i<j),
\qquad
Q_i=P_{i+1}\cup D_j\quad(j\le i\le r-1),
\]
where the second formula is absent when \(j=r\).  The endpoint classes before
level \(j\) are the original \(X_i,Y_i\), while the endpoint classes after
the skipped level \(j\) are the original \(X_{i+1},Y_{i+1}\).

When \(r=1\) and \(j=1\) in the collapsed case, this is the degenerate
length-zero tower on \(P\setminus e=P_1\cup D_1\).  In that convention
\(\ell_e=0\), \(T_e=P\setminus e\), \(\Gamma_e=1\), and
\(\mathcal R_{\mathrm{def}}^e(U)=0\).

Let the induced tower for \(P^e\) have length \(\ell_e\), terminal core
\(T_e\), exact endpoint probability \(\Gamma_e\), and defect residual
\(\mathcal R_{\mathrm{def}}^e(U)\) as in [[mrw-05f82d03b190]], computed with
the restricted product law on \(P^e\).  Then for every real threshold \(U\),
\[
\mathfrak M_{P\setminus e}(U)
\le
\Gamma_e\,\mathfrak M_{T_e}(U-2\ell_e)
+
\mathcal R_{\mathrm{def}}^e(U).
\]
Consequently, for every real \(L\),
\[
\sum_{e\in\mathcal E_{\mathrm{ov}}}q_e\,
\mathfrak M_{P\setminus e}(L-2)
\le
\sum_{e\in\mathcal E_{\mathrm{ov}}}q_e
\left(
\Gamma_e\,\mathfrak M_{T_e}(L-2-2\ell_e)
+
\mathcal R_{\mathrm{def}}^e(L-2)
\right),
\]
where \(q_e=q_pq_q\) for \(e=\{p,q\}\).

## Proof

First suppose \(C_j\setminus e\ne\varnothing\).  For every \(i<j\), the
deleted pair \(e\) lies in the deeper core \(P_i\), so
\[
Q_{i-1}=P_{i-1}\setminus e
=
(P_i\setminus e)\sqcup X_i\sqcup Y_i
=
Q_i\sqcup X_i\sqcup Y_i .
\]
At level \(j\),
\[
Q_{j-1}=P_{j-1}\setminus e
=
P_j\sqcup(C_j\setminus e)\sqcup D_j
=
Q_j\sqcup(C_j\setminus e)\sqcup D_j .
\]
Both endpoint classes at this level are nonempty by the case assumption and
by the definition of an endpoint tower.  For \(i>j\), no deletion occurs in
the \(i\)-th decomposition, so
\[
Q_{i-1}=P_{i-1}=P_i\sqcup X_i\sqcup Y_i=Q_i\sqcup X_i\sqcup Y_i .
\]
Thus the displayed \(Q_i\)'s form an endpoint tower for \(P^e\) of the same
length \(r\) and terminal core \(P_r\).

Now suppose \(C_j=e\).  Then
\[
P_{j-1}\setminus e=P_j\sqcup D_j.
\]
The class \(C_j\) has disappeared, so level \(j\) is skipped and \(D_j\) is
absorbed into all deeper cores.  For each level before \(j\), the same
calculation as above gives
\[
Q_{i-1}=Q_i\sqcup X_i\sqcup Y_i
\qquad(1\le i<j).
\]
For the first level after the skip, if \(j<r\),
\[
Q_{j-1}=P_j\sqcup D_j
=
(P_{j+1}\cup D_j)\sqcup X_{j+1}\sqcup Y_{j+1}
=
Q_j\sqcup X_{j+1}\sqcup Y_{j+1}.
\]
More generally, for \(j\le i\le r-1\),
\[
Q_{i-1}=P_i\cup D_j
=
(P_{i+1}\cup D_j)\sqcup X_{i+1}\sqcup Y_{i+1}
=
Q_i\sqcup X_{i+1}\sqcup Y_{i+1}.
\]
If \(j=r\), there is no post-skip level and the terminal core is simply
\(Q_{r-1}=P_r\cup D_r\).  Hence \(P^e\) has an endpoint tower of length
\(r-1\) and terminal core \(P_r\cup D_j\) in all cases.

If \(\ell_e=0\), then \(T_e=P^e\), \(\Gamma_e=1\), and
\(\mathcal R_{\mathrm{def}}^e(U)=0\), so the desired residual inequality is
the identity
\[
\mathfrak M_{P^e}(U)\le \mathfrak M_{P^e}(U).
\]
Otherwise, apply [[mrw-05f82d03b190]] to the induced endpoint tower on
\(P^e\).  For any
pair-link-free family \(\mathcal A\subseteq2^{P^e}\), that proposition gives
\[
\nu_{P^e}(\mathcal A\cap\{R:|R|>U\})
\le
\Gamma_e\,\mathfrak M_{T_e}(U-2\ell_e)
+
\mathcal R_{\mathrm{def}}^e(U).
\]
Taking the supremum over all pair-link-free \(\mathcal A\subseteq2^{P^e}\)
proves the displayed bound for \(\mathfrak M_{P\setminus e}(U)\).  Finally
substitute \(U=L-2\), multiply by \(q_e\), and sum over
\(\mathcal E_{\mathrm{ov}}\).

## Notes

- This proposition addresses the Oracle caveat recorded after
  [[mrw-c82229c73d8d]]: deleting two points from one endpoint class may empty
  that class, but the remaining space still admits a compatible induced
  endpoint tower after skipping that level and absorbing the opposite class
  into the deeper cores.
- The result is only a structural re-towering and residual-decomposition
  theorem.  It does not prove decay of the residuals
  \(\mathfrak M_{P\setminus e}\), does not prove an \(R_P(\theta)\) lift, and
  does not by itself close the Erdos 536 high-support problem.
- The collapsed-class case changes the terminal core from \(P_r\) to
  \(P_r\cup D_j\).  The next induction theorem must control these enlarged
  induced terminal cores or show that near-extremal induced residuals force
  pointwise mixed incidence and coherent-component defect.
- Focused Oracle passed the proof after requesting the degenerate length-zero
  tower convention for the case \(r=j=1\); that convention is now explicit in
  the statement and proof.
