# Corollary: Pair-link-free fiber unions obey pointwise endpoint residual bounds

## Statement

Let \(P=B\sqcup T\) carry a product law.  Write
\(\pi_B(e)=\nu_B(\{e\})\).  For a real threshold \(a\), define the ordinary
endpoint pair-link-free residual
\[
\mathfrak P_B(a)
=
\sup\{
\nu_B(\mathcal A):
\mathcal A\subseteq 2^B,\ 
\mathcal A\text{ is ordinary pair-link-free},\
\mathcal A\subseteq\{e:|e|>a\}
\}.
\]

Let
\[
\mathcal F
=
\bigcup_{e\in\mathcal E}\{e\cup R:R\in\mathcal R_e\}
\subseteq 2^{B\sqcup T}
\]
be pair-link-free.  For each \(R\subseteq T\), set
\[
\mathcal E_R=\{e\in\mathcal E:R\in\mathcal R_e\}.
\]
Then every \(\mathcal E_R\) is ordinary endpoint pair-link-free.  Consequently
for every real \(L\),
\[
\nu_P(\mathcal F\cap\{|S|>L\})
\le
\sum_{R\subseteq T}\nu_T(R)\mathfrak P_B(L-|R|)
=
\mathbb E_{R\sim\nu_T}\bigl[\mathfrak P_B(L-|R|)\bigr].
\]

More generally, if endpoint patterns are restricted to
\(\mathcal E'\subseteq\mathcal E\), define
\[
\mathfrak P_{\mathcal E'}(a)
=
\sup\{
\nu_B(\mathcal A):
\mathcal A\subseteq\mathcal E',\
\mathcal A\text{ is ordinary pair-link-free},\
\mathcal A\subseteq\{e:|e|>a\}
\}.
\]
The same proof gives the sharper bound
\[
\nu_P(\mathcal F'\cap\{|S|>L\})
\le
\sum_{R\subseteq T}\nu_T(R)\mathfrak P_{\mathcal E'}(L-|R|)
\]
for every subunion \(\mathcal F'\) supported on \(\mathcal E'\).

## Proof

Fix \(R\subseteq T\).  Suppose, for contradiction, that
\(\mathcal E_R\) is not ordinary endpoint pair-link-free.  Then there are
pairwise distinct endpoint patterns \(e_1,e_2,e_3\in\mathcal E_R\) with
\[
e_3\in I_B(e_1,e_2).
\]
Since \(R\in\mathcal R_{e_i}\) for all \(i\), the three ambient sets
\[
S_i=e_i\cup R
\]
all lie in \(\mathcal F\).  The terminal coordinate is unchanged, so
\[
R\in I_T(R,R).
\]
By endpoint-terminal interval factorization from `mrw-20ca89f696f2`,
\[
S_3\in I_P(S_1,S_2).
\]
This is a forbidden pair-link triple in \(\mathcal F\), contradicting
pair-link-freeness.  Hence \(\mathcal E_R\) is ordinary endpoint
pair-link-free.

Now decompose the product mass by terminal coordinate:
\[
\nu_P(\mathcal F\cap\{|S|>L\})
=
\sum_{R\subseteq T}\nu_T(R)
\sum_{\substack{e\in\mathcal E_R\\ |e|+|R|>L}}\pi_B(e).
\]
For each fixed \(R\), the inner endpoint family is an ordinary
pair-link-free subfamily of \(\{e:|e|>L-|R|\}\), so its mass is at most
\(\mathfrak P_B(L-|R|)\).  Summing over \(R\) proves the displayed bound.
The restricted \(\mathcal E'\) version is identical after replacing
\(\mathfrak P_B\) by \(\mathfrak P_{\mathcal E'}\).

## Notes

- This is an upper-bound and decomposition corollary, not terminal decay.
- It uses no pair-link-free hypothesis on the individual terminal fibers
  \(\mathcal R_e\).
- It deliberately discards cross-\(R\) terminal shadow constraints.  A sharper
  theorem should either bound the endpoint residual profile
  \(\mathfrak P_B(a)\) in the prime-biased endpoint regime, or recover the
  cross-fiber exclusions lost by this Fubini conditioning.
