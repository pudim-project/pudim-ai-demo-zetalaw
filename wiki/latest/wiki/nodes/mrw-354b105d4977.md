# Proposition: Pair-link-free two-extension slices are triangle-free

## Statement
Let \(P\) be a finite set and put
\[
I(A,B)=\{C\subseteq P:A\triangle B\subseteq C\subseteq A\cup B\},
\qquad
I^\circ(A,B)=I(A,B)\setminus\{A,B\}.
\]
Let \(\mathcal F\subseteq2^P\) be pair-link-free, meaning there are no
pairwise distinct \(A,B,C\in\mathcal F\) with \(C\in I^\circ(A,B)\).

For \(R\subseteq P\), define the two-extension slice graph
\[
G_R^\mathcal F=(P\setminus R,E_R^\mathcal F)
\]
by
\[
\{x,y\}\in E_R^\mathcal F
\quad\Longleftrightarrow\quad
x,y\in P\setminus R,\ x\ne y,\ R\cup\{x,y\}\in\mathcal F.
\]
Then \(G_R^\mathcal F\) is triangle-free.  Consequently
\[
|E_R^\mathcal F|
\le
\left\lfloor\frac{|P\setminus R|^2}{4}\right\rfloor.
\]
Equivalently,
\[
\left|\mathcal F\cap\{R\cup e:e\in\binom{P\setminus R}{2}\}\right|
\le
\left\lfloor\frac{|P\setminus R|^2}{4}\right\rfloor.
\]

## Proof
Suppose \(G_R^\mathcal F\) contains a triangle on distinct vertices
\(x,y,z\in P\setminus R\).  Then
\[
A=R\cup\{x,y\},\qquad
B=R\cup\{x,z\},\qquad
C=R\cup\{y,z\}
\]
all lie in \(\mathcal F\).  Moreover
\[
A\triangle B=\{y,z\}.
\]
The set \(C\) contains \(y\) and \(z\), and
\[
C=R\cup\{y,z\}\subseteq R\cup\{x,y,z\}=A\cup B.
\]
Thus
\[
A\triangle B\subseteq C\subseteq A\cup B,
\]
so \(C\in I(A,B)\).  Since \(x\in A\cap B\) but \(x\notin C\), while
\(z\in C\setminus A\) and \(y\in C\setminus B\), the three sets
\(A,B,C\) are pairwise distinct.  Hence \(C\in I^\circ(A,B)\), contradicting
pair-link-freeness.  Therefore \(G_R^\mathcal F\) is triangle-free.

It remains only to record the edge bound.  Let \(G\) be any triangle-free graph
on \(n\) vertices with \(m\) edges and degrees \(d(v)\).  If \(uv\) is an edge,
then \(N(u)\cap N(v)=\varnothing\); otherwise a common neighbor would form a
triangle with \(u\) and \(v\).  Hence
\[
d(u)+d(v)\le n
\]
for every edge \(uv\).  Summing over all edges gives
\[
\sum_{uv\in E(G)}(d(u)+d(v))
=
\sum_{v\in V(G)}d(v)^2
\le mn.
\]
By Cauchy's inequality,
\[
4m^2=\left(\sum_{v\in V(G)}d(v)\right)^2
\le n\sum_{v\in V(G)}d(v)^2
\le n^2m.
\]
If \(m=0\) the desired inequality is trivial; otherwise \(m\le n^2/4\).  Since
\(m\) is integral, \(m\le\lfloor n^2/4\rfloor\).  Applying this to
\(G_R^\mathcal F\) with \(n=|P\setminus R|\) proves the stated bound.

## Notes
- The triangle-free conclusion is a local structural constraint on graph links
  of the three-uniform pair-link hypergraph.  It does not prove
  \(U_k(\theta)\to0\) and has no standalone prime-biased mass consequence.
- This proposition strengthens the one-swap insertion-fiber proposition in the
  common-core two-extension setting: two same-insertion one-swap neighbors
  together with the base set form exactly a triangle in a graph \(G_R^\mathcal F\).
- The Mantel bound is sharp for one fixed slice.  If
  \(P\setminus R=X\sqcup Y\), then the slice
  \[
  \{R\cup\{x,y\}:x\in X,\ y\in Y\}
  \]
  is pair-link-free inside that fixed two-extension slice and has
  \(|X||Y|\) members.  This sharpness is only local; combining many dense
  bipartite slices can create pair-link triples across different cores.
- The next missing bridge is a weighted cross-core aggregation theorem, or an
  explicit positive-mass high-support construction assembled from dense
  triangle-free slices and then tested against the full interval criterion.
