# Proposition: Finite-prime weighted-grid reduction for Erdos 536

## Statement

Let \(P\) be a finite set of primes and put
\[
Q_P=\prod_{p\in P}p,
\qquad
\delta_P=\prod_{p\in P}\left(1-\frac1p\right).
\]
For \(X\ge1\), define
\[
\Gamma_P(X)=
\left\{
\alpha=(\alpha_p)_{p\in P}\in\mathbb Z_{\ge0}^P:
\prod_{p\in P}p^{\alpha_p}\le X
\right\}.
\]
Call three distinct exponent vectors \(\alpha,\beta,\gamma\) grid-bad if
\[
\alpha\vee\beta=\alpha\vee\gamma=\beta\vee\gamma,
\]
where \(\vee\) is coordinatewise maximum.  Let
\[
g_P(X)=
\max\{|S|:S\subseteq\Gamma_P(X),\ S\text{ contains no grid-bad triple}\}.
\]
If \(f(N)\) denotes the maximum size of an lcm-triangle-free subset of \([1,N]\), then
\[
f(N)\le
\sum_{\substack{r\le N\\(r,Q_P)=1}}g_P(N/r).
\]
Consequently, for fixed \(P\),
\[
\limsup_{N\to\infty}\frac{f(N)}N
\le
\delta_P
\int_1^\infty \frac{g_P(t)}{t^2}\,dt.
\]

## Proof

Let \(A\subseteq[1,N]\) be lcm-triangle-free.  Every \(n\in[1,N]\) has a unique decomposition
\[
n=r\prod_{p\in P}p^{\alpha_p},
\qquad
(r,Q_P)=1,
\qquad
\alpha_p\ge0.
\]
For a fixed \(r\), define the \(P\)-fiber
\[
S_r=
\left\{
\alpha\in\Gamma_P(N/r):
r\prod_{p\in P}p^{\alpha_p}\in A
\right\}.
\]
If \(\alpha,\beta,\gamma\in S_r\) were grid-bad, then the corresponding integers would have the same non-\(P\) part \(r\), and for each \(p\in P\) their pairwise lcm exponents would be the common coordinatewise maximum.  Hence their three pairwise lcms would be equal, contradicting the choice of \(A\).  Thus \(|S_r|\le g_P(N/r)\).  Summing over all \(r\le N\) with \((r,Q_P)=1\) proves the finite bound.

It remains to pass from the finite sum to the integral.  For fixed \(P\), the function \(g_P(t)\) is nondecreasing, right-continuous, and changes only when \(t\) crosses a \(P\)-smooth integer.  Put
\[
d_m=g_P(m)-g_P(m^-)
\]
for \(P\)-smooth integers \(m\), and \(d_m=0\) otherwise.  Then \(d_m\ge0\) and
\[
g_P(t)=\sum_{m\le t}d_m.
\]
Since \(|\Gamma_P(t)|=O_P((1+\log t)^{|P|})\), one has \(g_P(t)=O_P((1+\log t)^{|P|})\), so
\[
\int_1^\infty g_P(t)t^{-2}\,dt<\infty.
\]
Also, by changing the order of summation,
\[
\sum_{\substack{r\le N\\(r,Q_P)=1}}g_P(N/r)
=
\sum_{m\le N}d_m
\#\{r\le N/m:(r,Q_P)=1\}.
\]
The elementary residue count
\[
\#\{r\le x:(r,Q_P)=1\}=\delta_P x+O_P(1)
\]
gives
\[
\sum_{\substack{r\le N\\(r,Q_P)=1}}g_P(N/r)
=
\delta_P N\sum_{m\le N}\frac{d_m}{m}
+O_P(g_P(N)).
\]
Dividing by \(N\), the error is \(o(1)\).  Finally,
\[
\sum_{m\le N}\frac{d_m}{m}
=
\int_1^N \frac{g_P(t)}{t^2}\,dt+O\!\left(\frac{g_P(N)}N\right),
\]
by the same jump-function identity \(\int_m^\infty t^{-2}\,dt=1/m\).  Letting \(N\to\infty\) proves the asserted limsup bound.
