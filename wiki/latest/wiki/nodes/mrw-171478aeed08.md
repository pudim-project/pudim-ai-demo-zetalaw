# Proposition: Essential-index tail criterion for Erdos residue-class logarithmic density

## Statement

Use the notation of [[wiki/nodes/mrw-ba29cdf1fd30|Finite-shadow reduction for Erdos residue-class logarithmic density]], and set \(\delta_0=1\).  For \(i\ge1\), define the finite-shadow decrement
\[
h_i=\delta_{i-1}-\delta_i.
\]
Let
\[
\mathcal I=\{i\ge1:\ h_i>0\}
\]
be the set of essential indices, and define the essential union-tail majorant
\[
U_N^{\mathrm{ess}}=
\limsup_{x\to\infty}
\frac1{\log x}
\sum_{\substack{i>N\\ i\in\mathcal I\\ n_i<x}}
\frac{1+\log(x/n_i)}{n_i}.
\]
If
\[
\lim_{N\to\infty}U_N^{\mathrm{ess}}=0,
\]
then \(B\) has logarithmic density
\[
\delta=\lim_{N\to\infty}\delta_N.
\]

This condition is strictly weaker than the raw union-tail condition of [[wiki/nodes/mrw-f92c897044c4|Union-tail criterion for Erdos residue-class logarithmic density]].  In the nested system
\[
n_i=2i,\qquad a_i\equiv0\pmod {2i},
\]
one has \(U_N^{\mathrm{ess}}=0\) for every \(N\ge1\), while the raw majorant \(U_N\) is infinite for every fixed \(N\).

## Proof

Put \(B_0=\mathbb N\).  For \(i\ge1\), let
\[
H_i=B_{i-1}\setminus B_i
\]
be the first-hit set removed at step \(i\).  Since the finite shadows are decreasing,
\[
B_N\setminus B=\bigcup_{i>N}H_i
\]
as a disjoint union.  If \(m\in H_i\), then the only new condition failed at step \(i\), so
\[
m\ge n_i,\qquad m\equiv a_i\pmod {n_i}.
\]

For \(m\ge n_i\), membership in \(B_{i-1}\) is periodic modulo \(L_{i-1}\), and membership in \(H_i\) is periodic modulo \(L_i=\operatorname{lcm}(L_{i-1},n_i)\).  Let \(D_i\subseteq\mathbb Z/L_i\mathbb Z\) be the set of residue classes that lie over \(C_{i-1}\) and also satisfy \(r\equiv a_i\pmod {n_i}\).  Then, outside the threshold convention already built into \(m\ge n_i\),
\[
H_i=\{m:\ m\bmod L_i\in D_i\}.
\]
The finite-shadow density drop is exactly
\[
h_i=\delta_{i-1}-\delta_i=\frac{|D_i|}{L_i}.
\]
Thus \(h_i=0\) if and only if \(D_i=\varnothing\), and in that case \(H_i=\varnothing\).  Consequently
\[
B_N\setminus B
\subseteq
\bigcup_{\substack{i>N\\ i\in\mathcal I}}
\{m:\ m\ge n_i,\ m\equiv a_i\pmod {n_i}\}.
\]

For a fixed residue class modulo \(q\), the elementary bound used in [[wiki/nodes/mrw-f92c897044c4|Union-tail criterion for Erdos residue-class logarithmic density]] gives, for \(x>q\),
\[
\sum_{\substack{q\le m<x\\ m\equiv a\pmod q}}\frac1m
\le
\frac{1+\log(x/q)}q.
\]
Applying this only to essential indices yields
\[
\mu_x(B_N\setminus B)
\le
\frac1{\log x}
\sum_{\substack{i>N\\ i\in\mathcal I\\ n_i<x}}
\frac{1+\log(x/n_i)}{n_i}.
\]
Taking upper limits in \(x\) gives
\[
\limsup_{x\to\infty}\mu_x(B_N\setminus B)
\le U_N^{\mathrm{ess}}.
\]
If \(U_N^{\mathrm{ess}}\to0\), the tail-defect criterion in [[wiki/nodes/mrw-ba29cdf1fd30|Finite-shadow reduction for Erdos residue-class logarithmic density]] applies, so \(B\) has logarithmic density \(\delta\).

Finally, the essential criterion is strictly weaker than the raw criterion.  In the nested system \(n_i=2i\), \(a_i\equiv0\pmod {2i}\), the first exclusion removes the even integers and every later excluded progression is contained in the even integers.  Hence \(B_i\) is the odd integers for every \(i\ge1\), so
\[
\delta_0=1,\qquad \delta_i=\frac12\quad(i\ge1).
\]
Therefore \(h_1=1/2\), \(h_i=0\) for \(i\ge2\), and \(\mathcal I=\{1\}\).  It follows that \(U_N^{\mathrm{ess}}=0\) for every \(N\ge1\).  The raw majorant \(U_N\), however, is infinite for every fixed \(N\), as proved in [[wiki/nodes/mrw-f92c897044c4|Union-tail criterion for Erdos residue-class logarithmic density]].  This proves strictness.

## Notes

- This is an overlap-sensitive positive subcase, not a complete solution of Erdos Problem #25.
- The criterion discards fully redundant late exclusions, so it captures divisibility-containment examples that defeat the raw union-tail test.
- It still treats every genuinely density-decreasing index by a full progression bound.  The next target should weight partially redundant indices by residual first-hit mass, not merely by the binary condition \(h_i>0\).
- The block-uniform criterion supplies the next conditional form of such weighting; its hypothesis remains to be derived from residue-overlap structure.
