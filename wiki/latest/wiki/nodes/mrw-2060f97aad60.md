# Proposition: Fixed finite-prime axis-floor obstruction for Erdos 536

## Statement

Let \(P\) be a finite set of primes.  In the notation of [[wiki/nodes/mrw-f835f9671070|Finite-prime weighted-grid reduction for Erdos 536]], put
\[
\delta_P=\prod_{p\in P}\left(1-\frac1p\right)
\]
and let \(g_P(t)\) be the largest size of a grid-bad-free subset of
\[
\Gamma_P(t)=
\left\{\alpha\in\mathbb Z_{\ge0}^{P}:
\prod_{p\in P}p^{\alpha_p}\le t
\right\}.
\]
Then
\[
\delta_P\int_1^\infty g_P(t)t^{-2}\,dt
\ge
\delta_P
\left(
1+\sum_{p\in P}\frac1{p-1}
\right).
\]
In particular, for \(P=\{2,3,5\}\),
\[
\delta_{235}\int_1^\infty g_{235}(t)t^{-2}\,dt
\ge
\frac{11}{15}.
\]
Consequently, no fixed finite-prime instance of the reduction in [[wiki/nodes/mrw-f835f9671070|Finite-prime weighted-grid reduction for Erdos 536]] can by itself prove the terminal estimate \(f(N)=o(N)\).  Such a strategy must either control a growing family of prime sets \(P\), or leave the fixed finite-prime fiber framework.

## Proof

For a finite prime set \(P\), define the axis set
\[
A_P=\{0\}\cup\{n e_p:p\in P,\ n\ge1\}
\subseteq\mathbb Z_{\ge0}^{P},
\]
where \(e_p\) is the \(p\)-coordinate unit vector.

The set \(A_P\) is grid-bad-free.  Indeed, if three distinct points of \(A_P\) all lie on one axis, then in that coordinate the largest exponent is attained by exactly one of the three points, so the pairwise coordinatewise maxima cannot all be equal.  If the three points use exactly two axes, then on an axis containing only one of the points, or on the axis containing the larger of two distinct same-axis points, the maximum is again attained by exactly one point.  If the three points use three distinct axes, then each nonzero coordinate maximum is attained by exactly one point.  In all cases the grid-bad condition fails, because a grid-bad triple requires every coordinate maximum to be attained at least twice.

Thus
\[
g_P(t)\ge |A_P\cap\Gamma_P(t)|
\]
for every \(t\ge1\).  Using the same jump-function identity as in [[wiki/nodes/mrw-f835f9671070|Finite-prime weighted-grid reduction for Erdos 536]],
\[
\int_1^\infty |A_P\cap\Gamma_P(t)|t^{-2}\,dt
=
\sum_{\alpha\in A_P}\prod_{p\in P}p^{-\alpha_p}.
\]
The last sum is
\[
1+\sum_{p\in P}\sum_{n\ge1}p^{-n}
=
1+\sum_{p\in P}\frac1{p-1}.
\]
Multiplying by \(\delta_P\) proves the displayed lower floor.

For \(P=\{2,3,5\}\), one has
\[
\delta_{235}
=
\left(1-\frac12\right)
\left(1-\frac13\right)
\left(1-\frac15\right)
=
\frac4{15},
\]
and
\[
1+\frac1{2-1}+\frac1{3-1}+\frac1{5-1}
=
1+1+\frac12+\frac14
=
\frac{11}{4}.
\]
Hence the lower floor is
\[
\frac4{15}\cdot\frac{11}{4}
=
\frac{11}{15}.
\]

For fixed \(P\), this is a positive constant.  Therefore an upper bound obtained only by optimizing the fixed \(P\)-fiber integral cannot force \(\limsup f(N)/N=0\).  This does not obstruct a growing-\(P\) version of the finite-prime method, but it does obstruct treating further fixed \(P=\{2,3,5\}\) prefix-rank improvements as a terminal route.

## Notes

- This proposition is an obstruction to terminal use of a fixed finite-prime reduction, not an obstruction to the finite-prime program as a whole.
- For \(P=\{2,3,5\}\), the current local upper constant is \(197623/243000\), while the fixed-fiber axis floor is \(11/15\).  Further fixed-\(P\) improvements can still sharpen the constant but cannot close the terminal \(o(N)\) problem.
- Matching and fractional-cover vocabulary remains useful for certificate search, but local tests in the raw log show that ordinary matchings and fractional LP duals are too weak to explain the high-deficit exact prefix ranks by themselves.
