# Corollary: Endpoint interval triples exclude common-fiber lower shadows

## Statement

Let \(P=B\sqcup T\) be a finite disjoint decomposition, and let
\[
\mathcal F
=
\bigcup_{e\in\mathcal E}\{e\cup R:R\in\mathcal R_e\}
\subseteq2^P
\]
be pair-link-free.  For a terminal family \(\mathcal G\subseteq2^T\), define
its lower closure by
\[
\downarrow\mathcal G
=
\{C\subseteq T:\ C\subseteq R\text{ for some }R\in\mathcal G\}.
\]

If \(e_1,e_2,e_3\in\mathcal E\) are pairwise distinct endpoint patterns and
\[
e_3\in I_B(e_1,e_2),
\]
then
\[
\mathcal R_{e_3}\cap
\downarrow(\mathcal R_{e_1}\cap\mathcal R_{e_2})
=
\varnothing.
\]
Equivalently, no terminal set in the \(e_3\)-fiber can be contained in a
terminal set that occurs in both the \(e_1\)- and \(e_2\)-fibers.

Consequently, for any probability law \(\nu_T\) on \(2^T\),
\[
\nu_T(\mathcal R_{e_3})
\le
1-\nu_T\!\left(\downarrow(\mathcal R_{e_1}\cap\mathcal R_{e_2})\right),
\]
and for every real threshold \(h\),
\[
\nu_T(\mathcal R_{e_3}\cap\{|R|>h\})
\le
\nu_T\!\left(
\{|R|>h\}\setminus
\downarrow(\mathcal R_{e_1}\cap\mathcal R_{e_2})
\right).
\]

In particular, let
\[
H_L(T)=\{R\subseteq T:|R|>L\}.
\]
If
\[
H_L(T)\subseteq\mathcal R_{e_1}\cap\mathcal R_{e_2},
\qquad
L<|T|,
\]
then
\[
\mathcal R_{e_3}=\varnothing.
\]

## Proof

Suppose
\[
C\in
\mathcal R_{e_3}\cap
\downarrow(\mathcal R_{e_1}\cap\mathcal R_{e_2}).
\]
Then there is
\[
R\in\mathcal R_{e_1}\cap\mathcal R_{e_2}
\]
with \(C\subseteq R\).  Since
\[
I_T(R,R)=\{D:\varnothing\subseteq D\subseteq R\}=2^R,
\]
we have \(C\in I_T(R,R)\).  Set
\[
S_1=e_1\cup R,\qquad
S_2=e_2\cup R,\qquad
S_3=e_3\cup C.
\]
Because \(B\sqcup T\) is disjoint, equality of full sets forces equality of
their endpoint parts.  The endpoint patterns \(e_1,e_2,e_3\) are pairwise
distinct, so \(S_1,S_2,S_3\) are pairwise distinct, even when \(C=R\).

By hypothesis and endpoint-terminal interval factorization,
\[
e_3\in I_B(e_1,e_2),
\qquad
C\in I_T(R,R),
\]
imply
\[
S_3\in I_P(S_1,S_2).
\]
This contradicts pair-link-freeness of \(\mathcal F\).  Hence the
lower-closure intersection is empty.

The measure inequalities follow because
\[
\mathcal R_{e_3}
\subseteq
2^T\setminus\downarrow(\mathcal R_{e_1}\cap\mathcal R_{e_2}),
\]
and similarly after intersecting with the high-support window \(\{|R|>h\}\).
No product structure is needed for these inequalities.

It remains to prove the complete high-window consequence.  If \(L<|T|\), then
\[
\downarrow H_L(T)=2^T.
\]
Indeed, for any \(C\subseteq T\), if \(|C|>L\), take \(R=C\).  If
\(|C|\le L\), then \(L\ge0\); with
\[
m=\lfloor L\rfloor+1,
\]
we have \(|C|\le m\le |T|\), since \(L<|T|\) and \(|T|\) is an integer.
Extend \(C\) inside \(T\) to a set \(R\) of size \(m\).  Then \(C\subseteq R\)
and \(|R|>L\).  Therefore every \(C\subseteq T\) lies in
\(\downarrow H_L(T)\).  Since
\[
H_L(T)\subseteq\mathcal R_{e_1}\cap\mathcal R_{e_2},
\]
the lower-shadow exclusion gives
\[
\mathcal R_{e_3}\subseteq2^T\setminus\downarrow H_L(T)=\varnothing.
\]

## Notes

- This corollary sharpens the triple-intersection part of
  `mrw-88acf3940157`: the \(e_3\)-fiber avoids not only
  \(\mathcal R_{e_1}\cap\mathcal R_{e_2}\), but its entire lower closure.
- The high-window consequence is intentionally strong only under a strong
  common-fiber hypothesis.  It does not prove terminal decay or an Erdos 536
  residual theorem.
- The result remains valid for any terminal probability law; product measure
  is unnecessary for the displayed inequalities.
