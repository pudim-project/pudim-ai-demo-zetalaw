# Proposition: Fixed-child inverse-difference energy has a dyadic spectrum split

## Statement
Let \(B\) be finite and let \(\pi_B\) be a product probability law on \(2^B\)
with coordinate probabilities \(0<q_b<1\).  Let
\(\mathcal A,\mathcal C\subseteq2^B\) have positive masses
\[
\lambda=\pi_B(\mathcal A),
\qquad
\mu=\pi_B(\mathcal C).
\]
Fix \(g\subseteq B\), put \(U=B\setminus g\), and write \(\pi_g\) for the
restricted product law on \(2^g\).  For \(h\subseteq U\), set
\[
\omega_U(h)=\prod_{u\in h}q_u^2\prod_{u\in U\setminus h}(1-q_u),
\]
and define the sections
\[
\mathcal A_h=\{x\subseteq g:h\cup x\in\mathcal A\},
\qquad
\mathcal C_h=\{y\subseteq g:h\cup y\in\mathcal C\}.
\]
Let
\[
w_h=\omega_U(h)\pi_g(\mathcal A_h)\pi_g(\mathcal C_h),
\qquad
W_g=\sum_{h\subseteq U}w_h,
\]
and define the unnormalized fixed-child inverse-difference energy
\[
\mathfrak D_g=\lambda\mu D_{\mathcal A,\mathcal C}(g).
\]

If \(W_g=0\), then \(\mathfrak D_g=0\).  If \(W_g>0\), choose \(H=h\) with
probability \(w_h/W_g\).  Conditional on \(H=h\), only for \(w_h>0\), choose
\(X\) and \(Y\) independently from \(\pi_g\) conditioned on
\[
X\in\mathcal A_h,\qquad Y\in\mathcal C_h.
\]
Then
\[
\mathbb E\left[
\mathbf 1_{X\cup Y=g}
\prod_{b\in X\triangle Y}q_b^{-1}
\right]
=
\frac{\mathfrak D_g}{W_g}.
\]

Consequently, if \(\mathfrak D_g>0\) and \(\tau>0\), then either
\[
W_g\ge\tau,
\]
or there are an active common core \(h\subseteq U\) and traces
\[
x\in\mathcal A_h,\qquad y\in\mathcal C_h
\]
such that
\[
x\cup y=g,
\qquad
\prod_{b\in x\triangle y}q_b<\frac{\tau}{\mathfrak D_g}.
\]

For the dyadic spectrum, set
\[
Q_g=\prod_{b\in g}q_b^{-1},
\qquad
J_g=\lfloor\log_2 Q_g\rfloor.
\]
For \(0\le j<J_g\), define
\[
\mathcal B_j
=
\left\{
(x,y):x\cup y=g,\ 
2^j\le\prod_{b\in x\triangle y}q_b^{-1}<2^{j+1}
\right\},
\]
and define the final band
\[
\mathcal B_{J_g}
=
\left\{
(x,y):x\cup y=g,\ 
2^{J_g}\le\prod_{b\in x\triangle y}q_b^{-1}\le Q_g
\right\}.
\]
For active sections \(w_h>0\), let \(\mathbb P_h\) denote the conditional
independent law on
\[
X\in\mathcal A_h,\qquad Y\in\mathcal C_h,
\]
and set
\[
S_j=\sum_{h\subseteq U}w_h\,\mathbb P_h((X,Y)\in\mathcal B_j),
\]
where inactive sections contribute \(0\).  If \(\mathfrak D_g>0\), then for
some \(0\le j\le J_g\),
\[
S_j\ge\frac{\mathfrak D_g}{(J_g+1)2^{j+1}}.
\]
If in addition \(W_g<\tau\), the same band has common-core probability
\[
\mathbb P((X,Y)\in\mathcal B_j)
>
\frac{\mathfrak D_g}{\tau(J_g+1)2^{j+1}}.
\]

Finally let \(C_g=\mathbb P(X\cup Y=g)\) under the common-core law.  If
\[
W_g<\tau,\qquad C_g\le c,\qquad c>0,\qquad \mathfrak D_g>0,
\]
then there are an active common core \(h\) and a covering pair
\[
x\in\mathcal A_h,\qquad y\in\mathcal C_h,\qquad x\cup y=g,
\]
with
\[
\prod_{b\in x\triangle y}q_b<\frac{c\tau}{\mathfrak D_g}.
\]

The ordered-distinct repeated-parent analogue is explicit.  Let
\(\mathcal A=\mathcal C\) and define
\[
Z_{\mathcal A}=
\sum_{\substack{a,c\in\mathcal A\\a\ne c}}\pi_B(a)\pi_B(c),
\qquad
\mathfrak D_g^{\ne}=Z_{\mathcal A}D_{\mathcal A}^{\ne}(g),
\]
and
\[
w_h^{\ne}
=
\omega_U(h)
\sum_{\substack{x,y\in\mathcal A_h\\x\ne y}}
\pi_g(x)\pi_g(y),
\qquad
W_g^{\ne}=\sum_{h\subseteq U}w_h^{\ne}.
\]
If \(W_g^{\ne}=0\), then \(\mathfrak D_g^{\ne}=0\).  If
\(W_g^{\ne}>0\), choose \(H=h\) with probability \(w_h^{\ne}/W_g^{\ne}\),
and, only for \(w_h^{\ne}>0\), choose an ordered distinct pair
\((X,Y)\in\mathcal A_h^2\), \(X\ne Y\), with probability proportional to
\(\pi_g(X)\pi_g(Y)\).  Then all preceding conclusions hold with
\[
\mathfrak D_g,\quad W_g,\quad \mathbb P_h
\]
replaced by
\[
\mathfrak D_g^{\ne},\quad W_g^{\ne},\quad \mathbb P_h^{\ne}.
\]
If an active denominator is zero, no extraction is asserted.  In particular,
for \(g=\emptyset\) the ordered-distinct branch has zero active denominator.

## Proof
By `mrw-ce7f13a668ed`,
\[
\mathfrak D_g
=
\sum_{h\subseteq U}\omega_U(h)
\Phi_g(\mathcal A_h,\mathcal C_h).
\]
By `mrw-52e62752b165`, for every section pair
\(\mathcal P,\mathcal Q\subseteq2^g\),
\[
\Phi_g(\mathcal P,\mathcal Q)
=
\pi_g(\mathcal P)\pi_g(\mathcal Q)
\mathbb E\left[
\mathbf 1_{X\cup Y=g}
\prod_{b\in X\triangle Y}q_b^{-1}
\mid X\in\mathcal P,\ Y\in\mathcal Q
\right]
\]
whenever the section masses are positive, and both sides vanish if either
section is empty.  Therefore
\[
\mathfrak D_g
=
\sum_{h\subseteq U}w_h
\mathbb E_h\left[
\mathbf 1_{X\cup Y=g}
\prod_{b\in X\triangle Y}q_b^{-1}
\right].
\]
If \(W_g=0\), every summand is zero, so \(\mathfrak D_g=0\).  If \(W_g>0\),
dividing by \(W_g\) gives exactly the common-core expectation identity.

Assume \(\mathfrak D_g>0\) and \(W_g<\tau\).  Since the common-core
expectation equals \(\mathfrak D_g/W_g>\mathfrak D_g/\tau\), a positive
conditional atom has
\[
\mathbf 1_{x\cup y=g}\prod_{b\in x\triangle y}q_b^{-1}
>
\frac{\mathfrak D_g}{\tau}.
\]
This atom is a covering pair, and hence
\[
\prod_{b\in x\triangle y}q_b<\frac{\tau}{\mathfrak D_g}.
\]
This proves the common-core-or-tiny-difference dichotomy.

For the dyadic split, every covering pair has
\[
1\le\prod_{b\in x\triangle y}q_b^{-1}\le Q_g.
\]
The bands \(\mathcal B_0,\ldots,\mathcal B_{J_g}\) cover all covering pairs.
Moreover, on \(\mathcal B_j\),
\[
\prod_{b\in x\triangle y}q_b^{-1}\le2^{j+1},
\]
including the final band because \(Q_g<2^{J_g+1}\).  Hence
\[
\mathfrak D_g
\le
\sum_{j=0}^{J_g}2^{j+1}S_j.
\]
If every \(S_j\) were smaller than
\[
\frac{\mathfrak D_g}{(J_g+1)2^{j+1}},
\]
the last display would give \(\mathfrak D_g<\mathfrak D_g\), impossible.
Thus some band has the asserted lower bound.  If \(W_g<\tau\), divide
\[
S_j=\sum_hw_h\mathbb P_h((X,Y)\in\mathcal B_j)
\]
by \(W_g\) and use \(W_g<\tau\) to obtain the displayed strict common-core
probability lower bound.

For the cover-probability refinement, if all covering pairs under the
common-core law had
\[
\prod_{b\in x\triangle y}q_b\ge\frac{c\tau}{\mathfrak D_g},
\]
then the inverse-difference weight would be at most
\[
\frac{\mathfrak D_g}{c\tau}
\]
on covering pairs and zero outside them.  Therefore
\[
\frac{\mathfrak D_g}{W_g}
\le
\frac{\mathfrak D_g}{c\tau}C_g
\le
\frac{\mathfrak D_g}{\tau},
\]
contradicting \(W_g<\tau\).  Thus a covering pair has
\[
\prod_{b\in x\triangle y}q_b<\frac{c\tau}{\mathfrak D_g}.
\]

For the ordered-distinct repeated-parent branch, repeat the same argument
using the ordered-distinct formula from `mrw-ce7f13a668ed` and the
ordered-distinct inverse-difference identity from `mrw-52e62752b165`.  The
only active section laws are those with \(w_h^{\ne}>0\), and if
\(W_g^{\ne}=0\) then the nonnegative summands force
\(\mathfrak D_g^{\ne}=0\).  All averaging, dyadic pigeonholing, and
cover-probability steps are identical after replacing the denominator and
conditional laws by their ordered-distinct versions.

## Notes
This is a route-consolidation node, not terminal Erdos 536 evidence.  It turns
fixed-child high interval pileup into either large ratio-weighted common-core
mass or a dyadic band of inverse-difference cover certificates.  The next
problem is to aggregate those certificates into chargeable endpoint triples
and terminal third-fiber losses, or to classify the \(W_g\)-heavy and
tiny-difference branches as separator/product-tower residual structure.
