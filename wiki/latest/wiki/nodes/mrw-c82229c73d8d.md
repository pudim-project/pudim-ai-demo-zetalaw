# Proposition: Overfull endpoint incidence reduces to strict two-point residuals

## Statement

Use the finite endpoint-tower notation of [[mrw-05f82d03b190]]:
\[
P=P_0\supseteq P_1\supseteq\cdots\supseteq P_r,
\qquad
P_{j-1}=P_j\sqcup X_j\sqcup Y_j .
\]
Let
\[
\mathcal E_{\mathrm{ov}}
=
\bigcup_{j=1}^r
\left(\binom{X_j}{2}\cup\binom{Y_j}{2}\right)
\]
be the set of unordered same-class endpoint pairs.  For
\(e=\{p,q\}\in\mathcal E_{\mathrm{ov}}\), write
\[
P_e=P\setminus e,
\qquad
q_e=q_pq_q,
\]
and let \(\nu_{P_e}\) be the restricted product law on \(2^{P_e}\).  Define
\[
\mathfrak M_{P_e}(T)
=
\sup\{\nu_{P_e}(\mathcal A):
\mathcal A\subseteq2^{P_e},\
\mathcal A\text{ is pair-link-free},\
\mathcal A\subseteq\{R:|R|>T\}\}.
\]

Let \(\mathcal F\subseteq2^P\) be pair-link-free, and let
\[
H_L=\{S\subseteq P:|S|>L\}.
\]
Let the realized overfull endpoint event be
\[
O_{\mathrm{ov}}
=
\{S\subseteq P:\exists e\in\mathcal E_{\mathrm{ov}}\text{ with }e\subseteq S\}.
\]
Then, for every real threshold \(L\),
\[
\nu_P(\mathcal F\cap H_L\cap O_{\mathrm{ov}})
\le
\sum_{e=\{p,q\}\in\mathcal E_{\mathrm{ov}}}
q_pq_q\,\mathfrak M_{P_e}(L-2).
\]
Consequently,
\[
\nu_P(\mathcal F\cap H_L)
\le
\mathfrak M_{P_r}(L-2r)
+
\sum_{e=\{p,q\}\in\mathcal E_{\mathrm{ov}}}
q_pq_q\,\mathfrak M_{P_e}(L-2).
\]
In particular, if
\[
\mathfrak M_{P_r}(L-2r)\le\varepsilon_0
\quad\text{and}\quad
\mathfrak M_{P_e}(L-2)\le\varepsilon_e
\quad(e\in\mathcal E_{\mathrm{ov}}),
\]
then every pair-link-free \(\mathcal F\subseteq2^P\) satisfies
\[
\nu_P(\mathcal F\cap H_L)
\le
\varepsilon_0+
\sum_{e=\{p,q\}\in\mathcal E_{\mathrm{ov}}}q_pq_q\,\varepsilon_e.
\]

## Proof

Fix \(e=\{p,q\}\in\mathcal E_{\mathrm{ov}}\).  Define the two-point
conditioned fiber
\[
\mathcal F_e
=
\{R\subseteq P_e:R\cup e\in\mathcal F\}.
\]
This fiber is pair-link-free in \(2^{P_e}\).  Indeed, if
\(R_1,R_2,R_3\in\mathcal F_e\) are pairwise distinct and
\[
R_3\in I_{P_e}(R_1,R_2),
\]
then \(S_i=R_i\cup e\) are pairwise distinct members of \(\mathcal F\).
Since \(e\) is common to all three sets, adjoining \(e\) preserves the
pair-link interval, so
\[
S_3\in I_P(S_1,S_2),
\]
contradicting pair-link-freeness of \(\mathcal F\).

On the event \(e\subseteq S\), product independence gives probability
factor \(q_e=q_pq_q\) for selecting \(e\), followed by the restricted product
law on \(P_e\).  Also
\[
|R\cup e|>L
\quad\Longleftrightarrow\quad
|R|>L-2.
\]
Therefore
\[
\nu_P(\mathcal F\cap H_L\cap\{S:e\subseteq S\})
=
q_e\,\nu_{P_e}\bigl(\mathcal F_e\cap\{R:|R|>L-2\}\bigr)
\le
q_e\,\mathfrak M_{P_e}(L-2).
\]
The overfull event \(O_{\mathrm{ov}}\) is the union of the events
\(\{S:e\subseteq S\}\) over \(e\in\mathcal E_{\mathrm{ov}}\).  A set may
contain more than one same-class endpoint pair, so we use the union bound:
\[
\nu_P(\mathcal F\cap H_L\cap O_{\mathrm{ov}})
\le
\sum_{e\in\mathcal E_{\mathrm{ov}}}
\nu_P(\mathcal F\cap H_L\cap\{S:e\subseteq S\})
\le
\sum_{e\in\mathcal E_{\mathrm{ov}}}
q_e\,\mathfrak M_{P_e}(L-2).
\]

It remains to control the non-overfull part.  If \(S\notin O_{\mathrm{ov}}\),
then every endpoint class \(X_j\) and \(Y_j\) contains at most one selected
coordinate.  Hence every endpoint pattern \(\omega\) occurring in
\(O_{\mathrm{ov}}^c\) has
\[
|E(\omega)|\le 2r.
\]
For each such pattern, [[mrw-05f82d03b190]] gives a pair-link-free terminal
fiber \(\mathcal F_\omega\subseteq2^{P_r}\).  Since
\[
L-|E(\omega)|\ge L-2r
\]
and \(\mathfrak M_{P_r}(t)\) is nonincreasing in \(t\),
\[
\nu_{P_r}\bigl(\mathcal F_\omega\cap\{R:|R|>L-|E(\omega)|\}\bigr)
\le
\mathfrak M_{P_r}(L-2r).
\]
Summing over all non-overfull endpoint patterns gives
\[
\nu_P(\mathcal F\cap H_L\cap O_{\mathrm{ov}}^c)
\le
\mathfrak M_{P_r}(L-2r)
\sum_{\omega:\,E(\omega)\text{ has no overfull class}}\pi(\omega)
\le
\mathfrak M_{P_r}(L-2r).
\]
Combining this estimate with the overfull estimate proves the asserted
global high-support bound.  The final displayed consequence follows by
substituting the assumed residual bounds.

## Notes

- This proposition gives the strict-smaller-residual branch requested after
  [[mrw-59f327fd233e]].  Overfull endpoint mass is not charged directly to
  pointwise mixed incidence here; it is reduced by conditioning on a selected
  same-class endpoint pair and passing to the smaller ground set \(P\setminus e\).
- The result is intentionally a union-bound reduction.  It may overcount sets
  with several overfull endpoint pairs, but it is robust and uses only product
  independence plus common-coordinate stability of pair-link intervals.
- This is not a proof of terminal residual decay, not a mixed-incidence
  production theorem, and not an \(R_P(\theta)\) lift.  To finish the route,
  one still needs either useful bounds for the strict residuals
  \(\mathfrak M_{P_e}(L-2)\), or a separate argument turning large overfull
  incidence into pointwise mixed incidence and coherent-component defect.
- The strict-deletion residual \(\mathfrak M_{P_e}(L-2)\) need not inherit
  the same endpoint-tower structure: deleting two points from one endpoint
  class can leave that class small or empty.  The next residual theorem must
  either control arbitrary strict deletions \(P\setminus e\), or prove that
  these deleted sets can be re-towered with controlled constants.
