# Proposition: Cross-pattern pair-link intervals factor by endpoint and terminal cores

## Statement

Let \(P=B\sqcup T\) be a finite disjoint decomposition.  For
\(e_1,e_2,e_3\subseteq B\) and \(R_1,R_2,R_3\subseteq T\), put
\[
S_i=e_i\cup R_i
\qquad(i=1,2,3).
\]
Then the pair-link interval condition factors:
\[
S_3\in I_P(S_1,S_2)
\]
if and only if
\[
e_3\in I_B(e_1,e_2)
\qquad\text{and}\qquad
R_3\in I_T(R_1,R_2).
\]
Equivalently,
\[
e_1\triangle e_2\subseteq e_3\subseteq e_1\cup e_2
\]
and
\[
R_1\triangle R_2\subseteq R_3\subseteq R_1\cup R_2.
\]

Now let \(\mathcal E\subseteq2^B\), and for each \(e\in\mathcal E\) let
\(\mathcal R_e\subseteq2^T\).  Define the endpoint-pattern fiber union
\[
\mathcal F
=
\bigcup_{e\in\mathcal E}\{e\cup R:R\in\mathcal R_e\}.
\]
Then \(\mathcal F\) is pair-link-free if and only if, for every
\(e_1,e_2,e_3\in\mathcal E\) with
\[
e_3\in I_B(e_1,e_2),
\]
there are no \(R_i\in\mathcal R_{e_i}\) such that
\[
R_3\in I_T(R_1,R_2)
\]
and the three sets \(e_i\cup R_i\) are pairwise distinct.

In particular, if each terminal fiber \(\mathcal R_e\) is pair-link-free and
\(\mathcal E\) has no nonconstant endpoint interval triple, meaning
\[
e_1,e_2,e_3\in\mathcal E,\quad e_3\in I_B(e_1,e_2)
\quad\Longrightarrow\quad
e_1=e_2=e_3,
\]
then \(\mathcal F\) is pair-link-free.

The ordinary pair-link-free condition on \(\mathcal E\), which only forbids
pairwise distinct endpoint triples, is not sufficient for this last
conclusion.  The first extra cross-pattern obstruction occurs when
\[
e_1=e_2,\qquad e_3\subsetneq e_1,
\]
because two different terminal sets in the \(e_1\)-fiber can use a middle set
in the smaller \(e_3\)-fiber.

## Proof

Since \(B\cap T=\varnothing\),
\[
S_1\triangle S_2
=
(e_1\triangle e_2)\sqcup(R_1\triangle R_2)
\]
and
\[
S_1\cup S_2
=
(e_1\cup e_2)\sqcup(R_1\cup R_2).
\]
Thus
\[
S_1\triangle S_2\subseteq S_3\subseteq S_1\cup S_2
\]
holds if and only if the \(B\)-coordinates and \(T\)-coordinates satisfy the
two displayed interval inclusions separately.  This proves the factorization.

For the fiber-union criterion, suppose first that \(\mathcal F\) is not
pair-link-free.  Then there are pairwise distinct
\[
S_i=e_i\cup R_i\in\mathcal F
\qquad(i=1,2,3)
\]
with \(S_3\in I_P(S_1,S_2)\).  By the factorization just proved,
\[
e_3\in I_B(e_1,e_2)
\qquad\text{and}\qquad
R_3\in I_T(R_1,R_2),
\]
so the displayed forbidden data exist.

Conversely, if such \(e_i\) and \(R_i\) exist and the sets
\[
e_i\cup R_i
\]
are pairwise distinct, then the factorization gives
\[
e_3\cup R_3\in I_P(e_1\cup R_1,e_2\cup R_2),
\]
so \(\mathcal F\) is not pair-link-free.  This proves the exact criterion.

Now assume each \(\mathcal R_e\) is pair-link-free and \(\mathcal E\) has no
nonconstant endpoint interval triple.  If a pair-link triple existed in
\(\mathcal F\), the exact criterion would give
\[
e_3\in I_B(e_1,e_2).
\]
The endpoint shield forces \(e_1=e_2=e_3=e\).  Then the three ambient sets are
pairwise distinct exactly when the three terminal sets are pairwise distinct,
and the criterion gives
\[
R_3\in I_T(R_1,R_2),
\]
contradicting pair-link-freeness of \(\mathcal R_e\).  Therefore
\(\mathcal F\) is pair-link-free.

Finally, ordinary pair-link-freeness of \(\mathcal E\) is weaker because it
only tests pairwise distinct endpoint sets.  If \(e_3\subsetneq e_1=e_2\),
then
\[
e_3\in I_B(e_1,e_2),
\]
but the endpoint triple is not pairwise distinct.  When \(T\) has a coordinate
\(t\), choosing
\[
R_1=\{t\},\qquad R_2=\varnothing,\qquad R_3=\{t\}
\]
gives
\[
R_3\in I_T(R_1,R_2),
\]
and the ambient sets
\[
e_1\cup\{t\},\qquad e_1,\qquad e_3\cup\{t\}
\]
are pairwise distinct with the third in the interval of the first two.  Thus
this is a genuine cross-pattern obstruction not captured by ordinary
endpoint-level pair-link-freeness.

## Notes

- This is the exact cross-pattern constraint missing from the purely additive
  endpoint-pattern residual budget in [[mrw-05f82d03b190]].
- A future improvement over the mixture bound must exploit endpoint triples
  \(e_3\in I_B(e_1,e_2)\) together with terminal interval intersections
  \(I_T(R_1,R_2)\cap\mathcal R_{e_3}\).  Without such triples, the
  occupancy-defect branch is just a disjoint mixture of fixed-pattern terminal
  residuals.
- The nonconstant endpoint-interval shield is stronger than ordinary
  pair-link-freeness.  Equivalently, it can be enforced by ordinary
  pair-link-freeness for pairwise distinct endpoint triples together with the
  antichain condition on \(\mathcal E\).  The antichain condition removes the
  repeated-endpoint cases such as \(e_1=e_2\), \(e_3\subsetneq e_1\).
- Focused Oracle confirmed the interval factorization and flagged the same
  missing distinctness issue for the weaker endpoint-pair-link-free
  consequence; the statement above uses the corrected nonconstant endpoint
  interval condition.
- This proposition does not prove \(M_{P_k}(\theta)\to0\), \(U_k(\theta)\to0\),
  or an \(R_P(\theta)\) lift.  It identifies the next structural object that
  must be charged or ruled out.
