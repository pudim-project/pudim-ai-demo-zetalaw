# Counterexample: Singleton endpoint shields obstruct endpoint-only decay

## Statement

Let \(B\) be a finite endpoint coordinate set with independent product
weights \(0<q_b<1\), and let \(\nu_B\) be the corresponding product law on
\(2^B\).  Set
\[
\mathcal E_1(B)=\{\{b\}:b\in B\}.
\]
Then \(\mathcal E_1(B)\) is interval-shielded: it has no nonconstant endpoint
interval triple.

Its exact product mass is
\[
\Pi_1(B)
:=
\nu_B(\mathcal E_1(B))
=
\sum_{b\in B}q_b\prod_{c\in B\setminus\{b\}}(1-q_c)
=
\left(\prod_{c\in B}(1-q_c)\right)
\sum_{b\in B}\frac{q_b}{1-q_b}.
\]
Consequently, if \(B_n\) is a sequence of endpoint coordinate sets with
\[
Q_n:=\sum_{b\in B_n}q_b\to\alpha\in(0,\infty),
\qquad
\max_{b\in B_n}q_b\to0,
\]
then
\[
\Pi_1(B_n)\to \alpha e^{-\alpha}.
\]
In particular, for \(Q_n\to1\) this interval-shielded endpoint family has
asymptotic product mass \(e^{-1}\).

Moreover, for every finite terminal coordinate set \(T\) disjoint from \(B\)
and every pair-link-free terminal family \(\mathcal R\subseteq2^T\), the
singleton endpoint lift
\[
\mathcal F_1(B,\mathcal R)
=
\{\{b\}\cup R:b\in B,\ R\in\mathcal R\}
\subseteq2^{B\sqcup T}
\]
is pair-link-free.  Its high-support mass is exactly
\[
\nu_{B\sqcup T}(\mathcal F_1(B,\mathcal R)\cap\{|S|>L\})
=
\Pi_1(B)\,
\nu_T(\mathcal R\cap\{|R|>L-1\}).
\]
Thus the optimal singleton-shielded endpoint branch is
\[
\Pi_1(B)\,\mathfrak M_T(L-1).
\]

This gives a concrete positive-mass obstruction to any endpoint-only theorem
claiming that interval-shielded endpoint-pattern mass must vanish under
diffuse weights and bounded total endpoint weight with a nonvanishing limit.
It is not a counterexample to Erdos 536 or to terminal residual decay; it shows
that the shielded branch can only be controlled through a real endpoint
variational theorem, terminal residual estimates, or unshielded endpoint
interval triples.

## Proof

First prove the shield property.  If \(e_1=e_2=\{b\}\), then
\[
I_B(e_1,e_2)=\{f\subseteq\{b\}\},
\]
and the only member of \(\mathcal E_1(B)\) in this interval is \(\{b\}\)
itself.  If \(e_1=\{b_1\}\) and \(e_2=\{b_2\}\) with \(b_1\ne b_2\), then
\[
e_1\triangle e_2=\{b_1,b_2\}=e_1\cup e_2,
\]
so
\[
I_B(e_1,e_2)=\{\{b_1,b_2\}\},
\]
which contains no singleton.  Therefore any endpoint interval triple inside
\(\mathcal E_1(B)\) is constant.

The product mass formula is just the exact probability of selecting exactly
one endpoint coordinate:
\[
\nu_B(\{\{b\}\})
=
q_b\prod_{c\ne b}(1-q_c),
\]
and summing over \(b\) gives the two displayed forms.

For the asymptotic statement, write \(m_n=\max_{b\in B_n}q_b\).  Since
\(\sum_b q_b^2\le m_nQ_n\to0\),
\[
\sum_{b\in B_n}\log(1-q_b)
=
-Q_n+O\left(\sum_{b\in B_n}q_b^2\right)
\to -\alpha.
\]
Also, for all large \(n\), \(m_n<1/2\), so
\[
\sum_{b\in B_n}\frac{q_b}{1-q_b}
=
Q_n+O\left(\sum_{b\in B_n}q_b^2\right)
\to\alpha.
\]
Multiplying the two limits gives
\[
\Pi_1(B_n)\to\alpha e^{-\alpha}.
\]

Finally, the full pair-link interval audit is exactly the shield consequence
of `mrw-20ca89f696f2`: every terminal fiber is the same pair-link-free
\(\mathcal R\), and the endpoint family \(\mathcal E_1(B)\) has no
nonconstant endpoint interval triple.  Hence \(\mathcal F_1(B,\mathcal R)\)
is pair-link-free.  The high-support mass factors because endpoint slices are
disjoint and every selected endpoint set has cardinality one:
\[
\nu_{B\sqcup T}(\mathcal F_1(B,\mathcal R)\cap\{|S|>L\})
=
\sum_{b\in B}\nu_B(\{\{b\}\})
\nu_T(\mathcal R\cap\{|R|>L-1\})
=
\Pi_1(B)\nu_T(\mathcal R\cap\{|R|>L-1\}).
\]
Optimizing over \(\mathcal R\) gives the residual
\[
\Pi_1(B)\mathfrak M_T(L-1).
\]

## Notes

- This is a route obstruction, not a terminal construction for Erdos 536.
  It leaves all terminal-core residual questions untouched.
- The example is deliberately shielded; it creates no nonconstant endpoint
  interval triples and therefore no terminal cross-fiber exclusions.
- The \(e^{-1}\) limit shows that diffuse endpoint weights with bounded,
  nonzero total mass do not by themselves make the shielded endpoint branch
  negligible.  Any useful bound must use more structure than
  interval-shieldedness alone.
