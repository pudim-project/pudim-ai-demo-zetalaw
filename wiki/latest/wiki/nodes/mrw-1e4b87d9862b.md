# Proposition: Tripartite 3-uniform endpoint shields carry positive diffuse residuals

## Statement

Let \(B=X\sqcup Y\sqcup Z\) be a finite disjoint endpoint coordinate set
with independent product weights \(0<q_b<1\).  Let
\(H\subseteq X\times Y\times Z\) be any 3-partite 3-uniform hypergraph and
define
\[
\mathcal E(H)
=
\{\{x,y,z\}:(x,y,z)\in E(H)\}\subseteq2^B.
\]
Then \(\mathcal E(H)\) is interval-shielded.  Equivalently, if
\[
e_1,e_2,e_3\in\mathcal E(H),
\qquad e_3\in I_B(e_1,e_2),
\]
then \(e_1=e_2=e_3\).

Consequently, for every terminal core \(T\) disjoint from \(B\), the exact
supported high-support residual is
\[
\mathcal R_H(L)
=
\left(\sum_{e\in\mathcal E(H)}\pi_B(e)\right)\mathfrak M_T(L-3),
\qquad
\pi_B(e)=\nu_B(\{e\}).
\]
For \(e=\{x,y,z\}\), this product weight is
\[
\pi_B(\{x,y,z\})
=
q_xq_yq_z\prod_{b\in B\setminus\{x,y,z\}}(1-q_b).
\]

In the complete tripartite case \(H=K_{X,Y,Z}\), put
\[
a_X=\sum_{x\in X}q_x\prod_{u\in X\setminus\{x\}}(1-q_u),
\]
and define \(a_Y,a_Z\) analogously.  Then
\[
\mathcal R_{X,Y,Z}(L)
=
a_Xa_Ya_Z\,\mathfrak M_T(L-3).
\]
For balanced diffuse weights \(|X|=|Y|=|Z|=m\),
\(q_b=\alpha/(3m)\), and \(m\to\infty\), the endpoint factor satisfies
\[
a_Xa_Ya_Z\to e^{-\alpha}\frac{\alpha^3}{27}.
\]

Thus higher-uniform interval-shielded endpoint support has positive diffuse
mass outside the two-uniform endpoint-pair branch.  This is still a
self-similar residual statement, not terminal evidence: it shifts the
terminal residual window to \(\mathfrak M_T(L-3)\), and it gives no
\(R_P(\theta)\) lift by itself.

## Proof

First prove interval-shieldedness.  Since every member of \(\mathcal E(H)\)
has size three, the repeated-endpoint inclusion obstruction cannot occur
unless all endpoint sets coincide.  It is enough to exclude nonconstant
endpoint interval triples.

Take distinct \(e_1,e_2\in\mathcal E(H)\).  If
\(|e_1\cap e_2|\le1\), then \(|e_1\triangle e_2|\ge4\).  Every set in
\(I_B(e_1,e_2)\) contains \(e_1\triangle e_2\), so no three-set
\(e_3\in\mathcal E(H)\) can lie in this interval.

It remains to consider \(|e_1\cap e_2|=2\).  Since both endpoint sets are
one-from-each across \(X,Y,Z\), after relabeling the parts one has
\[
e_1=\{x_1,y,z\},
\qquad
e_2=\{x_2,y,z\},
\qquad x_1\ne x_2.
\]
Any \(e_3\in I_B(e_1,e_2)\) must contain the symmetric difference
\[
e_1\triangle e_2=\{x_1,x_2\}.
\]
If such an \(e_3\) has size three, its third element is chosen from the
common points \(y,z\).  Therefore \(e_3\) contains two vertices from the same
part \(X\), so \(e_3\notin\mathcal E(H)\).  This excludes all nonconstant
endpoint interval triples and proves that \(\mathcal E(H)\) is
interval-shielded.

The exact residual formula now follows from `mrw-3d6bb8271a4c`, because every
endpoint set in \(\mathcal E(H)\) has cardinality three.  The displayed
formula for \(\pi_B(\{x,y,z\})\) is the product probability of selecting
exactly \(x,y,z\) and no other endpoint coordinate.

For \(H=K_{X,Y,Z}\), summing \(\pi_B(\{x,y,z\})\) over all triples factors
over the three endpoint parts:
\[
\sum_{x\in X,y\in Y,z\in Z}\pi_B(\{x,y,z\})
=
a_Xa_Ya_Z.
\]
In the balanced diffuse case,
\[
a_X
=
m\frac{\alpha}{3m}
\left(1-\frac{\alpha}{3m}\right)^{m-1}
\to
\frac{\alpha}{3}e^{-\alpha/3},
\]
and the same limit holds for \(a_Y\) and \(a_Z\).  Hence
\[
a_Xa_Ya_Z
\to
\left(\frac{\alpha}{3}e^{-\alpha/3}\right)^3
=
e^{-\alpha}\frac{\alpha^3}{27}.
\]
This completes the proof.

## Notes

- The proof works for every 3-partite 3-uniform \(H\), not only the complete
  tripartite hypergraph.  The complete case is used only to compute a clean
  positive diffuse endpoint mass.
- This is a higher-uniform analogue of the endpoint-shield branch, not a
  contradiction to the two-uniform envelope in `mrw-d602b51accb8`.
- The complete tripartite residual is self-similar in the same sense as the
  earlier endpoint-pattern residuals: it passes the problem to the terminal
  core with cutoff shifted by three.
- The next live target is to understand higher-uniform endpoint-profile
  envelopes, for instance \(k\)-partite \(k\)-uniform shields with diffuse
  endpoint factor \(e^{-\alpha}\alpha^k/k^k\), or to prove terminal-core
  residual decay/cross-fiber exclusions that beat these shifted residuals.
