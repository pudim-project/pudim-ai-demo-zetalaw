# Theorem: Self-entropy Gamma-product threshold

## Statement

Let \(c\in\mathbb R\), let \(\rho>-1\), and define
\[
\Phi_{\rho,c}(s)
=
\frac{e^{-cs}s^s}{\Gamma(s+\rho)\Gamma(s)}
\qquad(s\ge1).
\]
Let \(\rho_c\) be the unique real number greater than \(-1\) satisfying
\[
\psi(1+\rho_c)=\gamma+1-c.
\]
Then \(\Phi_{\rho,c}\) is strictly decreasing on \([1,\infty)\) if and only if
\[
\rho\ge\rho_c,
\]
equivalently,
\[
\psi(1+\rho)\ge\gamma+1-c.
\]

In particular,
\[
\frac{s^s}{\Gamma(s+\rho)\Gamma(s)}
\text{ is strictly decreasing on }[1,\infty)
\quad\Longleftrightarrow\quad
\psi(1+\rho)\ge\gamma+1,
\]
and
\[
\frac{(s/e)^s}{\Gamma(s+\rho)\Gamma(s)}
\text{ is strictly decreasing on }[1,\infty)
\quad\Longleftrightarrow\quad
\psi(1+\rho)\ge\gamma.
\]

## Proof

Because \(\psi\) is strictly increasing on \((0,\infty)\), with \(\psi(t)\to-\infty\) as \(t\to0^+\) and \(\psi(t)\to\infty\) as \(t\to\infty\), the equation
\[
\psi(1+\rho_c)=\gamma+1-c
\]
has a unique solution \(\rho_c>-1\).

Let
\[
L_{\rho,c}(s)=\log\Phi_{\rho,c}(s)
=s\log s-cs-\log\Gamma(s+\rho)-\log\Gamma(s).
\]
Then
\[
L_{\rho,c}'(s)=\log s+1-c-\psi(s+\rho)-\psi(s).
\]
Set
\[
G_{\rho,c}(s)=\psi(s+\rho)+\psi(s)-\log s-1+c.
\]
Thus \(L_{\rho,c}'(s)=-G_{\rho,c}(s)\).

For \(x>0\),
\[
\psi'(x)=\sum_{k=0}^{\infty}\frac1{(x+k)^2}
>
\int_0^\infty\frac{dt}{(x+t)^2}
=\frac1x.
\]
Therefore, for \(s\ge1\),
\[
G_{\rho,c}'(s)
=\psi'(s+\rho)+\psi'(s)-\frac1s
>0.
\]
So \(G_{\rho,c}\) is strictly increasing on \([1,\infty)\), and its minimum is
\[
G_{\rho,c}(1)
=\psi(1+\rho)+\psi(1)-1+c
=\psi(1+\rho)-\gamma-1+c.
\]

If \(\psi(1+\rho)\ge\gamma+1-c\), then \(G_{\rho,c}(1)\ge0\).  Hence \(L_{\rho,c}'(s)\le0\) for \(s\ge1\), and \(L_{\rho,c}'(s)<0\) for every \(s>1\).  For any \(1\le a<b\),
\[
L_{\rho,c}(b)-L_{\rho,c}(a)
=\int_a^bL_{\rho,c}'(s)\,ds<0,
\]
so \(\Phi_{\rho,c}\) is strictly decreasing on \([1,\infty)\).  This includes the endpoint case \(G_{\rho,c}(1)=0\).

Conversely, if \(\psi(1+\rho)<\gamma+1-c\), then \(G_{\rho,c}(1)<0\), so \(L_{\rho,c}'(1)>0\).  By continuity, \(L_{\rho,c}'(s)>0\) on a right-neighborhood of \(1\), and \(\Phi_{\rho,c}\) initially increases.  Strict decrease on \([1,\infty)\) fails.  The equivalence follows.
