# Proposition: Triangle-free endpoint pair shields carry positive diffuse residuals

## Statement

Let \(B\) be a finite endpoint coordinate set with independent product
weights \(0<q_b<1\).  For a simple graph \(G\) on vertex set \(B\), let
\[
\mathcal E(G)=\{\{u,v\}:uv\in E(G)\}\subseteq2^B
\]
be its two-point endpoint-pattern family.  Then \(\mathcal E(G)\) is
interval-shielded if and only if \(G\) is triangle-free.

Writing
\[
P_0(B)=\prod_{b\in B}(1-q_b),
\qquad
r_b=\frac{q_b}{1-q_b},
\]
the exact endpoint mass of this shielded family is
\[
\Pi_G(B)
=
\sum_{uv\in E(G)}q_uq_v\prod_{b\in B\setminus\{u,v\}}(1-q_b)
=
P_0(B)\sum_{uv\in E(G)}r_ur_v.
\]

Let \(T\) be disjoint from \(B\) with a fixed product law \(\nu_T\), and use
\(\nu_{B\sqcup T}=\nu_B\otimes\nu_T\).  Let \(\mathfrak M_T(U)\) be the
terminal pair-link-free high-support residual at cutoff \(U\).  If \(G\) is
triangle-free, define the supported endpoint-fiber optimum by
\[
\mathcal R_G(L)
:=
\sup_{\mathcal F}
\nu_{B\sqcup T}(\mathcal F\cap\{S:|S|>L\}),
\]
where the supremum is over all pair-link-free families of the form
\[
\mathcal F
=
\bigcup_{uv\in E(G)}
\{\{u,v\}\cup R:R\in\mathcal R_{uv}\},
\qquad
\mathcal R_{uv}\subseteq2^T.
\]
Then
\[
\mathcal R_G(L)
=
\Pi_G(B)\mathfrak M_T(L-2).
\]

In particular, let
\[
B_n=X_n\sqcup Y_n,\qquad |X_n|=|Y_n|=m_n\to\infty,
\]
where \(\alpha>0\) and \(m_n>\alpha/2\) for all sufficiently large \(n\).  Put
\(q_b=\alpha/(2m_n)\) for every \(b\in B_n\), and take \(G_n\) to be the
complete bipartite graph between \(X_n\) and \(Y_n\).  Then
\(\max_bq_b\to0\), \(\sum_{b\in B_n}q_b=\alpha\), and for all \(n\) with
\(m_n\ge2\), \(\mathcal E(G_n)\) is an overlapping interval-shielded endpoint
family.  Moreover,
\[
\Pi_{G_n}(B_n)\to e^{-\alpha}\frac{\alpha^2}{4}.
\]
Therefore overlapping endpoint-pair shields can carry positive diffuse mass
even for a branch with no singleton endpoint patterns, i.e. internal
singleton intensity \(Q_{1,n}=0\), while every disjoint matching-type branch is
negligible.

## Proof

For two endpoint sets \(A,B\subseteq B\), recall that
\[
I_B(A,B)=\{C:A\triangle B\subseteq C\subseteq A\cup B\}.
\]
Because \(\mathcal E(G)\) is two-uniform, no distinct member of
\(\mathcal E(G)\) is contained in another.  Thus repeated-endpoint interval
obstructions \(e_3\subsetneq e_1=e_2\) never occur.

Now take two distinct graph edges \(e_1,e_2\).  If they are disjoint, then
\[
e_1\triangle e_2=e_1\cup e_2,
\]
so \(I_B(e_1,e_2)\) contains only the four-point set \(e_1\cup e_2\).  It
therefore contains no member of the two-uniform family \(\mathcal E(G)\).

If \(e_1\) and \(e_2\) share exactly one vertex, write
\[
e_1=\{x,y\},\qquad e_2=\{x,z\}
\]
with \(y\ne z\).  Then
\[
e_1\triangle e_2=\{y,z\},\qquad e_1\cup e_2=\{x,y,z\}.
\]
The only two-point set in \(I_B(e_1,e_2)\) is \(\{y,z\}\).  Hence a
nonconstant endpoint interval triple in \(\mathcal E(G)\) exists exactly when
\(\{x,y\},\{x,z\},\{y,z\}\) are all graph edges, which is exactly a triangle in
\(G\).  This proves the equivalence between interval-shieldedness and
triangle-freeness.

The endpoint mass formula is immediate from product measure:
\[
\nu_B(\{\{u,v\}\})
=
q_uq_v\prod_{b\notin\{u,v\}}(1-q_b)
=
P_0(B)r_ur_v.
\]
Summing over \(uv\in E(G)\) gives \(\Pi_G(B)\).

If \(G\) is triangle-free, the first part says that \(\mathcal E(G)\) is
interval-shielded.  Therefore `mrw-3d6bb8271a4c` applies to the product law
\(\nu_{B\sqcup T}=\nu_B\otimes\nu_T\), and since every endpoint pattern has
size \(2\),
\[
\mathcal R_G(L)
=
\sum_{uv\in E(G)}\nu_B(\{\{u,v\}\})\mathfrak M_T(L-2)
=
\Pi_G(B)\mathfrak M_T(L-2).
\]

For the complete bipartite example, \(G_n=K_{m_n,m_n}\) is triangle-free and
has \(m_n^2\) edges, so
\[
\Pi_{G_n}(B_n)
=
\left(1-\frac{\alpha}{2m_n}\right)^{2m_n}
\,
m_n^2
\left(\frac{\alpha/(2m_n)}{1-\alpha/(2m_n)}\right)^2.
\]
Equivalently,
\[
\Pi_{G_n}(B_n)
=
\left(1-\frac{\alpha}{2m_n}\right)^{2m_n-2}
\,
\frac{\alpha^2}{4}.
\]
Letting \(n\to\infty\) gives
\[
\Pi_{G_n}(B_n)\to e^{-\alpha}\frac{\alpha^2}{4}.
\]
For \(m_n\ge2\), the family is overlapping because all edges incident to a
fixed vertex share that vertex, and it is not a disjoint-block family.  This
gives the claimed positive diffuse obstruction beyond singleton and matching
branches.

## Notes

- This proposition is a route obstruction, not a terminal Erdos 536 theorem.
  It shows that the next endpoint-shield variational problem must include
  dense triangle-free endpoint-pair supports, not only singleton or disjoint
  matching supports.
- The complete bipartite construction is deliberately explicit and does not
  use weighted Mantel aggregation as terminal evidence.  It supplies a concrete
  positive-mass interval-shielded branch whose terminal lift is still just a
  shifted residual \(\mathfrak M_T(L-2)\).
- The next target is either a weighted triangle-free endpoint-pair residual
  theorem with shifted terminal windows, or a cross-level argument proving
  that such bipartite endpoint-pair shields cannot persist through the
  original endpoint-tower constraints without forcing terminal residual decay
  or nonshielded endpoint triples.
