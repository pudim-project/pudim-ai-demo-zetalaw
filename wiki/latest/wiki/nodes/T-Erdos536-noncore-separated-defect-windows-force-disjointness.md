# Theorem: Erdos536 noncore separated defect windows force disjointness

## Statement

For every fixed \(0<\theta<1\), \(\eta>0\), and \(\varepsilon>0\), there are \(\delta>0\) and \(k_0\) such that the following holds for all \(k\ge k_0\). If a positive-mass set of occupied tops \(C\) has conditional defect law \(\lambda_C\) with two separated defect-rank windows of \(\lambda_C\)-mass at least \(\varepsilon\), and \(\lambda_C\) is not \(\varepsilon\)-close to any common-core, endpoint-shield, or rank-thin weighted intersecting model, then \(\lambda_C^{\otimes2}\{D\cap E=\varnothing\}\ge\delta\) on a positive-mass set of tops.
