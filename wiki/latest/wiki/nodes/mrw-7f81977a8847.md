# Proposition: Disjoint endpoint block shields reduce diffusely to singleton residuals

## Statement

Let \(B\) be a finite endpoint coordinate set with independent product
weights \(0<q_b<1\), and let
\[
\mathcal A=\{A_i:i\in I\}\subseteq 2^B
\]
be a finite family of pairwise disjoint nonempty endpoint blocks.  Then
\(\mathcal A\) is interval-shielded.

Write
\[
\pi(A)=\prod_{a\in A}q_a\prod_{b\in B\setminus A}(1-q_b),
\qquad
P_0(B)=\prod_{b\in B}(1-q_b),
\qquad
r_b=\frac{q_b}{1-q_b}.
\]
The exact endpoint mass of \(\mathcal A\) is
\[
\Pi_{\mathcal A}(B)
=
\sum_{A\in\mathcal A}\pi(A)
=
P_0(B)\sum_{A\in\mathcal A}\prod_{a\in A}r_a.
\]

Let \(T\) be disjoint from \(B\), and let \(\mathfrak M_T(U)\) denote the
terminal pair-link-free high-support residual at cutoff \(U\).  Endpoint-fiber
unions supported on \(\mathcal A\) have exact optimum
\[
\mathcal R_{\mathcal A}(L)
=
\sum_{A\in\mathcal A}\pi(A)\mathfrak M_T(L-|A|).
\]
In particular, if
\[
\mathcal A_{\ge2}=\{A\in\mathcal A:|A|\ge2\},
\qquad
\delta=\max_{b\in B}q_b,
\qquad
Q=\sum_{b\in B}q_b,
\]
then for \(\delta<1/2\),
\[
\sum_{A\in\mathcal A_{\ge2}}\pi(A)\mathfrak M_T(L-|A|)
\le
\sum_{A\in\mathcal A_{\ge2}}\pi(A)
\le
4\delta Qe^{-Q}
\le
\frac{4}{e}\delta.
\]
Thus every disjoint-block branch with all blocks of size at least two,
including disjoint pair or matching endpoint patterns, has vanishing mass under
diffuse endpoint weights \(\delta\to0\).

More generally, for a sequence \((B_n,\mathcal A_n)\) with
\[
\delta_n=\max_{b\in B_n}q_b\to0,\qquad
Q_n=\sum_{b\in B_n}q_b\to\alpha\in[0,\infty),
\]
and singleton-block total intensity
\[
Q_{1,n}=\sum_{\{b\}\in\mathcal A_n}q_b\to\alpha_1,
\]
one has, for fixed \(T\) and \(L\),
\[
\mathcal R_{\mathcal A_n}(L)
=
e^{-\alpha}\alpha_1\,\mathfrak M_T(L-1)+o(1).
\]
If instead \(\delta_n\to0\) and \(Q_n\to\infty\), then the entire
disjoint-block endpoint mass \(\Pi_{\mathcal A_n}(B_n)\) tends to \(0\).

## Proof

First prove the interval shield.  If \(A_i=A_j=A\), then
\[
I_B(A,A)=\{E:E\subseteq A\}.
\]
No block \(A_k\ne A\) can be a nonempty subset of \(A\), because the blocks
are pairwise disjoint and nonempty.  If \(A_i\ne A_j\), then disjointness gives
\[
A_i\triangle A_j=A_i\cup A_j,
\]
so
\[
I_B(A_i,A_j)=\{A_i\cup A_j\}.
\]
No block of \(\mathcal A\) equals \(A_i\cup A_j\), since such a block would
intersect both \(A_i\) and \(A_j\).  Hence every endpoint interval triple in
\(\mathcal A\) is constant.

The endpoint mass formula follows from product measure:
\[
\pi(A)=\prod_{a\in A}q_a\prod_{b\notin A}(1-q_b)
=
P_0(B)\prod_{a\in A}\frac{q_a}{1-q_a}.
\]
Summing over \(A\in\mathcal A\) gives \(\Pi_{\mathcal A}(B)\).

Since \(\mathcal A\) is interval-shielded, `mrw-3d6bb8271a4c` gives the exact
terminal residual identity
\[
\mathcal R_{\mathcal A}(L)
=
\sum_{A\in\mathcal A}\pi(A)\mathfrak M_T(L-|A|).
\]

Now assume \(\delta<1/2\).  Then
\[
r_b=\frac{q_b}{1-q_b}\le 2q_b\le 2\delta.
\]
For every block \(A\) with \(|A|\ge2\),
\[
\prod_{a\in A}r_a
\le
(2\delta)\sum_{a\in A}r_a.
\]
The blocks are disjoint, so
\[
\sum_{A\in\mathcal A_{\ge2}}\prod_{a\in A}r_a
\le
2\delta\sum_{b\in B}r_b
\le
4\delta Q.
\]
Also \(P_0(B)\le e^{-Q}\).  Therefore
\[
\sum_{A\in\mathcal A_{\ge2}}\pi(A)
=
P_0(B)\sum_{A\in\mathcal A_{\ge2}}\prod_{a\in A}r_a
\le
4\delta Qe^{-Q}
\le
\frac{4}{e}\delta,
\]
because \(Qe^{-Q}\le e^{-1}\) for \(Q\ge0\).  Since
\(\mathfrak M_T(\cdot)\le1\), the same bound controls the non-singleton
residual contribution.

For the diffuse asymptotic with finite \(Q_n\), the non-singleton contribution
is \(o(1)\).  The singleton contribution is
\[
P_0(B_n)\sum_{\{b\}\in\mathcal A_n}r_b\,\mathfrak M_T(L-1).
\]
Because \(\sum_b q_b^2\le\delta_nQ_n\to0\),
\[
P_0(B_n)=\exp\left(\sum_b\log(1-q_b)\right)\to e^{-\alpha},
\]
and
\[
\sum_{\{b\}\in\mathcal A_n}r_b
=
\sum_{\{b\}\in\mathcal A_n}q_b+O\left(\sum_bq_b^2\right)
\to\alpha_1.
\]
This proves
\[
\mathcal R_{\mathcal A_n}(L)
=
e^{-\alpha}\alpha_1\,\mathfrak M_T(L-1)+o(1).
\]

If \(Q_n\to\infty\), then for large \(n\),
\[
P_0(B_n)\sum_{\{b\}\in\mathcal A_n}r_b
\le
e^{-Q_n}\,2Q_n\to0,
\]
and the non-singleton contribution is bounded by
\[
4\delta_nQ_ne^{-Q_n}\to0.
\]
Thus \(\Pi_{\mathcal A_n}(B_n)\to0\).

## Notes

- This proposition explains why the singleton obstruction is the only
  positive diffuse-mass obstruction inside the disjoint-block or matching
  class.  Pair blocks and larger disjoint blocks vanish under diffuse endpoint
  weights.
- It is still not a terminal Erdos 536 theorem.  It handles a structured class
  of interval-shielded endpoint supports, not arbitrary shielded antichains.
- The next obstruction class, if needed, must allow overlapping endpoint sets
  while still avoiding nonconstant interval triples.
