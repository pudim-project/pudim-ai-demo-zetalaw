# Theorem: Erdos536 zero disjointness common core exhaustion

## Statement

Assume an admissible non-rank-thin positive-mass sequence \(\mathcal F_k\subseteq H_{k,\theta}\) has zero expected coordinate coverage below occupied tops. Then, using the true defect-disjointness normal form, a positive-mass set of occupied tops has conditional defect laws \(\lambda_C\) that are asymptotically weighted-intersecting; moreover every such obstruction is exhausted by one of three templates: \(o(\sqrt{S_k})\)-rank concentration, moving common-core concentration, or endpoint-shield recursion. Each template either has vanishing ambient mass or feeds a lower-level obstruction of the same type.
