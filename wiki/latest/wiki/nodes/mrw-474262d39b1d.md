# Counterexample: Terminal residuals have unbounded finite-shift ratios

## Statement

For every integer \(h\ge1\) and every \(R>0\), there exists a finite terminal
product core \(T\), a product law on \(T\), and a real threshold \(L\) such
that
\[
\mathfrak M_T(L)>0
\qquad\text{but}\qquad
\frac{\mathfrak M_T(L-h)}{\mathfrak M_T(L)}>R.
\]
Consequently, no universal finite-shift comparison
\[
\mathfrak M_T(L-h)\le C_h\,\mathfrak M_T(L)
\]
with finite \(C_h\) can hold over arbitrary finite terminal product cores,
arbitrary product weights, and arbitrary thresholds.

More explicitly, take
\[
T=\{1,\ldots,h\},
\]
put independent coordinate weight \(q\in(0,1)\) on every point, and set
\[
L=h-\frac12.
\]
Then
\[
\mathfrak M_T(L)=q^h
\]
and
\[
\mathfrak M_T(L-h)
\ge
(1-q)^h+hq(1-q)^{h-1}.
\]
Thus
\[
\frac{\mathfrak M_T(L-h)}{\mathfrak M_T(L)}
\ge
\frac{(1-q)^h}{q^h}\to\infty
\qquad(q\downarrow0).
\]

## Proof

For \(L=h-\frac12\), the high-support event
\[
\{S\subseteq T:|S|>L\}
\]
contains only the full set \(T\).  The family \(\{T\}\) is pair-link-free, so
\[
\mathfrak M_T(L)\ge\nu_T(\{T\})=q^h.
\]
No family supported on this high-support event has mass larger than the event
itself, whose mass is \(q^h\).  Hence
\[
\mathfrak M_T(L)=q^h.
\]

Now
\[
L-h=-\frac12,
\]
so every subset of \(T\) lies in the shifted high-support event.  Consider
\[
\mathcal A=\{\varnothing\}\cup\{\{i\}:1\le i\le h\}.
\]
This family is pair-link-free.  If both endpoints are distinct singletons,
their symmetric difference has size two, so no member of \(\mathcal A\) lies
in the interval between them.  If one endpoint is \(\varnothing\) and the
other is a singleton, the interval contains only that singleton, so a
pairwise distinct triple cannot occur.  Triples involving repeated endpoint
sets are harmless for the same reason: the ambient sets would not be pairwise
distinct or the interval middle is not in \(\mathcal A\).

The product mass of \(\mathcal A\) is
\[
\nu_T(\mathcal A)
=
(1-q)^h+hq(1-q)^{h-1}.
\]
Therefore
\[
\mathfrak M_T(L-h)\ge \nu_T(\mathcal A),
\]
and
\[
\frac{\mathfrak M_T(L-h)}{\mathfrak M_T(L)}
\ge
\frac{(1-q)^h+hq(1-q)^{h-1}}{q^h}
\ge
\frac{(1-q)^h}{q^h}.
\]
The last expression tends to infinity as \(q\downarrow0\).  Given any
\(R>0\), choosing \(q\) sufficiently small proves the claim.

## Notes

- This counterexample does not refute a shifted-window theorem in the actual
  prime-weight Erdos 536 regime.  It shows that such a theorem needs extra
  hypotheses linking \(L\), the shift \(h\), the product weights, and the core
  size/profile.
- In particular, the endpoint factor \(e^{-h}\) from complete product towers
  cannot by itself force contraction, because
  \(e^{-h}\mathfrak M_T(L-h)/\mathfrak M_T(L)\) is still unbounded in this
  example as \(q\downarrow0\).
- The next live target is a threshold-aware shifted-window theorem or a
  product-tower alternative using actual high-support structure, not an
  endpoint-only or monotonicity-only comparison.
