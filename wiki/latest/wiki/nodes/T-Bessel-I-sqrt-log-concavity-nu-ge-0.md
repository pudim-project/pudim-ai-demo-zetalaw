# Theorem: forall nu >= 0, u -> sqrt(u) I_nu(u) strictly log-concave on (0,infty)

## Statement

For every \(\nu\ge0\), the function \(u\mapsto \sqrt{u}\,I_\nu(u)\) is strictly log-concave on \((0,\infty)\).
