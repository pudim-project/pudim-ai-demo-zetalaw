# Proposition: Cross-terminal dyadic child-loss aggregation

## Statement
Let \(P=B\sqcup T\) be finite.  Let \(\pi_B\) be a full-support product law on
\(2^B\), let \(\nu_T\) be a probability law on \(2^T\), and let
\[
\mathcal F
=
\bigcup_{e\in\mathcal E}\{e\cup R:R\in\mathcal U_e\}
\subseteq2^P
\]
be pair-link-free.  For each \(R\subseteq T\), set
\[
\mathcal E_R=\{e\in\mathcal E:R\in\mathcal U_e\}.
\]

Fix distinct \(R_1,R_2\subseteq T\), set
\[
\mathcal A=\mathcal E_{R_1},
\qquad
\mathcal C=\mathcal E_{R_2},
\qquad
\lambda=\pi_B(\mathcal A)>0,
\qquad
\mu=\pi_B(\mathcal C)>0,
\]
and let
\[
\mathcal T\subseteq I_T(R_1,R_2)\setminus\{R_1,R_2\}.
\]
Define
\[
M_{\mathcal T}
=
\sum_{R_3\in\mathcal T}\nu_T(R_3)\pi_B(\mathcal E_{R_3}),
\]
and
\[
\mathsf I=\mathsf I_B(\mathcal A,\mathcal C),
\qquad
\sigma=\pi_B(\mathsf I).
\]

For every \(0<\alpha\le1\), one of the following alternatives holds.

1. Large endpoint-shadow loss:
\[
M_{\mathcal T}\le(1-\alpha)\nu_T(\mathcal T).
\]

2. Fixed-child dyadic obstruction: there is \(g\in\mathsf I\) such that
\[
D_{\mathcal A,\mathcal C}(g)>\alpha^{-1}.
\]
Writing
\[
\mathfrak D_g=\lambda\mu D_{\mathcal A,\mathcal C}(g),
\]
we have
\[
\mathfrak D_g>\frac{\lambda\mu}{\alpha}>0.
\]
For this \(g\), use the common-core notation of `mrw-4210f8220daf`.  Then
some dyadic band \(0\le j\le J_g\) satisfies
\[
S_j
\ge
\frac{\mathfrak D_g}{(J_g+1)2^{j+1}}
>
\frac{\lambda\mu}{\alpha(J_g+1)2^{j+1}}.
\]
Moreover, for every \(\tau>0\), either \(W_g\ge\tau\), or the same fixed
child has common-core band probability greater than
\[
\frac{\mathfrak D_g}{\tau(J_g+1)2^{j+1}}
>
\frac{\lambda\mu}{\alpha\tau(J_g+1)2^{j+1}},
\]
and an active common-core covering pair \(x\cup y=g\) with
\[
\prod_{b\in x\triangle y}q_b
<
\frac{\tau}{\mathfrak D_g}
<
\frac{\alpha\tau}{\lambda\mu}.
\]
If the ordinary common-core cover probability satisfies \(C_g\le c\), with
\(c>0\), then the covering pair can be chosen so that
\[
\prod_{b\in x\triangle y}q_b
<
\frac{c\tau}{\mathfrak D_g}
<
\frac{c\alpha\tau}{\lambda\mu}.
\]

In particular, if \(\lambda,\mu\ge\eta>0\) and \(\alpha=\eta^2\), then either
\[
M_{\mathcal T}\le(1-\eta^2)\nu_T(\mathcal T),
\]
or a fixed child \(g\) has
\[
D_{\mathcal A,\mathcal C}(g)>\eta^{-2}
\]
and the corresponding \(W_g\)-heavy or dyadic tiny-difference obstruction
above.

## Proof
Let
\[
\sigma=\pi_B(\mathsf I_B(\mathcal A,\mathcal C)).
\]
By `mrw-e64516fca3bd`,
\[
M_{\mathcal T}
\le
(1-\sigma)\nu_T(\mathcal T).
\]
If \(\sigma\ge\alpha\), this gives
\[
M_{\mathcal T}\le(1-\alpha)\nu_T(\mathcal T),
\]
which is the large endpoint-shadow loss alternative.

Assume \(\sigma<\alpha\).  By `mrw-8d6210a920bc`, the normalized endpoint
interval-pair density \(D_{\mathcal A,\mathcal C}\) is nonnegative, has exact
\(\pi_B\)-support \(\mathsf I\), and integrates to one:
\[
\sum_{g\subseteq B}\pi_B(g)D_{\mathcal A,\mathcal C}(g)=1.
\]
If every \(g\in\mathsf I\) satisfied
\[
D_{\mathcal A,\mathcal C}(g)\le\alpha^{-1},
\]
then
\[
1
=
\sum_{g\in\mathsf I}\pi_B(g)D_{\mathcal A,\mathcal C}(g)
\le
\alpha^{-1}\pi_B(\mathsf I)
=
\alpha^{-1}\sigma
<
1,
\]
a contradiction.  Hence some \(g\in\mathsf I\) has
\[
D_{\mathcal A,\mathcal C}(g)>\alpha^{-1}.
\]
Multiplying by \(\lambda\mu\) gives
\[
\mathfrak D_g>\lambda\mu/\alpha>0.
\]

Apply `mrw-4210f8220daf` to this fixed child.  Since
\(\mathfrak D_g>0\), the \(W_g=0\) boundary is impossible.  The dyadic band
extraction gives a band \(j\) with
\[
S_j\ge \frac{\mathfrak D_g}{(J_g+1)2^{j+1}},
\]
and the displayed lower bound follows from
\[
\mathfrak D_g>\lambda\mu/\alpha.
\]
For a given \(\tau>0\), if \(W_g\ge\tau\), we are in the \(W_g\)-heavy
branch.  If \(W_g<\tau\), `mrw-4210f8220daf` gives the common-core
probability lower bound for the same dyadic band and extracts an active
covering pair with
\[
\prod_{b\in x\triangle y}q_b<\tau/\mathfrak D_g.
\]
Its cover-probability refinement gives the optional \(C_g\le c\) conclusion.
Substituting \(\mathfrak D_g>\lambda\mu/\alpha\) gives all displayed
quantitative certificates.

The \(\eta^2\)-scale specialization follows by taking \(\alpha=\eta^2\) and
using
\[
\lambda\mu\ge\eta^2.
\]

## Notes
- This proposition is cross-terminal only.  It does not cover the
  repeated-parent lower-shadow \(\mathsf J_B\) branch.
- The cover-probability improvement is conditional on the extra hypothesis
  \(C_g\le c\); it is not automatic.
- If \(\mathcal T=\emptyset\) or \(\nu_T(\mathcal T)=0\), the child-loss
  inequality is vacuous.
- This is not terminal Erdos 536 evidence.  It packages existing tools into a
  sharper route alternative: failure of an \(\eta^2\)-scale terminal child
  loss is now isolated as a fixed-child \(W_g\)-heavy or dyadic
  tiny-difference obstruction.
- Oracle returned `PASS` for the promoted statement and proof.
