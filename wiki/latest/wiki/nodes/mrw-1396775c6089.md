# Problem: Sharp reciprocal Gamma-product monotonicity threshold

## Statement

Bulboaca and Zayed ask for the smallest positive parameter values in their Gamma-product monotonicity examples.  In the base example, the question is to find the optimal \(\rho\) for which
\[
\varphi_\rho(s)=\frac{1}{\Gamma(s+\rho)\Gamma(s)}
\]
is strictly decreasing on \([1,\infty)\), equivalently for which
\[
W_\rho(s)=\Gamma(s+\rho)\Gamma(s)
\]
is strictly increasing on \([1,\infty)\).

The local theorem [[wiki/nodes/mrw-0fd149ddc79d|Sharp threshold for reciprocal Gamma-product monotonicity]] solves this base threshold problem.  If
\[
\psi(1+\rho_*)=\gamma,
\]
then the optimal condition is \(\rho\ge \rho_*\), where numerically
\[
\rho_*=1.2583969670859318174106234224981693941\ldots .
\]
The same theorem also gives the sharp endpoint for every example covered by the source's decreasing-logarithmic-derivative hypothesis: if \(J=u'/u\) is nonincreasing, the exact threshold is
\[
\psi(1+\rho)\ge \gamma+J(1).
\]
The follow-up theorem [[wiki/nodes/mrw-37311e7a5a0f|Variational sharp threshold for polynomial Gamma-product monotonicity]] handles the polynomial numerator model
\[
u_m(s)=s^m+1
\]
by an exact variational formula.  It proves that for \(m\ge4\) the sharp threshold is not controlled by the left endpoint \(s=1\).
The localization theorem [[wiki/nodes/mrw-73218406186e|Support localization for polynomial Gamma-threshold maximizers]] further proves that every maximizer for \(m\ge4\) lies in
\[
1<s<(m-1)^{1/m},
\]
and hence \(s=1+O(\log m/m)\) along the large-\(m\) frontier.

## Evidence

- Source problem context: Bulboaca--Zayed 2026, Remark 3, asks for the smallest positive \(\rho\)-values in the Gamma-product examples.
- The source proves a sufficient condition with \(\rho>\rho_*\); the local theorem adds necessity and includes the endpoint.
- The polynomial reduction theorem gives a rigorous next-step answer for the source's \(\rho_m\)-question: the optimal value is a maximization problem for an explicit digamma-inverse functional.

## Depends on

- Classical monotonicity of the digamma function \(\psi\) on \((0,\infty)\).
