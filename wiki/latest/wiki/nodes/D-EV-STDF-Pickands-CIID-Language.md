# Definition: Extreme-value stable tail and conditionally iid Pickands language

## Statement

For a bivariate extreme-value copula, the stable tail dependence function \(\ell\) is encoded by the Pickands dependence function \(A(t)=\ell(1-t,t)\). The symmetric conditionally iid / infinitely extendible bivariate subclass is denoted \(\mathcal A^*\).
