# Problem: Erdos residue-class logarithmic-density problem

## Statement

Let
\[
1\le n_1<n_2<\cdots
\]
be a sequence of integers, and for each \(i\) choose one residue class
\[
a_i \pmod {n_i}.
\]
Define
\[
B=\{m\in\mathbb N:\ \text{for every }i,\ m<n_i\text{ or }m\not\equiv a_i\pmod {n_i}\}.
\]
Erdos Problem #25 asks whether \(B\) must have a logarithmic density:
\[
\lim_{x\to\infty}\frac1{\log x}
\sum_{\substack{m\in B\\m<x}}\frac1m.
\]

## Evidence

- Source: Thomas F. Bloom, Erdős Problems Database, problem #25, accessed 2026-05-18.
- The database marks the problem open and records no claimed partial or complete solution in the comments as of the access date.
- The same database records problem #25 as a special case of Erdős Problem #486, where one may exclude arbitrary sets \(X_n\subseteq\mathbb Z/n\mathbb Z\) for each modulus.

## Local Bridge

This problem is a natural Erdos-list fallback for the local zeta-law program because:

- the target limit uses harmonic weights \(1/m\), matching logarithmic-density and zeta-law limiting measures;
- the construction is modular-residue based, matching [[wiki/nodes/mrw-538319137c76|Modular residue distribution and successor entropy]];
- the existing theorem [[wiki/nodes/mrw-1ac4e44cbbad|Zeta-law successor entropy and modular resolution]] already treats finite modular shadows as approximations to an infinite object.

## First Attack Target

Build a harmonic finite-measure model
\[
\mu_x(S)=\frac1{\log x}\sum_{\substack{m<x\\m\in S}}\frac1m
\]
and express \(B\) as a decreasing intersection of finite residue-exclusion sets
\[
B_N=\{m:\ m<n_i\text{ or }m\not\equiv a_i\pmod {n_i}\text{ for all }i\le N\}.
\]
The first concrete question is whether the finite limits
\[
\delta_N=\lim_{x\to\infty}\mu_x(B_N)
\]
exist and whether \(\mu_x(B)-\delta_N\) has a uniform tail control as \(N\to\infty\).
The local finite-shadow reduction [[wiki/nodes/mrw-ba29cdf1fd30|Finite-shadow reduction for Erdos residue-class logarithmic density]] proves that every \(\delta_N\) exists and equals the fraction of allowed residue classes modulo
\[
L_N=\operatorname{lcm}(n_1,\ldots,n_N).
\]
It also proves that if \(\delta_N\to0\), then \(B\) has logarithmic density \(0\).  The remaining positive-shadow obstruction is the tail-continuity condition recorded in [[wiki/nodes/mrw-17f44100cb83|Tail-continuity obstruction for Erdos residue-class logarithmic density]].
The local positive subcase [[wiki/nodes/mrw-f92c897044c4|Union-tail criterion for Erdos residue-class logarithmic density]] proves that \(B\) has logarithmic density \(\delta\) whenever the active tail is controlled by the weighted union majorant
\[
U_N=
\limsup_{x\to\infty}
\frac1{\log x}
\sum_{\substack{i>N\\ n_i<x}}
\frac{1+\log(x/n_i)}{n_i}
\]
with \(U_N\to0\).  In particular, the problem is solved locally under the summable-reciprocal hypothesis \(\sum_i1/n_i<\infty\), but this condition is not necessary.
The sharper local criterion [[wiki/nodes/mrw-171478aeed08|Essential-index tail criterion for Erdos residue-class logarithmic density]] first discards all late exclusions that do not decrease the finite-shadow density.  It proves the same conclusion under the essential-index majorant \(U_N^{\mathrm{ess}}\to0\), which is strictly weaker than the raw \(U_N\to0\) test and captures fully redundant nested exclusions.
The block-uniform criterion [[wiki/nodes/mrw-e0778085804e|Block-uniform first-hit criterion for Erdos residue-class logarithmic density]] gives a conditional partial-redundancy route: if finite first-hit blocks have uniformly bounded logarithmic mass in terms of their total finite-shadow decrement plus a summable error, then \(B\) has logarithmic density \(\delta\).  The route note [[wiki/nodes/mrw-536639208ce1|Escaping first-hit mass obstruction for finite-shadow decrement control]] explains why the scalar decrement sequence \(h_i=\delta_{i-1}-\delta_i\) alone is not enough; a proof must use uniformity, scale localization, or residue-overlap structure.
The finite CRT certificate [[wiki/nodes/mrw-2945dff32e3e|CRT prefix-dispersion certificate for Erdos first-hit block uniformity]] makes this route checkable for a block \(G_I\): its uniform logarithmic mass is bounded by a threshold-prefix term \(P_I\), a CRT residue-prefix dispersion term \(R_I\), and an absolute multiple of its finite-shadow decrement \(\eta_I\).  The next obstruction is to prove summability of these certificate defects or construct a residue-specific block where they are too large.
The obstruction note [[wiki/nodes/mrw-e0971c9b820a|Small-residue obstruction to unshifted CRT prefix-defect summability]] proves that \(R_I\) is not automatically summable: it may count small formal representatives that occur before the relevant exclusion threshold.  The repaired finite certificate [[wiki/nodes/mrw-f1348014e087|Threshold-aware CRT certificate for Erdos first-hit block uniformity]] replaces \(R_I\) by a first-active-representative defect \(Q_I\).  The activation-scale bound [[wiki/nodes/mrw-eaf102b5cac0|Activation-scale bound for threshold-aware Erdos first-hit defects]] proves
\[
Q_I\le \frac{L_B}{n_B\log n_B}\eta_I.
\]
The first-cycle entropy bound [[wiki/nodes/mrw-7586943cc138|First-cycle entropy bound for threshold-aware Erdos defects]] improves this to a packed support profile \(Q_I\le\Phi(n_B,L_B\eta_I)\), which is sharp using only the threshold and support size.  The live target is now to use residue-overlap or CRT dispersion to improve beyond that profile, or to construct a genuine large actual first-hit-mass obstruction.

## Notes

- This node is source-grounded open-problem context only.  It is not marked solved or partially solved.
- Problem #486 is kept as the broader generalization, but the next sprint should start with #25 because it has exactly one excluded residue class per modulus.
- The unshifted \(R_I\) route is now quarantined as an automatic summability target; use the threshold-aware \(Q_I\) defect instead.
- The activation-scale \(Q_I\) bound is only a sufficient subcase.  It does not solve Erdos Problem #25 because the ratio \(L_B/(n_B\log n_B)\) can be large.
- The first-cycle entropy profile is support-size-only sharp.  A stronger route must use actual residue structure.
