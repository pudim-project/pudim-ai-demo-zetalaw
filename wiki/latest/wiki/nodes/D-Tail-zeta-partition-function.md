# Definition: Tail zeta partition function

## Statement

For \(s>1\) and \(n\in\mathbb N\), the tail zeta partition function is \(\zeta_n(s)=\sum_{k=n}^{\infty}k^{-s}\). The associated tail law is \(\rho_{s,n}(k)=k^{-s}/\zeta_n(s)\) for \(k\ge n\).
